# Steam Input 預設配置

`rov_gamepad.vdf` 是雙搖桿手把的傳統 XInput 輸出配置。左右搖桿、類比扳機、
肩鍵、方向鍵、四顆面鍵、兩個選單鍵與壓桿均保留為手把輸入。遊戲內的飛行模式、
短按／長按與改鍵由輸入層決定。背鍵、陀螺儀與觸控板可由玩家另外配置。

1. 在開發用 Steam 客戶端將 VDF 放入 `controller_base/templates/`，重新啟動客戶端。
2. 連接對應類型的手把，在遊戲的控制器配置中從範本選取「標準手把」並套用。
   此檔的類型是 `controller_xboxone`。其他裝置從各自的 Gamepad 雙搖桿範本開始，
   依同一組位置輸出對照建立配置。Steam Deck 保留遊戲震動，Steam Input 轉送觸覺回饋。
3. 在遊戲內驗證選單確認／返回、搖桿回中、兩個扳機的半行程與震動。
   分別匯出每種裝置的配置，在 Steamworks 的該 AppID 設為官方建議配置並發佈。

Steam Input 顯示虛擬 XInput 手把時，遊戲只能依虛擬裝置顯示字母。Switch 配置要同時保留
飛行位置與右鍵確認時，保留 Steam 的位置輸出，並在遊戲設定中交換「確認」與「返回」。
直接連接並辨識為 Switch 配置時會自動套用。8BitDo 依模式可能回報為不同裝置。
