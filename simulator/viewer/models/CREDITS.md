# Third-party models and textures

The third-party scene assets listed below use CC0 or MIT. Vehicle reconstructions are documented separately; this is not a blanket license statement for manufacturer designs.

| File | Source | Author | License | Changes |
|---|---|---|---|---|
| `worker.glb` | [Quaternius: Animated Men pack](https://quaternius.com/packs/animatedmen.html) (`Smooth_Male_LongSleeve`) | Quaternius | CC0 1.0 | .blend to glTF, materials forced opaque; dressed by `cad/build_deck_crew.py`: head scaled to 90 %, coverall split into tintable top/trousers with a procedural fabric normal map, reflective tape, boots, gloves, and a skinned work vest and hard hat (original geometry); WebP textures, meshopt |
| `waternormals.jpg` | [three.js examples](https://github.com/mrdoob/three.js/tree/r160/examples/textures) | three.js authors | MIT | none |

`workboat.glb` is original work: an 11.6 m aluminium ROV support workboat generated by `cad/build_support_vessel.py` (geometry and all textures procedural, no third-party assets; registration lettering is a generic placeholder and the small deck monitor text are rasterised from the DejaVu Sans fonts (Bitstream Vera licence; only rasterised glyphs end up in the texture, the font is not distributed)). It replaced the CC0 OpenGameArt "Fishing boat low poly" model. `workboat_high.glb` is the same model with the 2048×1024 hull and 1024² deck maps, loaded only in the "high" quality mode (`render_quality.js`, `assetTextureTier`). Rebuild both deck assets with `python simulator/tools/build_support_assets.py` (Blender Python + [gltf-transform](https://gltf-transform.dev/), MIT, via npx).

Water and sky shaders: `three/addons/objects/Water.js` and `Sky.js` (three.js, MIT).

Inspection structures, marine fouling, rock armour and seabed materials (`../structures.js`, `../structure_materials.js`,
`../seabed.js`) are original procedural work of this project: geometry and canvas textures are generated at run time,
no external files. Marine-life GLBs registered later in `../marine_registry.js` (`models/marine/`) must be listed here.

`rov.glb` is the project's existing X1 reconstruction. `bluerov2_heavy.glb` is an estimated study model. `falcon.glb` is generated by `cad/build_falcon_reference.py` from original geometry using [Saab Seaeye's official photographs](https://www.saabseaeye.com/solutions/underwater-vehicles/falcon) as visual references. Photographs are not embedded. See `cad/VEHICLE_MODELS.md` for provenance and estimated dimensions/physics. These models are not manufacturer-certified replicas.

`observation_rov.glb`, `observation_rov_lod1.glb` and `observation_rov_lod2.glb` (generic asset set, `?assets=generic`) are original work: geometry and textures are generated from scratch by `cad/build_observation_rov.py` (Blender, procedural shaders baked to PBR maps) and compressed by `cad/pack_observation_rov.py` with the glTF-Transform CLI (MIT, build-time tool only). No third-party models, photographs, scans or texture libraries are used, and the design is not modelled on any manufacturer's vehicle.

An official BlueROV2 R3 CAD conversion exists only in the developer's `.runtime` reference directory. It is not included here or in the desktop distribution.

## Experimental vision pipeline

No additional runtime library or pretrained weights are vendored. Optional external adapters:
onnxruntime-web (MIT); training uses PyTorch / torchvision SSD-VGG (BSD-3-Clause), Pillow (MIT-CMU),
ONNX (Apache-2.0). Reference transport uses existing websockets (BSD-3-Clause).
No trained weights are included. See `tools/vision/train.md` for limitations.

## Chenjiao original wreck (G7)

`wreck_chenjiao*.glb`: original fictional 48 m coastal freighter; all mesh geometry and rust/algae/silt
textures authored procedurally in `cad/build_wreck_chenjiao.py`. No external models, scans, photographs,
trademarks or texture assets. Build-time glTF-Transform 4.5.1 (MIT) supplies meshopt and WebP compression.

## J1 養殖箱網（原創，CC0-1.0）

`aquaculture/net.webp`、`aquaculture/pen.glb`、`aquaculture/mission.json` 以及
`cad/build_aquaculture_pen.py` 產生的幾何／菱形網目均為本次自行程式製作，資產以 CC0-1.0 釋出。
沒有取用第三方模型、照片或品牌外觀。魚形沿用本專案 `marine_registry.js` 的原創低面數 fallback。
GLB 以 glTF Transform（MIT）、meshoptimizer（MIT）及 WebP（BSD）壓縮；工具不作為 runtime 依賴提交。
固定 seed 71；詳見 `docs/design/scenes/aquaculture/README.md`。

## M2 reservoir prototype

`reservoir/` GLBs and `qysim/reservoir.py` procedural geometry are original CC0 assets.
No photographs, crops, projection textures, third-party models, brands or real place labels are included.
Rebuild with `cad/build_reservoir.py` (Blender GPL tool, glTF Transform 4.5.1 MIT tool).
Current GLBs are collision blockouts, not approved final art. No texture images are embedded yet;
WebP conversion is enabled for the eventual generated texture assets. No `.blend` is committed.
