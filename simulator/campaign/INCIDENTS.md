# 事故與險情演練

工程面板 →「章節 / 訓練課程」可直接選取五項「事故訓練」，不需先通關。
保留對話（不要勾選「公司課程（略過故事）」）才能閱讀簡報與講評。
場景訓練選單也可單獨載入場景；完整腳本與講評請由章節入口進入。

| 腳本 | 操作與完成條件 |
| --- | --- |
| incident_jacket | 從導管架中心經西側出口，再回投放點 |
| incident_wreck | 反向解開預纏卡點，然後回投放點 |
| incident_silt | 經纜線方向中途點，再回投放點 |
| incident_compass | 後退離開鋼構，再回投放點 |
| incident_current | 中止站位，經撤離點回投放點 |

評分沿用 Scorer：目標完成率，碰撞與過張力扣分；斷纜、三次嚴重碰撞、逾時失敗。
成功與失敗均進講評。戰役「completed」代表讀完腳本，實際成功與否以場景 score 為準；
現有戰役成績匯出 completion 並不區分這兩者。

依據：`docs/reference/real-rov-research.md`「檢測怎麼飛、事故怎麼發生」、纜線應變、
光學揚沙與導航失效各節。前兩項為匿名事故改編；後三項是典型險情，不虛構個案細節。
數字、路線、期限為演練設計，不是原事故或特定機型的量測資料。

現有引擎限制（本任務不改物理或腳本執行器）：

- 洋流固定為強流，沒有隨時間轉強或結構背流模擬。
- 纜線用既有接觸、張力、斷裂和繞樁模型，沒有磨損累積或銅線收結模型。
- 人手與信標耗電是通報字幕，不扣減真實電池。
- 揚沙題開始於低能見度，最低為 1 m，非完全遮蔽影像或觸底事件觸發。
- 羅盤失準只以演練通報注入，沒有改寫航向讀數；腳本執行器目前不支援偏差注入。
- 完成路線不等於自動驗證退出定向、沿纜回航或中止決策的程序品質，仍需教官評核。

自動化測試以受控位置通過真正的目標評分器，測試解纏條件、完成及失敗講評路徑；
不宣稱已完成整段操桿航行驗證。
