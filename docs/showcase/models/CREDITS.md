# Third-party models and textures

The third-party scene assets listed below use CC0 or MIT. Vehicle reconstructions are documented separately; this is not a blanket license statement for manufacturer designs.

| File | Source | Author | License | Changes |
|---|---|---|---|---|
| `workboat.glb` | [OpenGameArt: Fishing boat low poly](https://opengameart.org/content/fishing-boat-low-poly) | OpenGameArt user (myBoat) | CC0 1.0 | Collada to glTF (Blender 4.5), textures embedded as JPEG |
| `worker.glb` | [Quaternius: Animated Men pack](https://quaternius.com/packs/animatedmen.html) (`Smooth_Male_LongSleeve`) | Quaternius | CC0 1.0 | .blend to glTF, materials forced opaque; hard hat and life vest are added in code |
| `waternormals.jpg` | [three.js examples](https://github.com/mrdoob/three.js/tree/r160/examples/textures) | three.js authors | MIT | none |

Water and sky shaders: `three/addons/objects/Water.js` and `Sky.js` (three.js, MIT).

`rov.glb` is the project's existing X1 reconstruction. `bluerov2_heavy.glb` is an estimated study model. `falcon.glb` is generated by `cad/build_falcon_reference.py` from original geometry using [Saab Seaeye's official photographs](https://www.saabseaeye.com/solutions/underwater-vehicles/falcon) as visual references. Photographs are not embedded. See `cad/VEHICLE_MODELS.md` for provenance and estimated dimensions/physics. These models are not manufacturer-certified replicas.

An official BlueROV2 R3 CAD conversion exists only in the developer's `.runtime` reference directory. It is not included here or in the desktop distribution.
