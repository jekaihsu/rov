# L5 海底電纜場景（Blender，之後的章節）

把下面整段貼給執行的代理。

```
你負責為 ROV 模擬器「ROV Solution」（GitHub：jekaihsu/rov）製作海底電纜巡線的場景。可以使用 Blender（含 Blender MCP）與 npx @gltf-transform/cli。

先完整讀：
- AGENTS.md（繁體中文，規則有約束力；授權只接受 MIT／BSD／Apache／zlib／CC0 或公有領域；超過 2 MB 的檔案要說明理由）
- docs/design/game-plan.md
- research_notes/遊戲設計/real_rov_jobs_missions.md 的 §2.5、§3、§4（海纜調查：巡線、埋設、裸露、懸空、交越、事件紀錄與沿纜距離 KP）
- docs/design/scenes/README.md（場景擺設的做法：看得到的東西都要有碰撞，有一致性測試）
- 養殖箱網場景的做法：docs/design/scenes/aquaculture/README.md 與 cad/build_aquaculture_pen.py

背景：這是職涯後段「海纜」章節的場景，玩家用觀測級 ROV 沿著一條風場陣列海纜巡線約 300 m，找出並記錄異常。

場景內容：
1. 一條海底電纜，沿著起伏的砂泥海床蜿蜒約 300 m，分成數種區段：
   - 完全埋設：只看得到溝痕。
   - 部分裸露。
   - 完全裸露。
   - 懸空段：海床沖刷造成電纜離底，下方有空隙。
   - 保護措施：混凝土連鎖塊墊或拋石覆蓋的一段。
   - 與另一條管線或舊纜的交越點：有保護墊。
2. 異常（輸出為任務資料，位置可由種子決定）：
   - 外皮損傷
   - 錨拖痕跡橫過電纜
   - 纏在電纜上的漁網或繩索（這是臍帶纜的勾纏點）
   - 一處懸空超過容許長度
3. 沿纜距離標記：每 50 m 一個小標樁或標牌。牌面不要烘死文字，留成可替換的平面。
4. 環境：砂泥海床、沙紋、零星岩塊與貝殼碎屑、底棲生物（海星、海膽，數量少）；水質為大陸棚型，能見度 4–8 m，有潮流。

技術要求：
- 伺服器端碰撞：電纜用一串低解析的膠囊體或圓柱；懸空段下方要真的有空隙，ROV 的高度計與 DVL 會打到。沿用 world.py 既有的 Cylinder、Box、SnagFeature、FieldMesh。
- 埋設段只是海床上的視覺溝痕，不需要碰撞。
- 電纜中心線輸出為折線資料（含每點的埋設狀態），讓任務可以計算「沿纜跟隨的橫向偏差」與 KP。
- 新增情境 key cable_survey（參考 qysim/scenarios.py 的既有寫法），先放三個目標：
  - 從 KP 0 跟到 KP 300，橫向偏差不超過 2 m。
  - 標記所有異常。
  - 量測懸空段長度。
- 預算：LOD0 ≤ 200k 三角形；貼圖預設層 GPU 記憶體 ≤ 32 MiB；meshopt＋WebP；低畫質層合併 draw calls。
- 可重現：建置腳本 cad/build_cable_route.py，固定種子、無頭 Blender 可重產；不提交大型 .blend；授權寫進 simulator/viewer/models/CREDITS.md。
- 外觀要像真實的水下影像：低飽和、近距離開燈才看得到顏色。驗收看模擬器內真實模式的截圖，不是離線算圖。

分支 task/L5-cable-route，開 draft PR，標題「L5: 海底電纜場景」。

驗收：
- cd simulator && python -m unittest discover -s tests 全過，含場景一致性測試；node --test simulator/tests/*.mjs 全過。
- python tools/run_browser_checks.py browser_smoke observation_smoke browser_tether_smoke browser_menu_smoke 通過。
- 附模擬器內截圖：
  - 真實模式機載視角，開燈與關燈
  - 每一種區段各一張
  - 每一種異常各一張
- 附資產報告：三角形、draw calls、貼圖記憶體、檔案大小。

共同的畫面標準（擁有者 2026-11-15 的決定，務必遵守）：
- 目標是「像真實照片一樣」：擁有者提供的現場照片就是標準。場景要有真實世界的髒污、鏽蝕、磨損、不整齊與比例感，不要乾淨的低面數幾何。
- 遊戲的選單會把這個場景全螢幕當背景，上面只壓一個大標題與一顆按鈕，所以場景本身要經得起全螢幕、靜止地看。
- 參考照片只能對照，絕不能進入專案（不提交、不裁切、不做投影貼圖）。遊戲中的畫面一律由遊戲自己算出來。
- 做完要自己用模擬器截圖檢查：和參考照片並排看，差在哪裡就繼續改，直到一眼看過去像同一個地方。
```
