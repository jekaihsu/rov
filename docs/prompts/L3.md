# L3 難度三檔與新遊戲畫面

把下面整段貼給執行的代理。

```
你在 jekaihsu/rov 這個專案（遊戲「ROV Solution」）工作。

先完整讀：
- AGENTS.md（繁體中文，規則有約束力；特別是「共用契約：擬真設定」整段——擬真設定只有一個來源 simulator/viewer/fidelity.js，預設組 real／assisted／custom，超出真機的項目在 real 必須為關）
- docs/design/game-plan.md §11
- docs/design/palette-631/README.md
- simulator/viewer/fidelity.js、fidelity_panel.js、simulator/viewer/menu/

擁有者的決定：
- 目標是硬核擬真玩家，預設是真實模式。
- 另外要有較容易的模式：開新遊戲時用一個全螢幕畫面選「簡單／標準／真實」，每個附說明與實際畫面預覽，之後可在設定更改。
- 畫面要有賽車／飛行模擬遊戲的大片感，不要一張張卡片。
- 配色：深海藍黑、冰白，安全橘只給每個畫面唯一的主要按鈕。

任務：基底 main，分支 task/L3-difficulty，開 draft PR，標題「L3: 難度三檔與新遊戲畫面」。

1. 擬真預設組：
   - 在 fidelity.js 新增「標準」預設組，介於現有的 assisted 與 real 之間。
   - 建議內容：機載視角、有影像延遲、定深輔助開、定點輔助關、AI 疊圖關、水下音效關。逐項列表說明理由，可調整。
   - 現有 assisted 對玩家顯示為「簡單」，real 顯示為「真實」；內部名稱與既有存檔相容，不改既有 key 的意義。
   - Steam 版（window.rovDesktop?.edition === 'steam'）的版本預設由 assisted 改為 real。內部訓練版不變。
   - 更新 AGENTS.md 中對應的說明文字，只改預設組的描述，不改規則。
   - 更新 test_fidelity 與 test_real_defaults 等測試。這是預期行為的改變，不是放寬測試，要在 PR 逐項說明。
2. 新遊戲畫面：
   - 沒有存檔的玩家第一次進入時顯示，設定中也能再打開。
   - 全螢幕版面：
     - 左側三個選項（簡單／標準／真實），用大字直排，鍵盤與手把上下選擇。
     - 右側是該模式的實際飛行畫面預覽。可以用同一個場景、同一個機位預先擷取三張圖；能即時切換更好。
     - 下方一句話說明差別，並提示「考照與真實時數只計算真實模式」。
   - 只有「確認」按鈕用安全橘。
   - 選擇後寫入擬真設定，之後不再出現。
   - 文字放 STRINGS；手把導覽走既有的選單導覽器。
3. 設定：擬真設定分頁最上方加一列「難度：◀ 真實 ▶」左右切換；自訂過的狀態顯示「自訂」。
4. 改動範圍：盡量寫在新模組（例如 simulator/viewer/menu/new_game.js），既有檔案只加最小的掛接點，因為同時有其他人在改選單。

驗收：
- node --test simulator/tests/*.mjs 全過；cd simulator && python -m unittest discover -s tests 全過。
- python tools/run_browser_checks.py browser_menu_smoke browser_menu_gamepad_smoke browser_hud_smoke browser_procedure_smoke browser_results_smoke 通過。
  - 注意：預設改為真實後，依賴輔助預設的檢查要明確指定 ?fidelity=assisted，而不是放寬斷言。
- 新增瀏覽器檢查：全新存檔出現新遊戲畫面、三個選項各自套用正確的預設組、再次啟動不再出現。
- 附三個選項的截圖（1600×900），以及 1280×720 的版面。

補充：版面依 docs/design/big-picture/（若已存在）與擁有者認可的方向——全螢幕實景、一個很大的粗體標題、最少的文字、粗框標示選取、不用細線與半透明面板。
```
