# K2 無線電 AI 配音（需要 OpenAI 金鑰）

把下面整段貼給執行的代理。

```
你在 jekaihsu/rov 這個專案（遊戲「ROV Solution」）工作。先完整讀 AGENTS.md（繁體中文，規則有約束力）、docs/design/game-plan.md（特別是 §9、§11：調性是寫實職場帶一點輕鬆；配音用 AI 語音合成）、simulator/viewer/audio/（音訊引擎、music.js 的壓低機制）、劇情與無線電對話的資料與顯示（simulator/campaign/*.json、simulator/viewer/story/）。

任務：建立無線電配音的產生流程，並產生序章的配音。基底 main，分支 task/K2-voice，開 draft PR，標題「K2: 無線電 AI 配音」。

1. 台詞清單：
   - 寫工具 simulator/tools/voice/extract_lines.py，從劇情與委託資料抽出所有無線電台詞。
   - 輸出 voice_manifest.json，每句包含：穩定的 id（內容雜湊）、角色、語言、文字。
   - 之後台詞有變，只重新產生變動的句子。
2. 產生：
   - 寫工具 simulator/tools/voice/synthesize.py，用 OpenAI 的語音合成 API。
   - 金鑰只從環境變數 OPENAI_API_KEY 讀取。不得寫進任何檔案、日誌或 commit；沒有金鑰時，工具要清楚報錯並結束。
   - 每個角色固定一種聲音與說話風格的指示（冷靜的主管、話多的纜線手、謹慎的客戶代表等）。角色表放在一個 JSON 檔。
   - 後製：
     - 加無線電效果：帶通濾波、輕微失真、開頭與結尾的按鍵雜音。
     - 響度統一到約 −18 LUFS。
     - 輸出 Ogg Opus，單聲道，約 32 kbps。
   - 先只做繁體中文的序章台詞，確認效果；架構要能支援英文、簡體中文、日文（依語言分目錄）。
3. 播放：
   - 在 simulator/viewer/audio/ 新增 voice.js：無線電對話出現時播放對應音檔。
   - 沒有音檔時維持現在的純文字加雜音，不能報錯。
   - 播放時音樂自動壓低（music.js 已有機制）。
   - 設定裡加「語音」音量。
   - 這是呈現層的聲音，不需要擬真項目。
4. 標示：
   - 在 simulator/viewer/models/CREDITS.md（或製作名單）註明「無線電語音由 AI 語音合成產生」。
   - 在 PR 描述附上 OpenAI 使用政策中關於商用與揭露的條文連結。
5. 檔案大小：
   - 列出音檔總大小。
   - 單檔不得超過 2 MB。
   - 整個序章的音檔若超過 5 MB，要在 PR 說明。

驗收：
- node 單元測試：台詞抽取、id 穩定性、沒有音檔時的退回行為。
- cd simulator && python -m unittest discover -s tests 全過；node --test simulator/tests/*.mjs 全過。
- python tools/run_browser_checks.py browser_audio_smoke browser_music_smoke browser_results_smoke 通過。
- PR 描述列出每個角色用的聲音與風格指示，並說明如何重新產生。
```
