# S6：內部訓練模式（整個 ROV 團隊用）（Codex）

> 先完整讀 `docs/prompts/R0-common.md`、`docs/reference/real-rov-research.md`、`docs/reference/own/`、
> `simulator/campaign/course_*.json`、`simulator/campaign/INCIDENTS.md`。分支 `task/S6-team-training`。

擁有者：ROV 團隊全部的人都需要訓練。內部版保留舊課程（a／b／i 系列）、事故演練、收藏，作為**獨立的訓練模式**，
不在 Steam 版主線。目前它們是舊格式、沒有開場水準的演出，也沒有給教官看的紀錄。

1. 訓練模式入口（內部版）：課程地圖，依等級分組（入門、操作員、進階、事故處置），每門課標示目標技能、時長、
   通過標準（照研究報告的真實能力要求寫，不要編造）。
2. 課程與事故演練改用共用劇情導演（R1 的 `story/beat_director.js`；若尚未合併，**先等 R1 合併**再開始這一步）：
   一次一個提示、角色無線電、時限與提醒，但不需要電影演出。
3. **學員紀錄**：每次練習記錄時間、纜線接觸次數、最大張力、碰撞、照片品質、程序是否照順序；可匯出 CSV 與一頁 PDF 成績單
   （給主管看）。紀錄只存在本機與匯出檔，不上傳。
4. **教官模式**（若已有教官功能就整合）：教官可在練習中觸發事故（洋流變強、能見度下降、羅經偏差、纜線勾纏），
   全部用既有物理與情境參數。
5. 真實模式強制：訓練模式預設 `real` 擬真設定，切到輔助要有提示並記錄在成績單。

跑：單元測試（成績計算、匯出格式）、`browser_campaign_smoke` 與新的 `browser_training_smoke.py`（跑完一門課並匯出成績單）。
