# M3 小艇：尾板下水＋選單基地（Blender）

把下面整段貼給執行的代理。

```
你負責為 ROV 模擬器「ROV Solution」（GitHub：jekaihsu/rov）製作小艇尾板下水的場景與動畫素材。可以使用 Blender（含 Blender MCP）與 npx @gltf-transform/cli。我會另外附上真實照片作為參考。

關於參考照片的規則（務必遵守）：
- 照片只用來對照。
- 不得把照片或其裁切放進專案、貼圖或提交。
- 不得用照片做投影貼圖。
- 照片中載具上的品牌字樣不得重現。遊戲中的載具是 YX Model R，使用專案既有的載具模型。

先完整讀：
- AGENTS.md
- docs/design/game-plan.md §11
- docs/design/support-assets/README.md 與 intro-v2/README.md（現有的工作船與 A 字架下水動畫）
- simulator/viewer/deploy_intro.js、launch_rig.js

背景：
- 真實的小型觀測級 ROV 多半從小艇的尾板用手放下水，不用 A 字架。
- 現有的 A 字架下水保留給較大的機型與離岸場景。
- 新增一種「小艇尾板」的下水方式，給 YX Model R 在近岸、港內、風場的委託使用。

要建的內容（對照照片）：
1. 一艘小型作業艇或遊艇的後半部：
   - 白色玻璃纖維船身。
   - 柚木條紋的尾板（游泳平台）。
   - 不鏽鋼的下水梯。
   - 兩側的座位或艙蓋。
2. 尾板上的擺設：
   - ROV 停放的位置：留一到兩個具名節點 rov_slot_0／1，程式會放上載具模型。
   - 捲在一旁的螢光黃綠色臍帶纜。
   - 纜線的防磨護套與安全掛繩。
3. 臍帶纜的外觀：
   - 螢光黃綠色，略帶浮力，會浮在水面上蜿蜒；靠近載具端有一段紅色標記。
   - 檢查專案目前纜線的顏色與水面上的呈現，提出調整方案。這是外觀調整，不改纜線物理。
4. 海面：深藍色的開闊海面與小浪，遠處有風機與自升式平台船的剪影（低面數）。
5. 下水動畫需要的節點與關鍵姿態：
   - 載具在尾板上。
   - 兩手提起（人物可用專案既有的甲板人員模型，或只做手部與手臂的簡化）。
   - 放入水中。
   - 載具浮在水面、纜線放出。

技術要求：
- 以新的下水方式接入現有的下水動畫系統，可用參數選擇，預設不變。寫明哪些委託應該用哪一種。
- 預算：
  - 小艇 ≤ 60k 三角形。
  - 貼圖預設層 GPU 記憶體 ≤ 24 MiB。
  - meshopt＋WebP。
- 可重現：cad/build_small_boat.py；不提交大型 .blend；授權寫進 CREDITS.md。
- 提供選單用的具名相機錨點：從座艙俯看尾板上的兩台載具（對照照片構圖）。

分支 task/M3-swim-platform-launch，開 draft PR，標題「M3: 小艇尾板下水」。

驗收：
- cd simulator && python -m unittest discover -s tests 全過；node --test simulator/tests/*.mjs 全過。
- python tools/run_browser_checks.py browser_menu_smoke browser_hud_smoke browser_procedure_smoke browser_camera_smoke 通過。
- 附模擬器內截圖：
  - 尾板俯視（對照照片構圖）。
  - 下水動畫的四個階段。
  - 纜線浮在水面的畫面。
- 附資產報告。

共同的畫面標準（擁有者 2026-11-15 的決定，務必遵守）：
- 目標是「像真實照片一樣」：擁有者提供的現場照片就是標準。場景要有真實世界的髒污、鏽蝕、磨損、不整齊與比例感，不要乾淨的低面數幾何。
- 遊戲的選單會把這個場景全螢幕當背景，上面只壓一個大標題與一顆按鈕，所以場景本身要經得起全螢幕、靜止地看。
- 參考照片只能對照，絕不能進入專案（不提交、不裁切、不做投影貼圖）。遊戲中的畫面一律由遊戲自己算出來。
- 做完要自己用模擬器截圖檢查：和參考照片並排看，差在哪裡就繼續改，直到一眼看過去像同一個地方。

追加：這艘小艇同時是遊戲選單的「基地」（取代原本另外規劃的工作船內部場景）
- 選單發生在這艘小艇上，鏡頭在幾個具名錨點之間移動，請一併建好並命名：
  - anchor_cockpit：座艙內的操作位置。有一個打開的控制箱（螢幕是獨立平面 screen_main，UV 0–1，程式會把委託畫面貼上去）、搖桿控制器、對講機、水壺。
  - anchor_platform：尾板，俯看停在上面的載具（rov_slot_0／1）與旁邊的裝備架（gear_slot_0…5，放可購買的裝備）。
  - anchor_logbook：艙內小桌，一本日誌或筆電（平面 screen_log）、牆上的執照框（平面 frame_licence）、幾張照片（平面 photo_wall_0…5）。
  - anchor_horizon：從艇上看向作業地點（海面與遠方的結構物），給委託選擇畫面當背景。
- 牆上與螢幕上的字不要烘進貼圖（遊戲要支援四種語言）。
- 新增 simulator/viewer/menu/boat_stage.js，載入場景並提供 goTo(錨點名稱) 的鏡頭移動；用網址參數 ?menuStage=boat 啟用，先不取代現有選單背景。
- 光線做兩種：白天晴朗（對照照片）與清晨或黃昏，選單預設用好看的那一種。
```
