要建的內容（對照照片）：
1. 四腿導管架基礎：
   - 斜腿、X 形斜撐、水平撐。
   - 腿與撐的節點要有加厚的接頭。
2. 水面以上：
   - 黃色塗裝。
   - 潮間帶一圈黑色附著帶與鏽蝕、剝落。
3. 轉接平台：
   - 底面有格柵樑的方形平台。
   - 欄杆、之字形樓梯與中間平台、小型吊桿。
   - 塔筒底部的灰白色圓柱。
4. 靠船設施：
   - 兩根直立的靠船柱與中間的爬梯（柱上有黑色橡膠磨損帶與鏽痕）。
   - 警告牌用通用圖樣，不寫字。
5. 水下部分（玩家主要看這裡，要最細）：
   - 依深度分層的海生物附著：上層藤壺與貝類，中層藻類與海綿，下層較乾淨。
   - 犧牲陽極塊、J 管與管夾。
   - 樁套與灌漿接頭、防沉板。
   - 海床的沖刷坑與拋石。
6. 遠景：一排風機（低面數，可用少量實例），海平線。
7. 水面：能從水下往上看到導管架穿出水面的輪廓。

- 預算：

  - 水上部分 ≤ 80k。
  - 貼圖預設層 GPU 記憶體 ≤ 48 MiB。
  - meshopt＋WebP，並提供低畫質版本。
- 可重現：建置腳本 cad/build_wind_jacket.py，無頭 Blender、固定種子；不提交大型 .blend；授權寫進 simulator/viewer/models/CREDITS.md。

  - 一個在水面上，從小艇的角度仰看導管架（對照照片的構圖）。
  - 一個在水下，看著斜撐與附著生物。

分支 task/M1-wind-jacket，開 draft PR，標題「M1: 離岸風電導管架場景」。
