# ROV Solution｜80 秒實機預告片

製作規格，非已拍影片。全片畫面來自首版候選遊戲內畫面，包含結尾背景；禁止現場照片、插畫、AI 生成影像、離線渲染、假 UI。字卡是剪輯文字，不代替玩法畫面。四語各輸出一支，不在同一鏡塞四語。以手動推力、纜線、感測限制與程序吸引硬核模擬玩家。

依 [Steam Trailers](https://partner.steamgames.com/doc/store/trailer)（2026-11-15 查閱）以 Gameplay 類別排第一支；靜音自動播放也能理解。輸出 1920 × 1080、16:9、H.264 MP4／AAC，至少 5,000 Kbps；30 或 60 fps（亦可 29.97／59.94），依實際穩定拍攝能力選定，不插幀。80 秒是本片編輯長度，不是遊戲任務時長。

## 開拍依賴與替換原則

所有鏡頭均遵守 [assets.md](assets.md) 的實機來源紀錄、原創品牌與畫質門檻。鏡頭 01–02 用 `real` 手動操作；03 的第三人稱是可選訓練功能，清楚標示，不能當真實機載能力。其餘需記錄實際設定，不將視覺輔助包裝為感測器真值。影片不暗示每台 YX 機型或每個配件都已可玩。

04 若無可重現的 DVL 情境，改拍已完成的感測讀數觀察，但不能宣稱失鎖機制已可玩；06 若量測未交付，四語改為「靠近。穩住。記錄。／Approach. Steady. Record.／靠近。稳住。记录。／近づき、安定させ、記録する。」並只拍攝影。07、08 若第二章未完成則整片仍屬排練稿，不能發布成首版完整展示；不可用後續風場、沉船或海纜替換並保留原承諾。09 須真實結算；所有替換維持時長並四語同步審核。

無線電聲音只能用遊戲內實際播放的版本，AI 語音依 [page.md](page.md) 揭露；無聲版本仍需靠字卡與畫面可讀。配樂若嚴格要求全部素材來自遊戲，使用遊戲已收錄、已核准的曲目剪輯；不能另外塞商用預告片曲庫。`real` 飛行的原始錄音不帶遊戲音樂；預告片配樂是後製音軌，不宣稱駕駛實際聽到它。沿用 [game-plan](../../design/game-plan.md) 的錄音授權限制：公有領域或 CC0；古典作曲公版不代表錄音公版，不採 CC-BY。

## 交付與驗收

交付四語上傳版、無字母版、逐語 SRT、剪輯時間表、原始錄影與授權清冊；片名建議 `ROV Solution — Gameplay`。字卡不得蓋住深度／航向／告警；以 720p 預覽及靜音完整看過。核對前 5 秒已有明確推力修正，80 秒時長、所有功能與實機一致、無快轉／插幀／假 UI、首版章節沒有超額宣稱。Steam 自動產生 microtrailer，另檢查其擷取片段是否讓觀眾誤判視角或玩法。
