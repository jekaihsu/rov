## 主視覺落地與缺檔處理

指定的 `docs/design/key-art/README.md`、`docs/design/palette-631/README.md` 在本次 main 基底不存在（GitHub 亦為 404）；已向擁有者詢問位置。**未完成這兩份文件的閱讀，色票、YX 幾何與機型符號精確造型均未查證，不宣稱已符合其規格。** 此處依任務訊息制定可執行的暫行方向；取得文件後，逐張重核才能交付成圖。

- 「上半實景」解讀為遊戲實機場景，不是現場攝影。優先水池、港灣、養殖場，避免擴大首版範圍。
- 「下半抽象符號」取自遊戲內已實際出現的 YX 與機型符號 UI／材質；不得另畫假 HUD 或讓抽象圖暗示新功能。膠囊可排版裁切這些實機素材，但截圖必須保持單一真實遊戲畫面。
- 名稱四語均維持 **ROV Solution**。品牌為 YX；玩家機型僅用核准的 YX Model R／O／V。Model S 是後段目標，不在首版主圖展示。不要把內部 key 或真實廠牌寫到商店。
- 若遊戲尚未出現合格字標／符號，標為「待遊戲素材落地」；本任務不改程式、不以外部重繪繞過全實機限制。Logo 欄位需透明去背，場景仍保留原始取樣檔及可追溯擷取紀錄。
- `palette-631` 的實際色碼與比例尚未讀到，不從檔名猜成正式 60/30/10。先用遊戲原有冷水體、結構中性色、局部燈光做明暗層次；補齊文件後調整拍攝場景與遊戲選項，不在後製染成遊戲沒有的視覺。
- 不增加售價、折扣、評分、獎章、媒體引句、EA 字樣、Wishlist 或平台圖徽到膠囊；僅遊戲名稱與品牌美術，遵守 [R]。

## 截圖清單（10 張，按建議上傳順序）

全部從候選 Steam 版本拍攝，非工程／內訓版。原生 1920 × 1080 以上、16:9；建議保存 3840 × 2160 原檔，禁止放大低解析素材假裝達標。四語 HUD 分別實際切換語言再拍，不後製翻譯 UI。以下每個場景都須實玩重現；未交付的鏡頭延後拍，不用照片或概念圖代替。

| # | 場景與時刻 | 機位／構圖 | 要呈現的賣點與驗收 |
|---|---|---|---|
| 01 | 第一章港灣，接近樁柱巡檢點 | 機載 FPV，樁柱在右三分之一，視野含通道與原生目標提示 | 第一眼看懂正在巡檢；深度與航向可讀，實際可拍證據 |
| 02 | 序章水池，對準訓練標記 | FPV 正視標記，保留原生操作提示與姿態讀數 | 推力操作練習；不是滿屏按鈕或空藍水 |
| 03 | 第二章養殖網衣破洞檢查 | FPV 斜向網面，破洞及結構邊緣同框 | 細節觀測、距離控制；網衣破洞與碰撞幾何已驗收 |
| 04 | 港樁繞行，纜線受拉 | 玩家可選第三人稱訓練視角；機體、接點、纜線、樁柱同框 | 真實纜線路徑與施力；保留遊戲原有訓練視角標識，不冒充機載觀測 |
| 05 | 港口橫流中維持觀測方向 | FPV 斜看同一固定結構，當前讀數和原生告警同框 | 洋流與可用推力的限制；不後加流向箭頭或誇大流速 |
| 06 | 訓練中感測條件無效的時刻 | FPV；環境仍可見，系統資訊按玩家正常方式展開 | DVL 有效性／失鎖提示與定點限制；不顯示除錯真值或假警報 |
| 07 | 第一章船殼量測／攝影 | FPV 船殼斜面，實際裝備的比例尺與目標同框 | 證據品質；只有已裝備可用量具才入鏡，不疊後製標尺 |
| 08 | 第二章回收作業 | FPV 向下，實際夾爪與回收物同框 | 接近、抓取與回收；若為死魚，採非血腥取景但問卷仍揭露 |
| 09 | 出發前任務簡報與檢查 | 遊戲的核心預潛介面，實際任務目標、設備、檢查狀態可讀 | 程序是玩法一環；不用普通設定選單充數 |
| 10 | 完成港灣任務後交付講評 | 遊戲原生講評／證據介面，選中本次實拍照片與評分 | 結果可交付、評分有依據；不能捏造成績或以概念 UI 代替 |

拍攝阻擋若影響 03／08（第二章）或 09／10（職涯流程），不得用其他場景充數同時保留「首版已有」宣稱。可以先發布已驗收且不同內容的至少 5 張 Coming Soon 截圖，完整素材包仍須補足至少 8 張，首版開賣仍須驗收已定章節。第一批至少四張在核對後標「適合所有年齡」，不能因題材無性內容就全自動勾選。

## 交付與檢查

每張附擷取紀錄：build commit、Steam edition、關卡 ID、seed、鏡頭、遊戲時間、擬真模式、已開輔助、語言、解析度、畫質／實際渲染比例、原檔路徑與裁切／去背步驟。記錄來源與授權，不納入現場照片。實機圖中如含 AI 生成貼圖等，也須在素材清冊記錄，不能因為從遊戲擷取就免除 AI 揭露。

建議檔名 `store_header_tchinese_920x430.png`、`shot_01_english_1920x1080.png`；四語不混在同一張。保留無後製原檔與編輯母檔，實際二進位交付到素材空間，本 PR 僅文件。

逐張核對尺寸、色彩、字標、品牌、章節範圍、透明度、小膠囊縮圖、Hero 安全區及 Logo 視差；在 Steam 預覽檢查四語、桌面與窄視窗。禁止刪除必要告警、去霧、美化照明、合成不同時間的 HUD、修造未完成裝備或隱藏低效能痕跡。
