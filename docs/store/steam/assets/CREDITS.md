# 商店素材來源

截圖與膠囊的攝影來源是本儲存庫的即時遊戲畫面。場址、視角與擷取流程記錄在 [分鏡與重製說明](../../../../simulator/tools/store_shots/README.md)。遊戲內模型、材質、音訊及其授權沿用 [遊戲素材清冊](../../../../simulator/viewer/models/CREDITS.md)。含魚群的畫面可能呈現其中以 AI 預先生成的 CC0 魚類貼圖，發行揭露見 [Steam AI 內容說明](../ai-disclosure.md)。

膠囊名稱、透明字標與聯絡表標籤使用 Noto Sans Bold，© Google，SIL Open Font License 1.1。本次以 Debian fonts-noto-core 的 NotoSans-Bold.ttf 出圖，SHA-256 為 `e83493c945848ecd4a9ad0f6d19164541a0d3e23a9c952304a00a46e00272ac5`。字型以系統套件安裝。[字型來源及授權](https://github.com/notofonts/noto-fonts/blob/main/LICENSE)

成就的 22 個海事符號為本次以 AI 協助撰寫的原創 SVG 向量，識別名稱對應遊戲的 Steam 成就 API。用戶端的捷徑與清單圖示則來自遊戲機庫的 Model R 符號。每對成就圖示共用同一構圖，鎖定版由彩色版轉為灰階。[向量原稿](../../../../simulator/tools/store_shots/symbols.svg)
