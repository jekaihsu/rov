# 截圖與預告片拍攝計畫

以下皆為待拍場景與機位，不是現有素材。不得用概念圖替代商店截圖。畫面使用經審核的 Steam 原創資產；機載第一人稱為主，第三人稱必須確實可在發行版選用。不得用開發相機做成玩家視角的假象。

## 共用開拍門檻

- **H｜HUD**：T04／T16 的全幅畫面、主要遙測、當前目標、警告與速覽卡完成驗收；無左右常駐工程表單、除錯訊息與鍵位溢出。僅使用遊戲內選項改 HUD 密度，不能後製擦掉必要警示。
- **W｜水下畫質**：T07 水體吸收、近距燈光、懸浮物、揚沙、深度光線與畫質效能驗收。美化輔助標示正確，不能用後製去霧偽造能見度。
- **M｜模型**：T11 原創載具、船、海床、生物與結構完工，碰撞／纜線接點吻合，品牌與素材授權審查通過。舊內訓載具即使移除標誌也不能拍。
- **G｜遊玩**：每鏡目標、照片、圖鑑、工程任務與字幕在候選發行版實際可完成；多人鏡頭另需跨機驗收。任務書中的空殼不能拍作既有功能。

所有截圖都等 H/W/M/G；表內列出該鏡最重要的具體依賴。可先用白盒排練位置，但白盒不交付商店。任一依賴延期，就延後該鏡或用已驗收的真實操作替換，不能合成未實作機制。

## 拍攝驗收與存檔

每張／每鏡記錄 build commit、場景 ID、seed、遊戲時間、位置／角度、視角模式、擬真設定、畫質／DPR／ratio、解析度與語言；錄影另記硬體和 FPS。以最終原創場景對照 `harbor_inspection`、`coral_reef`、`wreck_survey` 等現有場景，不直接沿用有真實名稱的資產。正式截圖要從玩家可選畫面擷取，無游標、除錯面板、帳號資訊或品牌殘留。

交付前在 1920×1080 及商店縮圖檢視可讀性，實玩重現所有鏡頭；至少四張標記適合所有年齡（確認內容後才勾），八張均避免血腥與暴力。Steam 官方要求至少五張，本計畫交付八張；若協作未就緒使用表中的單人替代鏡，仍維持八張不同內容。
