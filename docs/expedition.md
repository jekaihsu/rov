# 海洋探索與工程

主選單選擇「海洋探索與工程」，在珊瑚礁、海草床或港灣下潛。
最多三人各開自己的 ROV；一台 Falcon 也可獨自完成全部工程。房主接案，
隊友自由分工。完成或取消不換場景、不重新投放，仍可攝影及接下一項。
其他海域仍可探索攝影，首版工程只開放上述三處。

## 工程操作

- 定點巡檢：接近實際工程標牌，在站點 1.5 m 內以不超過 0.35 m/s 的速度保持三秒，切換機載鏡頭拍到標牌。三站完成即結算。
- 海底物件回收：先以機載鏡頭拍摄物件，再用 Falcon 機械臂夾取，帶到交付區並釋放。物件在交付中心兩公尺內、速度不超過 0.2 m/s 持續兩秒才算交付。
- 觀測儀部署：夾取並運送觀測儀，在指定海床放開並保持穩定兩秒，再用機載相機拍攝部署成果。

回收及部署需有一台在線 Falcon。取物時可用關節姿勢底座 0°、肩部 45°、肘部 −15°、腕部 0°作為起點；仍須把機器移到物件旁並實際張開／閉合夾爪，沒有瞬間拾取。
委託沒有強制倒數；結果記錄參與者、耗時及碰撞，零碰撞為「精準完成」。
已部署設備留在當次海域，達上限時不再接部署案；换場景才重建海域。

## 攝影與圖鑑

「拍攝觀測照」、鍵盤 P 及手柄拍照鍵共用影像擷取流程。原有「下載照片」還會輸出 PNG 與姿態資料。
珊瑚、海星、海草、海藻、魚群五類觀察可登錄個人圖鑑。這些是程序場景中的觀察類別，不是特定物種的鑑定結果。

登錄需機載視角、足夠畫面占比、真實幾何可見與有效距離；泥沙及能見度也影響結果。
相機判斷使用投影、射線和後端姿態校驗，不是像素影像辨識。第三人稱、未通過驗證、離線或確認逾時的照片保留為紀念照。
SDK 本身的合成相機紀錄不能解鎖新圖鑑。

隊伍共享當次發現與位置標記，不傳照片原圖。隊友發現不直接解鎖個人圖鑑；需自己拍攝。
收藏面板可以選封面、下載原圖、匯出或匯入備份。瀏覽器收藏在該網站的 IndexedDB；桌面版收藏在固定 userData/collection，重新啟動換埠號也能讀取。
收藏滿額或保存失敗時會提供原圖下載，不自動刪除既有成果。

## 相容性與介面

新模式 ID 為 `expedition`。既有 `S.mission` 保持空目標探索狀態，新增 `S.expedition` 保存 `dive_id`、`active`、`available`、`discoveries`、`markers`、`results`、`last_observation`。
沿用 operation 封包：`expedition_start`（contract、request_id）、`expedition_cancel`（request_id）、`expedition_mark`（entity_id）、`observation_photo`（photo_id、entity_id、機載相機與可見性資料）。
接案及取消限房主；相同請求可重送，同模式初始化不重置正在進行的下潛。
斷線期間保留席位，逾時釋放攜帶物；房主離開後隊伍接任。伺服器關閉結束當次世界，已保存在個人收藏的成果仍保留。

舊模式與舊回放仍可開啟。新回放保存共享工程狀態；回放觀看本身不解鎖收藏成果。
網際網路主機、帳號雲端存檔、Steam 發行與經濟系統不屬於此版本。
