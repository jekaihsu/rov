# 60/30/10 配色試作

依「兩個主色＋一個意外強調色」規則做的配色，擁有者於 2026-11-15 選定安全橘為強調色，現為預設（`viewer/palette_631.css`、`viewer/palette.js`）。
`?palette=classic` 回到舊的青色配色；`?accent=violet|pink|lime` 可比較其他候選。飛行 HUD 的警示色（綠／黃／紅）不受影響。

| 角色 | 顏色 | 用在哪 |
|---|---|---|
| 主色 60% | 深海藍黑 `#06121C` | 背景、面板 |
| 第二色 30% | 冰白 `#EEF3F0` | 文字、分隔線、次要按鈕外框、焦點框 |
| 強調色 10% | 安全橘 `#FF7A2F`（救生衣、浮標的顏色） | 每個畫面唯一的主要按鈕（開始、下水、下一章）；另有選中分頁底線、目前步驟、載入進度 |

原本的青色 `#4FD1E0` 和海水背景同色系，到處都用（小標、邊線、焦點、分頁），不會把視線帶到按鈕上。
試作把這些全部改回第二色，強調色只留給要被按下去的那顆按鈕。`after-*` 截圖是最初的萊姆綠試作，`accent-*` 是橘、紫、粉三個候選。
