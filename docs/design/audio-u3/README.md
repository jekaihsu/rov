甲板與水下音色是場景混音的假設。港口選的是停靠河輪；海鷗與海浪錄自澳洲海岸。這些錄音沒有經過 X1 實艇聲壓校正。

## 重建

在儲存庫根目錄執行下列指令。工具需要 curl、Python、NumPy、含 libopus 的 FFmpeg（製作版本 7.1.5）。
快取位於 repo 外。腳本核對每個輸入的 SHA-256，擷取片段、混合、把首尾兩秒交疊後旋轉接點，
依 EBU R128 量測整段再施加固定增益至 −23 LUFS，最後檢查每檔與合計的十進位大小。

```sh
python simulator/tools/build_audio_u3.py /tmp/rov-audio-u3
```
