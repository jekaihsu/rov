# 遊戲化方案：ROV 駕駛員的職涯

依據三份研究收斂而成：

- `research_notes/遊戲設計/sim_game_patterns.md`：其他模擬遊戲怎麼做。
- `research_notes/遊戲設計/real_rov_jobs_missions.md`：真實 ROV 工作與 28 關任務表。
- `docs/design/game-audit/README.md`：目前新玩家實際體驗的盤點。

不變的底線（AGENTS.md）：物理與 SDK 不為好玩而改；遊戲化只加在輔助層與呈現層；`real` 預設等同真機。

## 1. 一句話

玩家是一名剛入行的 ROV 駕駛員。從水池考照開始，接港口、養殖場、搜救、離岸風電、海纜的真實委託，
累積時數與聲譽、取得更高等級的執照、添購真實裝備，最後能指揮作業級任務。

## 2. 核心循環

```
委託看板 → 下潛前準備（選裝備、看簡報、檢查） → 下潛作業 → 交付（照片、量測、事件紀錄）
  → 講評與評分（覆蓋度、證據品質、纜線管理、無碰撞、時間）→ 報酬、駕駛時數、聲譽 → 升照、買裝備 → 新委託
```

- **評分以「交付品質」為主，而不是速度。** 參考 PowerWash 的覆蓋度清單：檢查點、照片、量測一項項打勾，同時也就是真實的檢查證據。
- **失敗不卡關。** 可以「中止但仍及格」（低分），立刻重來；獎章（銅／銀／金）是給想精進的人的額外目標。
- **一次只加一個新變數。** 洋流、低能見度、纏纜、DVL 失鎖、通訊中斷、揚沙、夜間、多機協作，逐關引入。

## 3. 成長：執照階梯（虛構發證機構）

真實業界：Trainee → Junior → Pilot/Tech Grade II → Grade I／Senior → Supervisor，升級要求駕駛時數與出海天數。
IMCA 本身不發證，也不得在能力證書上使用其標誌，因此遊戲中由虛構機構發照。

| 執照 | 解鎖的工作 | 考照 |
|---|---|---|
| 見習駕駛員 | 水池、港內簡單檢查 | 序章結業 |
| 二級駕駛員 | 船殼、碼頭、養殖場 | 第一章結業考 |
| 一級駕駛員 | 搜救、水庫、離岸風電 | 第三章結業考 |
| 資深駕駛員 | 海纜、夜間、多機 | 第四章結業考 |
| 主管 | 作業級任務的監看與指揮 | 第五章結業考 |

- **執照只解鎖工作類型，不讓操控變強。**
- **考照一律強制 `real`。** 開著輔助飛的時數另外記，不算進考照。

## 4. 經濟與商城

- **一種貨幣**：委託報酬。前期報酬要夠買第一件裝備，避免「前期太窮只能磨」。
- **商城只賣真實存在的裝備**：雷射比例尺、夾爪、影像聲納、陰極保護探針、測厚儀、DVL、USBL、更亮的燈。裝備只解鎖「能做什麼」，不改物理數值。
- **外觀**：貼紙、塗裝、公司標誌。
- **不做**：數值提升、真錢商城。

## 5. 職涯章節（28 關，詳見研究報告 §6）

| 章 | 主題 | 新技能／變數 | 需要的新場景 |
|---|---|---|---|
| 序章 | 水池考照 | 基本操控、纜線 | 沿用 |
| 一 | 港口與船舶 | 檢查路線、海生物量測、船殼附著評級 | 沿用港灣、船殼 |
| 二 | 養殖場 | 網衣破洞、死魚回收（夾爪） | **養殖箱網** |
| 三 | 公共服務 | 聲納搜尋、零能見度、進水口 | **水庫進水口、泥湖** |
| 四 | 離岸風電 | 平潮窗口、陽極、沖刷、電纜入口 | **單樁套件（沖刷坑、保護套管）** |
| 五 | 海纜 | 沿纜巡線、事件紀錄 | **海纜（埋設／裸露／懸空）** |
| 六 | 進階與作業級 | 監看 ROV、作業級 | 視需要 |

切纜、修復、埋設是作業級 ROV 的工作，放在第六章，屬於生涯後段的目標。觀測級在風場與海纜的工作
（巡線、保護套管、沖刷調查）是真實存在的，放在第四、五章。搜尋遺體類任務改用證物或訓練假人。

## 6. 第一印象（前 10 分鐘）必修

依盤點的嚴重度排序：

1. **全繁中、無內部字串**：飛行畫面的英文與內部名稱改為玩家語言；長期支援多語（T09）。
2. **一下水就有東西看**：出生點靠近海床或目標；定深預設開；輔助「未生效」要說明原因（DVL 超出範圍）。
3. **鍵盤預設照遊戲習慣**：W/S 前後、Space/C 升降、A/D 平移、Q/E 轉向；按鍵表以動作命名；支援鍵盤重綁。
4. **任務有結尾**：結算畫面（評分、獎章、報酬、下一步），章節獎勵看得見；Steam 成就實際觸發。
5. **不露出開發畫面**：連線面板閃現、手輸 `ws://`、AI 除錯字、「暫定，待實測」都不出現在玩家路徑。
6. **HUD 不重疊**；自由探索不顯示時限與目標；新手清單與委託不藏在工程抽屜。
7. **回饋**：拍照有快門與閃光、有音樂、手把震動擴充。
8. **設定補齊**：語言、FOV、顯示模式與解析度、亮度、介面縮放、色盲、單位、按鍵重綁、動態舒適、幀率上限。

## 7. 介面與美術方向

- 主選單背景改用最好看的場景（下水動畫是目前的視覺標竿）。
- 選單、圖鑑、委託看板、結算統一同一套視覺語言（HUD 方向 A 的線條、半透明）。
- 章節與委託卡片要有圖、描述、獎章與最佳成績。
- 品牌：介面不顯示真實廠商機型名與真實沉船名；機型以原創名稱呈現（現有內部 key 不變）。

## 8. 分期

| 期 | 內容 | 負責 |
|---|---|---|
| P0 第一印象 | §6 全部 | 內部代理（進行中） |
| P1 職涯骨架 | 委託看板、結算、執照、貨幣、商城、存檔、成就串接；序章到第一章改寫成委託 | 內部代理 |
| P2 內容 | 第二～五章的關卡與新場景 | 關卡由內部代理；場景建模外派（Blender／GPT） |
| P3 包裝 | 音樂、多語、Steam 頁面與宣傳素材、照片模式 | 外派＋擁有者 |

## 9. 擁有者決定（2026-11-15）

- **遊戲名稱**：ROV Solution。
- **發照機構**：YX；**玩家所屬公司**：YX。
- **調性**：寫實職場，帶一點輕鬆。作業程序、術語、評分照真實；無線電、委託方與同事台詞有人味與職場幽默，不搞笑。
- **音樂**：先用網路上可公開使用的素材，古典與輕鬆兩種。錄音本身須為公有領域或 CC0（作曲公有領域不代表錄音可用）；CC-BY 等不在授權白名單內，不採用。
  飛行中的音樂真機聽不到，註冊為擬真項目 `diveMusic`（`real` 關）；選單與結算音樂為一般偏好。

## 10. 機型命名與第一版範圍（2026-11-15 擁有者同意）

**YX 機隊**（命名風格：短型號＋藏梗＋迭代編號；只改玩家看到的名稱，內部 key、存檔、協定、SDK 不變）：

| 對外名稱 | 內部 key | 定位 |
|---|---|---|
| YX Model R | `x1` | 入門觀測型，第一台機 |
| YX Model O | `bluerov2_heavy` | 重載觀測型，推力大、可掛較多配件 |
| YX Model V | `falcon` | 輕作業型，有機械臂 |
| YX Model S | （新，作業級） | 生涯後段解鎖 |

- R、O、V 三台拼成「ROV」，加上 S 為「ROV S」，暗藏遊戲名 ROV Solution。
- 機體迭代：裝備升級後顯示「YX Model R · Block 2／3」。裝備只解鎖能力，不改物理。
- 沉船 Korean Castle 改為虛構船名「碧海號」。

**第一版範圍**：序章＋第一～二章（約 10 關），以 Steam 搶先體驗推出。

## 11. 擁有者訪談結論（2026-11-15）

| 題目 | 決定 |
|---|---|
| 目標玩家 | **硬核擬真玩家**（DCS、微軟飛行那一群）。難與真是賣點。 |
| 預設難度 | **預設真實**。另有較容易的模式；在**開新遊戲時**以全螢幕畫面選擇（簡單／標準／真實，各附說明與實際畫面預覽），之後可在設定更改。 |
| 任務長度 | **15–25 分鐘一關**：準備、下潛、作業、回收的完整流程，不拖。 |
| 驚喜 | **突發事故與救援**＋**角色與公司故事**，全部寫實（只用真實會發生的事：纏纜、失聯、趕工、客戶刁難），不加奇幻或誇張戲劇。 |
| 故事比重 | 平常在簡報、無線電、結算評語裡；**每章一個有演出的大事件**（真的事故、緊急搜救、大客戶考驗），有鏡頭與配樂。 |
| 配音 | **AI 語音合成**做無線電配音（加無線電失真）；需確認所用服務的商用授權。 |
| 失敗代價 | **要賠錢修設備**、聲譽下降；不會破產卡死（公司墊付）。 |
| 畫面風格 | **寫實但好看**：物理與光學是真的，但挑漂亮的時刻與地點；像紀錄片，不像監視器畫面。 |
| 介面 | **賽車／飛行模擬的大片感**（Forza、Gran Turismo、微軟飛行）：全螢幕實景、大標題、橫向大圖，少邊框與格子。現有的卡片式畫面要重做。 |
| 選單場景 | **在工作船上**：控制室螢幕接委託、甲板上看 ROV 與裝備、船艙看日誌；鏡頭在這幾個點之間移動。 |
| 飛行畫面 | **乾淨的遊戲 HUD**：最少資訊、線條與數字，目標與提示需要時才淡入。 |
| 配色 | 60/30/10：深海藍黑、冰白、**安全橘**只給主要按鈕。 |
| 多人 | 保留現有功能，不再加強。 |
| 語言 | 第一版：**繁體中文、英文、簡體中文、日文**。 |
| 長期玩法 | 職涯之後有**隨機生成的委託**。 |

### 對既有方案的影響
- §3 考照強制真實不變；但 Steam 版預設也改為真實（原方案是預設輔助）。`fidelity.js` 的版本預設要跟著改，並新增「標準」這一檔（介於簡單與真實之間）。
- §2 的「失敗不卡關」保留，但加入維修費與聲譽懲罰。
- §7 介面方向改為大片感＋工作船場景；P0 做的卡片式章節／委託清單屬過渡，P1 之後重做。
- 多語（T09）從 P3 提前：四種語言是第一版必備，所有新畫面的字串都要可翻譯。
- 新增工作項目：工作船內部場景（控制室、甲板、船艙）建模；AI 配音管線；隨機委託產生器；每章大事件的演出。
