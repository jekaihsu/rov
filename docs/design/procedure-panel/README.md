# 潛前檢查與回收：從擋路的面板改成低調的檢查欄

擁有者試玩回報：右側的「潛前檢查與回收」面板「非常非常擋路」。原本是 440 px 寬、不透明（.92）、青色框線、
最高 76vh 的方框，固定在畫面右側，而且**整趟潛航都不會消失**（只剩標題、說明、作業紀錄與一顆「收纜回收」）；
在甲板上還蓋住工作船與 A 字架的下水畫面。青色框線也不在 60/30/10 配色內。

只改呈現層：伺服器的流程、閘門（`simulator/qysim/procedure.py`）、協定與 `deployProcedure` 擬真設定的語意都沒有動。

## 現在的樣子

| 階段 | 呈現 |
|---|---|
| 甲板（檢查、下水、入水確認） | 左下一欄，只有漸層壓暗、沒有框；小分類行加進度（「潛前檢查 3 / 10」），目前項目是大標題，完成的項目只留計數；一顆橘色主要按鈕，「跳過」是純文字次要按鈕。推進器短測是一排數字，測過的變橘色 |
| 潛航中 | **畫面上什麼都不留。** 收纜回收移到暫停選單（Esc／長按 Menu）的「目前目標」下方；還沒浮上水面或還沒上鎖時，項目會寫「收纜回收 · 先浮上水面／先上鎖」並停用。真的下潛過（> 2 m）又回到 0.8 m 內時，畫面中上方出現一行約 7 秒的提示；略過檢查導致故障時也用同一行提示 |
| 回收中、潛後（沖洗、檢查、日誌、完成） | 同一欄，可以稍寬（34vw）；加上四個大數字（作業時間、最大深度、最大纜長、扣分）與日誌欄 |

- 欄寬 32vw（潛後 34vw），內容不進入畫面中間三分之一。欄位顯示時，左下的小地圖、深度尺與 OSD 左下角文字暫時讓位；
  上方的深度、航向不受影響。
- 鍵盤與手把：選單情境的上下左右移動焦點，Enter、Space 或手把 A 確認。主要按鈕在每一步之後自動保持焦點，所以連按確認就能
  走完檢查；焦點不會自動落到「跳過」。沒有可按的東西時（收纜中）不攔截輸入。
- 「短測為模擬診斷…」與「暫定，待實測」的工程說明不在玩家畫面上，只留在分類行的滑鼠提示（game-plan §6 第 5 點）。
- 樣式在 `simulator/viewer/procedure/procedure.css`，用配色變數（`--color-main`／`--color-second`／`--color-accent`）與
  `--z-controls`、`--z-notice`，沒有寫死的顏色與 z-index。
