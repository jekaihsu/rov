## 拍攝條件

基底為 `ad62e04`。從獨立的遊戲房間載入 seed 42，使用預設 Model R、1600×900、DPR 1、中畫質、機載鏡頭、real、燈關。兩個版本各用自己的伺服器、物理與 viewer。等候載具自行漂移、上浮，每個房間都不送操作輸入。拍攝工具在伺服器時間達 12 秒時保留第一筆遙測（本次各圖為 12.00–12.04 s），讓軟體渲染與 JPEG 擷取延遲不會改變構圖。開場標竿取自演出段落，保留原有燈光。

```sh
ROV_HTTP_PORT=8080 ROV_WS_PORT=8765 python simulator/tools/browser_spawn_looks.py
ROV_HTTP_PORT=8081 ROV_WS_PORT=8766 ROV_LOOKS_TAG=before python simulator/tools/browser_spawn_looks.py
```

## 光學與構圖依據

倒敘建立鏡頭中，近處的載具、腿柱與遠處的魚群互相遮擋。一般作業鏡頭保留 HUD 與實際視線，靠近、中、遠物件之間的重疊提供尺度。開放水域採情境既有的選填 `water_type` 指定外洋水，並在投放工作船附近配置魚群。港口的投放點沿樁外側加深，朝向考慮了鎖定推進器時的橫向漂移。

上一版陸棚水把剩餘消光的 94% 分配給散射，且將日光散射 RGB 權重設為 (0.34, 1, 0.68)。本次採 92% 散射占比及 (0.38, 0.46, 1) 權重。具色選性的顆粒吸收以 0.025 m⁻¹ 為界，其餘採中性礦物吸收，綠光水平消光仍由能見度決定。暗處的全額曝光補償會把綠色殘光放大。前次測光在沉船深水鏡位確實達到 12800 上限。此次關燈補償固定為 82%，增益上限從 12800 降到 800，下降四級曝光。對混濁陸棚，假設上覆水柱比近底水平光路清澈，平均非純水消光最多 0.5 m⁻¹。增益 400 到 800 的最後一級逐漸降低色度，最高混入 55% 等亮度灰階，以模擬暗處的色度降噪。此假設、水色權重與感測器增益均待實測。[參考資料](../../reference/real-rov-research.md)

## 布局限制

船殼與沉船的投放點均還原為 N/E/D (0, 0, 3) m。船殼場景的機體在 12 秒時為 2.40 m 深。貨輪外殼距起點約 16 m，最近舭龍骨約 39 m，能見度 7 m。沉船場景的機體在 12 秒時為 2.47 m 深，全幅平均 RGB 為 (79, 115, 147)。沉船距離場的包圍盒頂部位於 18.4 m 深處，能見度 4 m。即使往主體移動允許的 3 m，仍隔著數個能見距離。從上述位置拍攝的影像與飛到近處觀察的畫面必須分開判讀。

港口、網箱與泳池的位移均以 main 為基準限制在 3 m 內。`test_scene_launch.py` 檢查位移、任務點座標、纜盤與纜長。

舊版使用固定初始姿態的重播。當時的曝光、像素分布與效能數字可在前次審查版本查閱。[前次量測與拍攝方法](https://github.com/jekaihsu/rov/blob/3e3c92e9a916a437d9bd252ddfa0bdc7960c1e73/docs/design/scene-look-v1/README.md)
