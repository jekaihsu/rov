# 前端視覺與互動方向

所有前端任務（T02–T07、T09）以此為準。目標：打開就像一款 Steam 上的模擬遊戲，而不是後台管理頁。

## 真實性優先

依 `docs/reference/real-rov-research.md`：真實駕駛是純第一人稱，只靠一支受限的鏡頭與聲納建立空間感。因此：

- **機載第一人稱是主要視角**，HUD 以它為準設計；第三人稱是訓練輔助，可在真實模式中停用。
- 機載畫面的疊字依真機 App 的慣例（待 X1 截圖補齊前，以研究報告中 V6 世代的配置為暫定參考）。
- 研究顯示同類遊戲被批評的是「到處都是按鈕」與上手負擔，不是寫實本身。寫實與精簡不衝突。

## 現況的問題（2026-11 截圖審視）

- 遊戲畫面被左右兩欄表單夾住，3D 視窗只佔約六成，四周還有圓角邊框。看起來是儀表板，不是駕駛艙。
- 兩欄同時顯示任務、洋流剖面、推進器條、纜線按鈕、系統訊息。資訊沒有主次，飛行時真正要看的深度、航向、速度反而很小。
- 主選單是一長串下拉選單與說明小字，需要捲動才看得完。
- 畫面中央永遠浮著兩顆虛擬搖桿，接了手把也不消失。
- 沒有任何聲音、轉場與回饋動效。

## 參考對象與取用的原則

只取設計原則，不複製任何一款遊戲的版面、圖示、配色或名稱。

| 參考類型 | 取用的原則 |
|---|---|
| 消費級空拍機的飛行 App 與官方飛行模擬器 | 畫面全幅；遙測只留一條底部資訊帶；模式切換一眼可見；警告用顏色與位置分級 |
| 大型民航飛行模擬器的主選單 | 以世界／載具的即時 3D 畫面為主角；選項用大卡片；手把可完整操作選單 |
| 穿越機競速模擬器 | 手感設定頁：曲線即時預覽、死區與靈敏度滑桿、推桿時曲線上的點跟著動 |
| 水下探索生存遊戲 | 深度決定色調與能見度；光束、懸浮微粒、焦散；聲音隨深度變悶；介面有「儀器感」 |
| 賽車模擬的車庫與賽前畫面 | 載具展示轉台、規格以少量大數字呈現、進場轉場乾淨 |
| 真實 ROV 駕駛軟體（開源地面站類） | 航向帶、深度尺、姿態指示、纜線與障礙距離的呈現方式；內部訓練版保留完整工程面板 |

## 版面

- **3D 全幅**，無邊框。所有介面是疊在上面的 HUD。
- **飛行 HUD（預設）** 只有：
  - 上緣中央：航向帶（羅盤條）。
  - 左緣：深度尺與離底高度。右緣：姿態與俯仰梯（小）。
  - 下緣中央：速度、纜線已放長度／張力狀態、電量。左下：小地圖（俯視，含纜線走向與隊友）。
  - 右上：模式膠囊（輔助等級、飛行檔位、定深、燈光、鎖定）。
  - 上緣左側：任務目前一步與進度，一行。
  - 警告：中央偏上，分三級（提示／注意／危險），危險級伴隨畫面邊緣色暈與震動。
- **預設收起，按了才短暫跳出（peek）**：飛行時畫面上只有上面這幾樣。其餘資訊分成四張「速覽卡」，由手把十字鍵呼出：
  - 上：任務與目標清單。左：載具系統（推進器、纜線、電量、損傷）。右：放大地圖與隊友。下：目前鍵位提示。
  - 按一下顯示約 3 秒後自動淡出；按住則持續顯示，放開即收。再按同方向立即收起。鍵盤對應 1–4。
  - 相關事件發生時對應的卡自動跳出一次（例如纜線張力升高時跳出系統卡並標出該項），不需要玩家去找。
  - 速覽卡不搶輸入焦點，飛行操控不中斷。
- **工程面板**（現有兩欄的全部內容）收進一個可呼出的側抽屜，預設關閉；鍵盤 Tab／手把 View 鍵長按切換。內部訓練與 SDK 開發照常使用。
- **虛擬搖桿**只在觸控裝置顯示。偵測到手把或鍵盤輸入後隱藏。
- 16:9 與 21:9 都要正確；最小支援 1280×720。安全邊距 4%。
- **選單、暫停與結算採「大片感」版面**（擁有者 2026-11-15 核准，`docs/design/big-picture/README.md`）：全幅遊戲場景、
  一個大標題、三個大數字、一顆橘色主要按鈕、右下圖磚列；不用細線與半透明加框面板，細節收在「明細」。
  下面「視覺語彙」的細線與半透明面板只適用於飛行 HUD。

## 視覺語彙

```css
:root {
  --bg-0: #04090d;      /* 最深背景 */
  --panel: rgba(8, 18, 26, 0.62);   /* HUD 面板，搭配 backdrop-filter: blur(14px) */
  --line: rgba(160, 205, 225, 0.18);
  --text: #e8f1f5;
  --text-dim: #8fa6b2;
  --accent: #4fd1e0;    /* 主要強調：青 */
  --go: #5fd38a;        /* 正常 */
  --warn: #f2b84b;      /* 注意 */
  --danger: #ff5a52;    /* 危險 */
  --radius: 10px;
  --space: 8px;         /* 間距以 8 的倍數 */
}
```

- 字體：介面 `Inter`／系統無襯線；數字一律等寬數字（`font-variant-numeric: tabular-nums`），避免跳動。中文退回系統黑體。
- 數字大、標籤小：主要讀數 28–36 px，標籤 11 px 大寫加字距。
- 面板用半透明加模糊，不用實心色塊與粗邊框。同一畫面最多一個實心強調色按鈕。
- 圖示用單線風格的 SVG，集中在一個 sprite 檔，不用 emoji。

## 動效與回饋

- 所有讀數以 60 fps 平滑插值，不逐格跳字。
- 面板進出 160–220 ms，ease-out。尊重 `prefers-reduced-motion`。
- 每個重要操作都有三重回饋：畫面、聲音、手把震動（解鎖、定深、拍照成功、碰撞、纜線張力警告）。

## 手把優先

- 所有選單與設定都能只用手把完成：方向鍵／左搖桿移動焦點，A 確認，B 返回，LB／RB 切分頁。
- 焦點框清楚可見。按鍵提示依目前裝置顯示對應圖示（Xbox、PlayStation、Switch、通用、鍵盤）。
- 最後使用的輸入裝置決定提示圖示，切換時即時更新。

## 驗收方式

每個前端 PR 附 1600×900 的前後截圖。審查時問三個問題：

1. 只看一眼，能不能讀到深度、航向、速度？
2. 不碰滑鼠，能不能從主選單一路進到水裡？
3. 把截圖放在 Steam 商店頁上，像不像一款遊戲？
