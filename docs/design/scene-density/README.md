# 水下調查航線的空鏡頭比例

每個情境從原版出生點出發，每五秒取一張機載影像，從 5 秒到 60 秒，共 12 張。以下聯絡表上下兩列是同一段飛行的前後對照。每列的連結可開啟 1600 × 900 原圖。

判讀時只看水中實景。能辨認樁、浮具、船、殘骸、生物或地形輪廓，就記為有主體；只剩水色、平底、燈斑、微粒、任務環或自己的臍帶纜，就記為空鏡。以空鏡張數除以 12，每個場景最多容許一張空鏡。短程回收路線停在船邊後，仍保留剩餘的定時影格，因此部分後段影像相似。

**21 個情境全數達到每條航線空鏡 ≤ 10% 的目標。** 全部 252 個取樣點合計由 77 張（30.6%）降至 3 張（1.2%）。下表比例後附空鏡出現的秒數。點選場景名稱可檢視聯絡表。

## 重拍條件

- 基準版為 `bea1953`，所有場景固定 seed 42。包含三種養殖情境、五個事故演練、風場開場及隨機場景；略過室內教學池。
- 以原版伺服器的 0.01 秒物理步長駕駛，每 0.1 秒更新推桿，每秒保存遙測。導管架由外側切入 A、B 陽極巡檢點。船底航線避開艉舵後，機體仰俯約 27° 朝上巡檢。箱網內側向下看回收作業點。聲納搜尋進入原目標的目視確認距離後定點。
- 前後使用同一份位置、姿態、燈檔、纜線及濁度資料。各版本魚群從該版棲點出發，沿錄下的 ROV 動線演進。兩次都用真實模式、performance 畫質、機載鏡頭、一檔燈；移開 DOM 疊圖以看清光學影像。場景原有的立體任務環仍可見。
- `routes/` 記錄播放時間、遲延後的影像時間、NED 位置與姿態。工具逐格比對前後紀錄。箱網外側的纜線在繞行中會被網片勾住，後段影像留在同一扇網附近。這組結果描述指定航線與種子。玩家轉向空水、關燈或實際揚沙時，仍可能失去目視參照。

在儲存庫根目錄執行下列命令。重拍用的是已錄好的遙測，兩個本機 HTTP 服務各自提供對應版本的 viewer。

```bash
baseline=../rov-before
git worktree add --detach "$baseline" bea1953
serve='from qysim.server import start_static; import sys, threading; start_static(int(sys.argv[1]), "127.0.0.1"); threading.Event().wait()'
PYTHONPATH="$baseline/simulator" python -c "$serve" 8080 &
before_pid=$!
PYTHONPATH=simulator python -c "$serve" 8081 &
after_pid=$!
driver=simulator/tools/capture_scene_density.py
cache=/tmp/rov-density-replay
PYTHONPATH="$baseline/simulator" python "$driver" record --cache "$cache"
ROV_HTTP_PORT=8080 PYTHONPATH="$baseline/simulator" python "$driver" before --cache "$cache"
ROV_HTTP_PORT=8081 PYTHONPATH=simulator python "$driver" after --cache "$cache"
PYTHONPATH=simulator python "$driver" sheets --cache "$cache"
kill "$before_pid" "$after_pid"
```

## 調查細節

每個海域配置 18 個可近拍的採樣點。附著物朝向主機表面的外法線，遠處不建立細節批次。拍攝時沿用機載鏡頭的遮蔽、解析度與能見度檢查；主機核可後，原圖留在收藏中。同一種類在不同樁位或不同種子的發現，各有自己的海域紀錄。

港邊的玻璃、陶片與纜繩殘段分布在樁腳和港底，樁面可見測站編號及附著群。沉船的斷肋、鋼板和散落件延伸到船體以外。礁區的岩拱可以穿過，海草場的岩脊露出草冠。風場的水平線保持開闊，箱網外圈可見遮蔽海灣。布置及光學參數為虛構場址的設計假設，素材來源見 [模型授權紀錄](../../../simulator/viewer/models/CREDITS.md)。

另用 medium 畫質停在相同時間、相同機位切換既有的水下美化。海草床第 35 秒在 6 公尺深，關閉時仍看得到石峰和沙地。沉船事故第 25 秒位於 128 公尺深，兩種設定下都由機燈照出鋼材本色、蛇尾與藤壺。[查看光照開關對照](lighting-medium.jpg)
