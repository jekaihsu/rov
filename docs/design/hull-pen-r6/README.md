## 尺度與碰撞

遊戲中的沿岸貨輪沿用任務的長 80 m、寬 18 m、吃水 8 m。公開散貨船試驗船型的滿載軸心沉深相當於吃水的 0.69 倍，本場景為 5.56 / 8 ≈ 0.70。船艉開口、平底與舭部均由伺服器船形定義。格柵背板、鋅塊與水尺位於船殼表面，四片槳葉各自的 17 個弦向截面同時定義可見葉面與碰撞外形。水尺數值自龍骨向上量起。焊道間距、塗層損耗與附著分布是巡檢呈現假設。[公開試驗船型數據](https://www.t2015.nmri.go.jp/jbc_gc.html)

網箱直徑 36 m、網深 16 m。新增的 24 支橫向托架與扶手柱同站，伺服器與畫面共用幾何參數。網衣在側邊繩、浮管及沉子環間受流鼓起，單一水平座標的最大位移為 3.5 cm。兩處破洞仍可通行及拍照。活魚沿用伺服器的八個魚群中心，載入 kit 魚模，載入前使用長度約 0.58 m 的鮭形替身，三個畫質檔分別繪製 96、768、960 尾。魚體尺寸及視覺密度皆為訓練假設。

## 重拍

從要拍攝的版本啟動模擬器。在相同版本的 simulator/tools 放入本分支的 capture_hull_pen_r6.py，讓回放資料與網頁使用同一份程式。拍攝工具內的 STATIONS 記錄各鏡位的公尺座標與注視點。

```bash
cd simulator
python -m qysim.server --http-port 8092 --ws-port 8792
# 第二個終端機，同一目錄；退回版本用 before，修訂版用 after
ROV_HTTP_PORT=8092 python tools/capture_hull_pen_r6.py after
```

### 審查後的槳形

日本散貨船試驗船型的 MP687 是五葉定螺距槳。公開表列直徑 203 mm、轂徑比 0.18、螺距比 0.75、最大弦長比 0.2262、展開面積比 0.50、後傾 5°。場景沿用四葉碰撞配置及 4.48 m 外徑。各半徑的展開弦長取自 MP687，再乘 5/4 以分配到四葉，最大弦長約 1.26 m。截面角由局部半徑與固定螺距推算。錐形轂最大直徑 0.84 m，葉尖側斜 20° 是本船的外觀假設。[NMRI MP687 原始徑向截面表](https://www.t2015.nmri.go.jp/file/Geometry_IGES_files/jbc/MP687_particulars.zip)

## 巡檢照片與發現

船殼有 16 個新增觀測對象：水線與舭部的七簇藤壺、格柵內三尾小魚、三處船底刮痕、兩個海床卸扣及進場魚群。網箱有 14 個：四處繫泊纜海藻、六處網衣海藻、三堆沉積飼料及一群野生竹筴魚。拍照時沿用機載相機的構圖與遮擋檢查，伺服器確認場景對象後以實體 ID 記錄照片，同類照片可共用一張圖鑑封面。

完整側網的 U 座標沿網寬變化，垂直網目座標由深度取得；側網 V 僅編碼到撕裂邊緣的距離。完整網片將 V 固定在磨損帶之外。網底由法線辨認，使用兩個平面座標。4 m 內解析菱形網目，4–9 m 逐漸混入遠景透明材質。破網上下片使用場景欄位 `torn_edge`。洋流停止或流場失效時網片回到靜止位置。

出生路線從 0 秒拍到 30 秒，每 5 秒取一張，共 14 張機載影格。腳本用同一組 NED 航點與朝向建立兩個版本的回放，確保移動速度與取樣角度一致。原圖在 [route-before](route-before/) 與 [route-after](route-after/)。

```bash
cd simulator
ROV_HTTP_PORT=8092 python tools/capture_inspection_route.py ../docs/design/hull-pen-r6/route-after
```

### 空鏡頭逐張判讀

用原尺寸檢查每張畫面。能指出魚、附著物、破網、可辨識的艉部配件或局部漆損即列為有巡檢對象。只有水、懸浮粒子、纜線或沒有局部特徵的均勻表面列為空鏡頭。這是兩條固定路線的目視判讀。
