## 尺度與碰撞

遊戲中的沿岸貨輪沿用任務的長 80 m、寬 18 m、吃水 8 m。公開散貨船試驗船型的滿載軸心沉深相當於吃水的 0.69 倍，本場景為 5.56 / 8 ≈ 0.70。船艉開口、平底與舭部均由伺服器船形定義。格柵背板、鋅塊與水尺位於船殼表面，螺槳沿四組葉緣碰撞包絡建模。水尺數值自龍骨向上量起。焊道間距、塗層損耗與附著分布是巡檢呈現假設。[公開試驗船型數據](https://www.t2015.nmri.go.jp/jbc_gc.html)

網箱直徑 36 m、網深 16 m。新增的 24 支橫向托架與扶手柱同站，伺服器與畫面共用幾何參數。網衣在側邊繩、浮管及沉子環間受流鼓起，單一水平座標的最大位移為 3.5 cm。兩處破洞仍可通行及拍照。活魚沿用伺服器的八個魚群中心，使用長度約 0.58 m 的鮭形魚體，三個畫質檔分別繪製 96、768、960 尾。魚體尺寸及視覺密度皆為訓練假設。

## 重拍

從要拍攝的版本啟動模擬器。在相同版本的 simulator/tools 放入本分支的 capture_hull_pen_r6.py，讓回放資料與網頁使用同一份程式。拍攝工具內的 STATIONS 記錄各鏡位的公尺座標與注視點。

```bash
cd simulator
python -m qysim.server --http-port 8092 --ws-port 8792
# 第二個終端機，同一目錄；主分支用 before，R6 用 after
ROV_HTTP_PORT=8092 python tools/capture_hull_pen_r6.py after
```
