# 第四章 · 紙上的斷點

九月的礫環海峽。第一班把岸側斷端、拖痕與海側外皮交給修復班判讀，再到吊索外側報位。第二班回到前班照片裡的岩面，記錄旁邊的灰色外殼。修纜船負責吊重。甲板失準期間，報告用岩面的相對位置。兩關分別由谷弦、林岑簽收。

## 場景尺寸

公開資料所列海底通信纜外徑約 17–50 mm（約 2–5 cm，隨鎧裝而異）。本工單指定的近岸重鎧裝外徑取 10 cm，屬遊戲設定。建模、接觸與工單比例基準均使用同一外徑；破口露出的內層直徑為 3.6 cm。分段保護管與接續套另外建模。朝岸側的纜線在保護管下入土，作業畫面呈現登陸路由的水下部分。[ICPC 提交 IHO 的尺度資料](https://iho.int/uploads/user/Services%20and%20Standards/HSSC/HSSC15/HSSC15_2023_07.10A_EN_ICPC_report.pdf)

海床用 0.6 m 網格取樣。兩側泥脊夾著約 20 m 長的拖痕，斷面各有十二股外翻的鋼線。回收繩從修纜船舷側垂下。兩次部署共用海床、障礙物及局部北東下座標。水深約 13 m、流況、可見度、溝深、鋼線數與勾纏保持力均為虛構工區假設。[#83 原稿](https://github.com/jekaihsu/rov/pull/83)

## 遊玩與交件

在劇情選單選「第四章｜兩頁底片」，下一張工單為「第四章｜框外」。在 K3 的職涯節點接上前，前置存檔使用現有主線的 `finale`。`c4_sheets.requires` 是前章插入點。`c4_frame` 末段 `receipt → night → done` 是 K2 章末剪輯接點。進入夜班段會發送一次文件事件 `rov-chapter-handover`，隨附當班證據報告。水下練習也可單獨載入 `cable_repair` 或 `cable_perimeter`。

快門需要距離、朝向與未受遮蔽的視線。第一班將岸側斷面與犁溝同框，再取另一端近照。齊備後以兩端三維位置算端距；工單外徑另列為照片比例依據。第二班的灰殼與岩面需同時可見。報告記錄照片檔名、模擬時間、深度、量測與甲板定位異常的起訖。原片保存在本機收藏；重新部署後仍可在職涯結算紀錄找到當班快照。
