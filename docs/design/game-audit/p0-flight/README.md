# P0 第一印象・飛行中：前後截圖

`before-*` 是 `b71da8b`（任務開始前），`after-*` 是 `p0/flight` 完成後。同一個擷取腳本、乾淨 localStorage、
SwiftShader 軟體繪圖、`quality=performance`，每個畫面各有 1600×900 與 1280×720（速覽卡與拍照只有 1600×900）。
輔助模式以 `?fidelity=assisted` 模擬 Steam 預設。

| 檔名 | 狀態 | 看什麼 |
|---|---|---|
| `assisted-first` | 珊瑚礁自由探索，輔助，略過下水動畫，進場 4 s | 前：離底 11 m 空藍；後：從第一個作業點前方開始，珊瑚在畫面內、定深已開 |
| `assisted-fly` | 同上，解鎖後按 W 2 s | 前：W 是俯仰；後：遊戲鍵位 W 前進、T 解鎖、定點中 |
| `real-first` | 珊瑚礁，真實模式，含完整下水流程 | 前：水下 2.9 m 卻要做潛前檢查；後：載具在工作船後甲板，檢查完才吊放 |
| `real-dive` | 真實模式，略過流程 | OSD：`馬達鎖定 · 按 SPACE 解鎖`；系統膠囊不再壓住場景名稱 |
| `story`、`story-task` | 序章，輔助 | 無線電移到航向帶下方；解鎖步驟鍵帽不再壓字、手柄→手把 |
| `scenario` | 開放水域場景訓練，輔助 | 從檢查點 1 前方開始；右上狀態不再疊字 |
| `chase` | 追蹤視角 | 不再畫機載十字與俯仰梯 |
| `keys` | 長按 4 鍵位速覽卡 | 以動作命名（前進／後退 W / S…），不顯示 ROV_USA |
| `photo` | 按 P 後約 1.4 s | `已拍照` 提示；AI 除錯列已隱藏 |
| `after-keyboard-rebind` | F8 → 鍵盤按鍵 | 改鍵（拍照改 Z）與重複按鍵被拒絕的提示 |
