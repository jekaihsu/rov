# 潛前檢查（甲板版）截圖

擁有者回饋：舊版十項檢查只是「讀一句話、按確認」，畫面沒有任何反應，也不會真的發現問題。
新版只保留真的有動作、看得到反應的檢查，例行項目改由船員以無線電回報，並在生涯／訓練情境中有時藏一個真實瑕疵。

截圖由 `simulator/tools/browser_predive_shots.py` 產生（1600×900，預設載具，真實模式，軟體算圖）：

| 檔案 | 步驟 | 畫面上發生的事 |
|---|---|---|
| `01-deck.jpg` | 開場 | 載具在工作船後甲板；方晴以無線電回報配重配平 |
| `02-walkaround.jpg` | 繞機目視（前方） | 鏡頭繞載具一站一站走；每站提示要看什麼 |
| `03-walkaround-defect.jpg` | 繞機目視（有瑕疵） | 推進器護罩斷裂：一根護罩條彎出、碎片掉在甲板 |

## 判斷

- 每一步都有畫面反應（燈、轉動的槳、鏡頭移動、影像切換），不再是一串句子。
- 瑕疵與故障都沿用既有模型：推進器健康度（碰撞損傷同一套）、漏水警報、通訊劣化。沒有為了遊戲新增物理。
- 瑕疵位置、尺寸與 X1 實際零件位置是近似值（由載具外框與模型的螺旋槳節點推得），待實測。
- `10-fault.jpg` 只有文字提示；推力下降本身要在操控中感受，HUD 的推進器列在工程抽屜裡。
- 甲板上沒有接觸陰影（效能畫質），載具看起來略浮；這是既有下水動畫的呈現，不在本次範圍。
