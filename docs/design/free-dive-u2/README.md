# 自由潛水

主選單直接選海域。水池一開始就能進入，完成序章後，青嶼港和碧海號一起開放。其他海域跟隨劇情章節解鎖，同一海域只列一次。

開場鏡頭繞過載具，地點字卡停留四秒後交回機載視角。駕駛可以自行改燈光、定深和視角。圖鑑照片須使用機載鏡頭，由現場可見的實體、畫面佔比和目前水下能見度決定能否辨識。暫停選單和飛行畫面的「待發現清單」都可查看本地紀錄。

## 碧海號

從艏樓看起錨機和彎折的欄杆，再循錨鏈繞向二號貨艙。從上方越過圍板，可以看見細泥沉積的艙底；斷面露出橫向肋骨。向艉航行可看到駕駛台窗框，船艉外側還有一具脫落的螺槳。

水色、18 m 能見度、平潮和脫落螺槳的位置均為這次虛構潛水的場景設定。船體沿用既有模型與距離場，新增的螺槳沿用輪轂與成對槳葉碰撞形狀。原沉船調查任務使用原場景。
