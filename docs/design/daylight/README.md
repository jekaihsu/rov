# 水面以上的日光與色彩（`simulator/viewer/fx/daylight.js`）

所有鏡頭在水面以上的畫面（下水動畫、場址水面段、浮在水面時的追蹤鏡頭）共用同一套日光模型：
太陽、天光、天空（漸層、太陽周圍散射、雲）、開闊海面、固定的日光曝光與色彩處理。
鏡頭在水面下（以及俯視地圖視角）時，燈光維持水下光學原本校正用的數值，水下畫面不變。

## 做了什麼

- `fx/daylight.js`：擁有場景的太陽與半球光（從 `app.js` 搬入）。水面下使用 `UNDERWATER_DAYLIGHT`（與原本完全相同）；
  水面上依預設組 `clear`／`overcast` 設定。港區與淡水場址為陰天，其他為晴天。
- 天空：天頂深藍、地平線偏淡的漸層，太陽周圍前向散射，低空積雲；陰天依 CIE 陰天亮度分布（天頂為地平線 3 倍）。
- 海面：法線貼圖波紋、粗糙海面的菲涅耳反射（掠角反射率上限）、太陽閃光、依水型的水體顏色、遠處空氣霧化。
  取代下水動畫原本的 `Water.js` 平面鏡反射（少一次整個場景的反射繪製）。
- 曝光：水面上改為固定日光增益、不做灰世界白平衡（`AutoExposurePass.metering`）；水面下照舊。
- 空氣霧化：只作用在完全位於水面上的光路（`uAirHaze`，鏡頭在水下時為 0）。
- 太陽陰影：medium 以上開啟，只在水面上繪製；水面下陰影視錐移出世界之外，不重繪。
- 色彩處理：色調映射後，只在水面上，把 45～80° 的黃色往金黃轉回最多 14°、略提飽和度；天空、海、綠、橘、灰不動。
  這是攝影機的色彩呈現，不是超出真機的功能，因此沒有註冊擬真項目。
