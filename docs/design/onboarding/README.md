# 新手引導與下水動畫（2026-11-17）

擁有者回報：「開始的時候不知道為甚麼沒有動畫」「也都沒有提示引導」。

## 原因

1. **動畫**：`introForLaunch()` 只在第一次下潛播放下水動畫，之後直接從水中開始（除非開「每次都播放」）。
   另外桌面殼（`simulator/desktop/main.cjs`）載入選單時帶 `?nointro`，使桌面版**每一次**都不播動畫，
   連潛前檢查流程也一併略過。
2. **引導**：`pilot_guide.js` 的操作清單放在工程抽屜裡，一般玩家看不到；右上的「首次潛航練習」只列出項目，
   沒有告訴玩家按哪個鍵。

## 改了什麼

- **每次下潛都播放下水動畫**，播放中可跳過。設定「介面 › 下水動畫」、簡報的開關與 `?nointro` 照舊可關閉；
  「每次都播放」選項移除（已無意義）。桌面殼不再帶 `?nointro`。完整潛前流程時動畫仍停在甲板等待（不變）。
- **跳過提示**（`play/intro_skip.js`）：右下一行小字，依目前裝置顯示按鍵圖示：手把「按住 ○／B 跳過 · Esc」，
  鍵盤「Esc 跳過下水動畫」。手把長按選單的返回鍵 650 ms 跳過，經過輸入層（`back` 動作），
  按住期間不會觸發錄影；按住時提示條由左向右填滿。
- **新手提示卡**（`play/onboarding.js`、`onboarding_model.js`）：畫面左下（小地圖與底部讀數之間，不擋中央）一次一張，
  依序教：解鎖 → 移動與轉向（前後、轉向、升降三項分別打勾）→ 定深 → 燈光 → 拍照 → 任務速覽 → 暫停選單。
  按鍵取自玩家實際綁定（`bindings.js`）與目前裝置的圖示（`glyphs.js`），PS、Xbox、鍵盤各自正確。
  完成由遙測判定（真的解鎖、真的推桿），打勾約 2 秒後淡出，再淡入下一張；可按 × 略過。
  第一次遇到**纜線張力升高、DVL 失鎖（且開著輔助）、低能見度**時插入一張說明怎麼處理的提示（黃色線條）。
  下水動畫、甲板流程、劇情無線電、暫停選單、結算畫面在畫面上時提示等待；SDK 或 USB 遙控器操作時不顯示按鍵提示。
- **進度依瀏覽器設定檔保存**（`localStorage` 的 `rov.onboarding.v1`）：第二次下潛不重複已學會的步驟。
  設定「介面」新增「新手提示」開關與「重新顯示新手提示」按鈕（主選單與暫停選單各一份）。
- **暫停選單新增「操作教學」**：列出全部步驟、目前按鍵與完成狀態，隨時可查，不必開工程抽屜。
- 自由潛航、快速開始、職涯委託與劇情章節共用同一套提示。
- 配色：細青線、半透明深色底、冰白字；完成用綠、事件提示用黃；不使用橘色。

### 擬真規則的判斷

提示只說明本遊戲自己的操作，以及教官站在駕駛旁會講的作業常識；不提供真機控制台看不到的資訊
（纜線張力、DVL 狀態、能見度本來就在 HUD 上）。因此屬於介面說明，不是超出真機的輔助，未註冊為擬真項目；
另有獨立的開關可關閉。

## 截圖

由 `simulator/tools/browser_onboarding_smoke.py --shots docs/design/onboarding --size WxH --pad xbox|playstation|none`
產生（全新設定檔、輔助預設、快速下水）。檔名後綴為解析度與裝置：

| 檔案 | 內容 |
|---|---|
| `01-intro-skip-prompt-*` | 下水動畫播放中，右下的跳過提示 |
| `02-first-hint-unlock-*` | 入水後第一張提示：解鎖（顯示實際按鍵） |
| `03-unlock-hint-cleared-*` | 解鎖完成，提示淡出 |
| `04-hint-move-*` | 移動與轉向提示 |
| `05-hint-progress-*` | 推桿後「前進／後退」打勾 |
| `06-hint-depth-*` | 下一步：定深 |
| `07-second-dive-intro-*` | 第二次下潛（快速開始）仍播放下水動畫 |
| `08-second-dive-hint-*` | 第二次下潛：從未完成的步驟繼續，不重複解鎖與移動 |
| `09-pause-tutorial-*` | 暫停選單的「操作教學」 |

`1600x900-xbox` 為 Xbox 手把、`1366x768-playstation` 為 PS 手把、`1600x900-none` 為鍵盤（遊戲鍵位）。

## 評估

第一次玩的人入水後，左下會直接看到「解鎖推進器 [△] 解鎖」，按下去卡片打勾換成三行附按鍵的移動說明，
一路帶到暫停選單；右上原有的「首次潛航練習」清單同時顯示進度。我認為第一次玩的人知道該做什麼。
仍可改進：解鎖完成的打勾狀態只停 2 秒；右上清單與左下卡片內容部分重疊（清單是進度，卡片是怎麼做），
之後可考慮合併。
