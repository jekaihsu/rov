# 大片感選單（big picture）

擁有者對原本畫面的意見：太雜、字太多、框線太細、看起來不真實。核准的方向（`docs/design/game-plan.md` §11「介面」）：
**整個畫面就是遊戲自己的場景**，左邊一行小分類、**一個**很大很重的標題、三個大數字配小標籤、**一顆**實心橘色主要按鈕；
其他選擇是右下一排大圖磚，每塊只有名字，選中的用粗（4 px）冰白框；右上一行狀態（執照 · 資金）。
沒有細線、沒有半透明加框的面板、沒有段落；細節按「明細」才出現。參考 Forza、Gran Turismo、Call of Duty 的選單。

背景一律由遊戲自己算出來：選單的 3D 舞台（`menu/stage.js`），或從遊戲截下來的海域預覽圖（`menu/previews/`）。
**不使用任何真實照片。**

## 版面系統

`simulator/viewer/menu/big_picture.css`（樣式）＋ `simulator/viewer/menu/big_picture.js`（小元件）。

| 元件 | 做法 |
|---|---|
| 主視覺區（hero） | `createHero()`：分類行、標題、數字列、短標籤（chip）、行動列。空的列自動收起 |
| 標題 | 1080p 約 120 px、字重 900；`fitTitle()` 依字數分三級，最多兩行（英文等較長語言也放得下） |
| 數字 | `stat()`：大數字（1080p 約 60 px、字重 800）在上，小標籤在下 |
| 主要按鈕 | `primaryButton()`：實心橘、粗字。每個畫面只有一顆 |
| 次要行動 | `linkButton()`：純文字；滑過或聚焦時底下出現實心粗線 |
| 圖磚列 | `tile()`＋`createTileStrip()`：右下一排，目前那一塊有 4 px 冰白框，其他略暗；可左右捲動，還有更多的那一側邊緣淡出 |
| 狀態行 | `statusLine()`：右上一行（執照 · 資金） |
| 明細 | `createDetailSheet()`：右側實心頁（`<dialog>`），手把「返回」關閉，段落可用方向鍵逐段捲動 |
| 場景遮罩 | `.menu-shade`：左側與下緣漸層壓暗，文字站在暗的一側，不放在框裡 |
| 預覽圖墊底 | `createBackdrop()`：切換海域時先全幅顯示該海域的遊戲預覽圖（緩慢推近），3D 舞台換好後淡出；這個版本沒有的場景就留著預覽圖 |

尺寸跟著視窗走：`--bp-u` 是 16:9 畫面高度的 1%（1080p 為 10.8 px）。內文最小 1080p 為 20 px（720p 不低於 15 px）。
配色：主色 `#06121C`、第二色 `#EEF3F0`、強調色 `#FF7A2F` 只給主要按鈕；警示色（缺條件、暫定）沿用 `--warn`。
聚焦一律是粗冰白框或實心粗線；停用的東西變暗，不加框。

## 操作

- 手把／鍵盤導覽不變（`menu/navigator.js`）：方向鍵在圖磚、標籤與按鈕間移動，確認＝選目前那塊，LB／RB 換分頁，返回＝上一頁或關閉明細。
- 圖磚在聚焦或滑鼠移上去時成為「目前」那一塊：左邊主視覺區與背景跟著換。
- 裝備部維持「按兩次才購買」；執照考核維持第二次明確確認。
- 底部按鍵提示列保留，但變淡、沒有分隔線。
- 暫停與結算開著時，飛行儀表與浮動面板暫時隱藏，後面只剩場景（關掉就回來）。

## 重新截圖

```bash
cd simulator
python -m qysim.server --http-port 8092 --ws-port 8792 &
python tools/browser_big_picture_shots.py after        # 寫到 docs/design/big-picture/
python tools/capture_site_previews.py tutorial_pool:briefing aquaculture_pen   # 補圖磚用的遊戲預覽圖
```

這次新增兩張圖磚用的預覽圖 `menu/previews/tutorial_pool.jpg`、`aquaculture_pen.jpg`（各約 11–13 KB），
都是用上面的工具從選單的 3D 舞台截下來的。

## 已知限制

- 這台截圖機器沒有粗體中文字型（只有文泉驛正黑），中文粗體是瀏覽器合成的；使用者電腦上的
  PingFang TC／Microsoft JhengHei／Noto Sans TC 會是真正的粗體。專案沒有內嵌中文字型（授權白名單不含 OFL）。
- 裝備部的品項沒有圖片（不得使用照片，遊戲內也還沒有配件模型），圖磚是實心色塊加名稱與價格。
- 訓練、多人、設定三個畫面只做了字重、分頁與框線的整理，版面還是清單／表單；它們不在這次範圍內。
