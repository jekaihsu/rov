# 從 SDK 讀懂模擬器

**座標與單位。** 世界原點在情境參考點的水面。NED 的 x 向北、y 向東、z 向下，深度隨下潛增加；機體 FRD 分別為前、右、下。
四元數順序為 `[w,x,y,z]`，將機體向量旋轉到世界座標。航向北為 0°、東為 90°。
距離通常為 m，速度通常為 m/s，`_kn` 為節；高頻 50hz 封包的整數深度為 cm。
定向控制須處理跨北角度，例如從 359° 到 1° 的最短轉角為 +2°。

**取樣與傳輸。** 物理預設每 0.01 s 步進，viewer 約 30 Hz 發布狀態。SDK 則是本機 TCP 9760 的逐行 JSON 請求與回覆，以 id 配對；
每次輪詢取得當下可用的讀值。模型的取樣保持可能讓連續兩次輪詢得到相同數值。高頻狀態介面交替給出標記為 10hz／50hz 的封包；
聲納須訂閱才開始掃描，目標更新率為 5 Hz。

**感測器與真值。** 自動駕駛取用 SDK 的壓力深度、融合航向及 DVL 狀態。
viewer 的 `pos`、`q`、`vel` 留供渲染與回放。DVL 失鎖時回報的零速無法證明載具已停止；
先檢查 `DVL_Status`，使用導覽資料時也要檢查 `position_valid`。
前向測距的 50 m、高度計的 100 m 表示無回波，0.3 m 是盲區讀值。

**控制權。** SDK 控制 training 房間的第一艘載具。接手後實體 RC 輸入被忽略；
搖桿與滾輪為 1000–2000 PWM，1500 置中，軸意義取決於操作配置。SDK 遠端控制及自動導航都略過 viewer 的速度／定點輔助。
viewer 的 assist 0 為手動、1 為速度、2 為定點，後兩者在 DVL 失鎖時退回手動。
定深仍有獨立開關，接手 SDK 不會自動開啟定深。

**失聯與復歸。** viewer 座席使用遞增 seq，RC 心跳至少 5 Hz；0.6 s 未收到有效輸入時，伺服器置中、上鎖並取消導航。
若分頁卡住，Worker 最多代送 2 秒。失聯鎖定後先同步控制狀態，送一次上鎖封包，再明確解鎖。
USB 橋接也有 0.6 s 看門狗。SDK 的 TCP 請求沒有這個心跳契約，控制迴圈應在 finally 置中、上鎖並交還控制；
程式異常退出後可由該座席的 viewer 發送 `remote_release`。
