# 向潮號｜兩張工單之間

各段在結算後、下一張工單前出現；無論交全件或部分報告都成立。每次一個片段，約 8–25 秒，可立即跳過。簡訊不加無線電濾音。

## P1 結算後 → P2

周楷把池壁照翻面，畫出餘纜的弧線。取玩家照片時依實際纜位；位置不符或沒有成照，就用馬力示範趟的右側進纜照片。

周楷「線從右邊進來。這面也留著。」（P1-103）

## P2 結算後 → P3

艇邊，方晴把沒喝完的茶從排班簿上挪開。

方晴「杯底這個圈，正好圈到你的班。」（P2-103）

## P3 結算後 → C1-1

客戶簡訊。葉理傳來首樁照的紙本摺法；若本趟沒有成照，她拿前班的照片示範。

葉理「我把樁號朝外摺。夜班一翻就找到。」（P3-103）

葉理轉來隔壁泊位場務的回覆。翁慈「葉姐，樁號這樣印，船上也看得清。」（P3-106）

## C1-1 結算後 → C1-2

馬力用兩指遮住舊照的尺點。林岑把手撥開。

馬力「少這兩點，誰還敢報厚度？」（C11-103）

## C1-2 結算後 → C1-3

工作日誌裡夾著隔離單。方晴把船方最後回話的時間寫上去，沒等到確認就圈出空格。

方晴「下班的人也得知道，是幾點回的話。」（C12-103）

## C1-3 結算後 → C1-4

岸台簡訊。夜班在搜尋圖上描出已掃範圍；若全程沒掃到，只留下次起掃點。

葉理「這張圖我收。明早不用從頭找。」（C13-103）

## C1-4 結算後 → C2-1

方晴攤開潮表，指甲旁邊是她用鉛筆添的一欄。

方晴「左欄是預報。右欄才是我們下水的時間。」（C14-103）

方晴收起潮表時，下一張工單傳來一行備註。翁慈「葉姐說你們會留未查範圍。我的網也要。」（C14-106）

## C2-1 結算後 → C2-2

白框有一角掉了漆。翁慈在岸上交班圖的同一角描白。

翁慈「藍筆借我。這面紙還缺個水深。」（C21-103）

翁慈手機上，葉理傳回交班圖的校樣。葉理「翁姐，白框那一角我替夜班印大了。」（C21-106）

## C2-2 結算後 → C2-3

周楷脫了手套才翻三號圈的圖。紅鉛筆停在白框旁。

周楷「先留洞位給補網班。籃子我來數。」（C22-103）

## C2-3 結算後 → 本版結尾

回艇交過完整或部分報告後，馬力擦乾操控台，把風場排班簿翻到季末。周楷在 C 腿東南角點出纜盤。

若尚缺考核，林岑先在預排表夾一張補考單。馬力「主駕那欄留給你。我簽備援。」（C23-103）

最後一幕待船員交班後淡出。排班頁的日期與第一潛相隔三個月，字卡「八月二十八日 · 風場試單 · C 腿｜平潮還剩二十分鐘」（C23-104），停兩秒收「待續」。不重演事故，不替開場選結局。
