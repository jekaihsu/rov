## 1. 一句話

玩家是 **YX 海事服務** 的新進觀測級 ROV 駕駛員。從水池考照出發，接港口、船殼、
養殖場的真實工單；平常故事藏在簡報、無線電與結算評語裡，每章有一次有演出的大事件。

調性：**寫實職場，帶一點輕鬆**——程序、術語、評分照真；無線電有人味與職場幽默，
不搞笑、不奇幻。參考《潛水員戴夫》的船上生活感：同事有個性，每次回船上都有一點新東西。

目標玩家：硬核擬真。一關 **15–25 分鐘**。失敗可中止仍及格（低分）；獎牌是精熟目標。

## 2. 世界與公司

### 2.1 YX 是什麼

| 項目 | 設定 |

| 據點 | **青嶼港**（Qingyu Port／青屿港／セイショ港）——虛構港區，沿岸補給、訓練水池、一小棟貨櫃控制室。不影射真實港口。 |

### 2.2 地理與季節感（第一版）

- 作業海域：亞熱帶近岸——港內濁水、潮差、午後雷陣雨窗口。
- 序章：訓練季，水池與港外避風區。

## 3. 角色（六位）

玩家本人不具名；無線電呼號見 §5。每位名字需在繁中／英文／簡中／日文都自然。

### 3.1 林岑｜督導（Supervisor）

| 語系 | 寫法 |
|---|---|
| 繁中 | 林岑 |
| EN | Lin Cen |
| 簡中 | 林岑 |
| 日文 | リン・ツェン |

- **背景**：四十出頭，前一級駕駛，現任向潮號作業督導兼考照考官。嘴硬、護短，程序絕不讓。
- **說話方式**：短句、先講結論再講原因；少用語助詞。稱呼玩家多用呼號，偶爾「新人」。
- **口頭禪**：「先停。」「報告只寫看得到的。」「退路想好了嗎？」
- **與玩家**：嚴格的師傅；金牌時只點頭，中止時先問「人機都回來了沒」。
- **弧線（序～二）**：從「盯住不出事」→「敢把趕工窗口交給你」→ 養殖場大事件後第一次當眾說「這趟你做得對」。
- **配音**：年齡感 42–48；語速中偏慢；基調沉穩、低壓命令；緊張時變更快但不喊叫。

### 3.2 周楷｜纜線手（Tether / Tender）

| 語系 | 寫法 |
|---|---|
| 繁中 | 周楷 |
| EN | Zhou Kai |
| 簡中 | 周楷 |
| 日文 | シュウ・カイ |

- **背景**：二十大後半，甲板纜線手。手指有舊繭，記纜長比記人名準。
- **說話方式**：口語、會插一句職場冷幽默，但緊急時只報數字與方向。
- **口頭禪**：「線還夠。」「我收一點。」「別讓我跟樁談戀愛。」
- **與玩家**：第一個會用玩笑緩和緊張的人；纜線出事時比督導先罵、罵完立刻協助。
- **弧線**：序章愛碎念 → 第一章學會在趕工時少說話多報張力 → 第二章逃魚時主動建議「先補洞座標再收魚」。
- **配音**：年齡感 26–32；語速偏快；基調輕鬆帶砂感；告警時變乾、變短。

### 3.3 方晴｜甲板手（Deck）

| 語系 | 寫法 |
|---|---|
| 繁中 | 方晴 |
| EN | Fang Qing |
| 簡中 | 方晴 |
| 日文 | ファン・チン |

- **背景**：三十初，小艇甲板與收放。負責下水／回收口令、甲板安全、偶爾把咖啡遞進遮棚。
- **說話方式**：清楚、像檢查表；偶爾吐槽天候與客戶時程。
- **口頭禪**：「甲板淨空。」「艇邊就位。」「窗口還有幾分，我看表。」
- **與玩家**：實務派姊／兄長感；玩家回收慢也不催，只報剩餘潮時。
- **弧線**：從「看好新人別掉海里」→ 第一章趕工時成為時間壓力的人聲節拍器 → 第二章在網箱邊幫忙準備夾爪籃，話變少、動作變快。
- **配音**：年齡感 30–36；語速中等、咬字清楚；基調務實、微涼；趕工時提高音高但不尖。

### 3.4 馬力｜資深駕駛員（Senior Pilot）

| 語系 | 寫法 |
|---|---|
| 繁中 | 馬力 |
| EN | Ma Li |
| 簡中 | 马力 |
| 日文 | マー・リー |

- **背景**：三十五左右，一級駕駛。名字常被笑「馬力不夠／馬力太大」——他本人懶得解釋。
- **說話方式**：懶、準；愛用比喻但不講幹話。常在結算後才出現一句評語。
- **口頭禪**：「慢就是快。」「你撞的是錢。」「回來我煮麵——今天偏鹹。」
- **與玩家**：不是對手，是「你未來可能變成的樣子」。會在玩家銀牌時說「還能更乾淨」。
- **弧線**：序章在岸上旁觀 → 第一章交班大事件遠端聽頻、必要時提醒 → 第二章大事件與玩家並肩（他開第二視角或備機），承認新人判斷。
- **配音**：年齡感 34–40；語速慢、尾音掉；基調慵懶自信；緊急時忽然變清楚。

### 3.5 葉理｜港務客戶代表

- **背景**：港務局／碼頭營運窗口，三十多。要交班報告、怕延誤、不完全懂 ROV，但懂合約罰則。
- **說話方式**：公文腔夾口語；催的時候用「窗口」「簽收」「複查」。
- **口頭禪**：「照片要能對上工單。」「交班前我要檔案。」「這段寫『待複查』可以，空白不行。」
- **與玩家**：壓力來源，不是反派。尊重專業，但時間不等人。
- **弧線**：第一章從「催件」→ 大事件後改口「你們中止得對，我去延交班」。
- **配音**：年齡感 33–40；語速偏快；基調客氣帶焦躁；滿意時忽然變短、變軟。

## 5. 無線電通話規範

### 5.1 呼號

| 單位 | 呼號（繁中） | EN |
|---|---|---|
| 工作船 | 向潮 | Facing Tide |
| 控制室／督導 | 向潮－指揮 | Tide Control |
| 駕駛員（玩家） | **R-1** | R-One |
| 纜線手 | 向潮－纜手 | Tide Cable |
| 甲板 | 向潮－甲板 | Tide Deck |
| 備機／資深駕 | R-2 | R-Two |
| 港務客戶 | 岸台－葉 | Shore Yeh |
| 養殖客戶 | 網台－翁 | Pen Weng |

開場示例：「向潮－指揮呼叫 R-1。」／「R-1，收到。」

### 5.2 確認與習慣用語

- 收到／明白／等待／再說一次
- 到位／拍照完成／目標完成
- 張力偏高／請求放纜／請求收纜
- 揚沙，減速／保持距離
- 中止作業，回收／人機安全
- 不要說「over and out」混用；結束用「向潮－指揮，R-1 結束。」

### 5.3 真實的簡短習慣

1. **先身份、後內容**。
2. **一次一事**：不要在一句裡塞三個指令。
3. **數字要單位**：米、節、點鐘方位。
4. **壞消息先報狀態再報建議**：「張力高。停推。我收一米。」
5. **客戶頻道與內頻分開**：對葉理／翁慈少講內部吐槽。

## 7. 禁忌清單

1. **不出現**真實 ROV／船舶／養殖／能源公司名稱與商標。
2. **不出現**真實事故受害者姓名、真實海難細節、可辨識的真實沉船。
3. **遺體**：若未來有搜救關，只用**證物**或**訓練假人**；畫面與台詞不描述遺體。
4. **不搞笑到出戲**：可以吐槽趕工與泡麵，不講超自然、不講第四面牆玩梗。
5. **不改物理說服力**：台詞不暗示玩家可以「加馬力硬拖」過關。
6. **不宣稱** IMCA 或其他真實機構認證；執照皆 YX 虛構發照。
7. **客戶刁難**限於時程、報告格式、重拍角度——不人身攻擊、不歧視。
8. **動物福利**：養殖關強調燈光勿嚇魚、勿高速撞魚群；逃魚寫財產與合規壓力，不寫血腥。

## 9. 這一季的工單

**季末排班前，R-1 能讓下一班憑自己的報告決定要不要下水嗎？若辦不到，首張風場試單的主駕欄就得填馬力，港內那一班也得退給別隊。**

青嶼港的春末到夏末，向潮號早班出港，午後常得趕在雷雨前靠岸。十八到二十五人的 YX 只有一組班底能同時湊齊主駕、督導和纜手。港務工單簽收後才請款，重拍的油錢先從艇上的週轉金出。葉理每次催交件，岸上其實也有人等她決定明早要帶什麼工具。青灣箱網在港外的虛構海灣「折帆灣」；三號圈入口的白浮框是場方約定的十二點鐘。報洞位必須帶圈號和深度，換一個入口就不能照抄鐘點。

| 船員 | 序章・誰看著誰 | 第一章・誰能喊停 | 第二章・誰簽名 |
|---|---|---|---|
| 林岑 | 把新人第一張相片留下，背面仍由自己簽。 | 葉理要整份簽收，他讓 R-1 決定剩下的潮時夠不夠重拍。 | 翁慈問要不要出備機，他讓 R-1 報位置，自己只覆誦。 |
| 周楷 | 用指頭沿首張照片畫出纜從哪一側進來。 | 客戶佔著頻道時只報張力，等岸台回覆才解釋退路。 | 平常怕多管駕駛的事，這次先說洞位得留給補網班。 |
| 方晴 | 沒等到上鎖回報，手就留在艇緣外。 | 葉理要一個交件時間，她在表上另圈出最後回收時間。 | 場方想多收一尾，她先點籃、留時間回收，再讓翁慈簽實收數。 |
| 馬力 | 在岸邊想伸手修正，改用燈照給新人看池壁編號。 | 隔著耳機認出錯看的回波，等玩家自己看出石頭輪廓。 | 把備機放在手邊，一直沒搶操控；交班時將自己的名字移到備援欄。 |

### 三個月後，八月二十八日早班

五月二十八日第一潛。P3 的同側走纜讓人第一次看懂照片邊角那條線。C1-4 方晴把「預報平潮」和「現場可作業」分成兩欄。C2-3 場方靠一個固定入口辨認洞位，周楷也就在風場草圖上標出纜盤所在的一角。三張工作紙最後夾進同一本防水簿。各條路徑都能留下這些觀察；中止就在工作紙上圈出未查範圍。

八月二十八日是本季最後一個風場試作班。早班已到東南側放纜位，方晴看見水面浮物仍橫走，等現場流緩才報可下水；先前的等待已用掉預留窗口，林岑接手時報「平潮還剩二十分鐘」。依開場 §5，作業深度十二米，東南纜盤放出四十五米，約十米餘纜被微流帶向北北西，貼過 C 腿南側。沿西面北轉往 B 腿時，纜從西南角折過陽極座；機體能過，後面的纜未必能過。周楷得等真有勾點才報卡住，林岑問退路，正是 P3 圖上反向的那一筆。若線滑開、沒勾到或中止，照開場各自收尾，日誌只記當班所見。第二章後只給排班卡，留給玩家自己想起那段無線電。

### 編劇紅線（續 §7）

不以冒險留場換取英雄評語，不放大一次漏拍成有人遇險。小艇不演甲板吊或貨櫃控制室；近鋼構可看輪廓，聲納亮點要用影像辨識，鬆桿後仍可能隨流漂。輕夾爪可掛繩，重物起吊與補網交現場班組。窗口、排班與收支是本作虛構條件；研究依據見 [ROV 研究「纜線、聲納、流程與事故」](../reference/real-rov-research.md)。

## 10. 給逐關劇本的播放規則

每關字卡和外景共 8–12 秒，可立即跳過。逐關劇本的工單供備查，開局只播當步角色的短句；接手就切機載原設定、撤黑邊和配樂。每步只顯一個動作，依目前裝置從 `input/glyphs.js` 取圖示。飛行中角色依逐關觸發條件輪流上頻，安全告警優先；未發生的失誤不播。各項操作（含回收）從該步開始計時：20 秒無進展覆誦該步指示一次；在尋找目標時改播本關閒置句。單步滿 120 秒仍未完成，或工單窗口先到，播逾時句，按中止交已取得的部分報告。反覆移桿不重置步限；需要長航段就以每一測點、每一層分段。逾時時若仍在操控，先結束玩家值班，由船組接手處置，再切回艇。隔離、解鎖、證據與考照不因逾時視為通過。回艇以實際照片／航跡和等第對應一句評語；未滿銅牌條件記中止，可續章。若有損壞記維修，公司可墊付。 交班或中止後，客戶簡訊只確認收件；考照評語限通過考核時播放。

## 11. 海纜危機｜五月到十月

霧汀邦的居民住在圍著淺水內海的三座長島上，青嶼港在中島凹岸。沿岸往灣底是折帆灣，翻過山脊是水庫。從港口朝外，先見風機，再見礫環海峽的碎島；另一端是同樣由群島組成的序岬國。兩岸平時共用避風水域，家庭和船員往來。地圖以港為紙面中央，島塊像三張錯開的紙條，只標渡船方向與民生服務區。風場維運線路與島際電信海纜分屬不同工單。

**八月的二十分鐘。** 業主想在下一班維運人員上工前知道 C 腿是否還能照常通行。只有平潮能從同一方向取得可比的陽極照。小艇在原泊位放纜，向北北西的流把周楷放出的餘纜帶到腿側。鏡頭邊那條線是自己的臍帶纜。三章翻到同日班簿時，使用玩家實際留下的照片或缺件欄；任何結局都可接外海報障。

**交班的人。** 林岑原先替新人圈漏拍處，四章改讓主駕親筆標未查面，自己在對外報告擋下歸責要求。周楷從記纜長到記停工時刻，讓岸台能對上原片。方晴把平潮表翻面記家中停電時間；五章由她喊停回收，沒人追問還剩幾分鐘。馬力守備機，把自己補拍的頁另署名，封面主駕留給玩家。葉理把港口複寫聯送到修船班，翁慈的網台替斷網人家留口信。玩家從交一張清楚的照片，到交出下一班可以據以開工的範圍。

新增兩位聯絡人。**余禾**是電信值班員，總是先問哪一頁可以簽收；末班她得親自打通診所電話才能劃掉一行。**谷弦**是修纜船甲板領班，有等吊具完全靜止才摘手套的習慣；他接手重件與接續，將玩家的水下原片編入完工單。兩人皆為民間雇員。
