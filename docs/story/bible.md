## 1. 一句話

玩家是 **YX 海事服務** 的新進觀測級 ROV 駕駛員。從水池考照出發，接港口、船殼、
養殖場的真實工單；平常故事藏在簡報、無線電與結算評語裡，每章有一次有演出的大事件。

調性：**寫實職場，帶一點輕鬆**——程序、術語、評分照真；無線電有人味與職場幽默，
不搞笑、不奇幻。參考《潛水員戴夫》的船上生活感：同事有個性，每次回船上都有一點新東西。

目標玩家：硬核擬真。一關 **15–25 分鐘**。失敗可中止仍及格（低分）；獎牌是精熟目標。

## 2. 世界與公司

### 2.1 YX 是什麼

| 項目 | 設定 |
|---|---|
| 全名 | **YX 海事服務**（EN: YX Marine Services；簡中同繁中寫法；日：YXマリンサービス） |
| 雙重身分 | 遊戲內**發照機構**與**玩家所屬公司**同名（game-plan §9）。對外合約寫「YX 發照／YX 作業隊」以免玩家搞混；UI 可簡稱「YX」。 |
| 規模 | 小型區域承包商，約 **18–25 人**（含行政）。觀測級為主，輕作業一台；不做大型鋪纜或重型作業級主契約。 |
| 據點 | **青嶼港**（Qingyu Port／青屿港／セイショ港）——虛構港區，沿岸補給、訓練水池、一小棟貨櫃控制室。不影射真實港口。 |
| 工作船 | **向潮號**（Facing Tide／向潮号／コウチョウ）。約 24 m 近岸工作船：甲板吊、纜線絞車、控制室貨櫃、簡易廚房。玩家「回船上」的生活空間在這裡。 |
| 機隊（玩家可見名） | YX Model R（入門觀測）、Model O（重載觀測）、Model V（輕作業，有臂）。第一版玩家主要開 **Model R**；第二章解鎖夾爪後可接 Model V 相關工單（若尚未解鎖載具，則在 R 上掛輕夾爪——需擁有者確認，見 PR）。 |
| 客戶類型 | 港務／碼頭營運、船舶管理、保險公證、海上箱網養殖場。第一版不出現真實公司名。 |

虛構原則：地名、船名、客戶名一律原創。不寫真實事故、真實受害者、真實沉船名
（沉船「碧海號」屬後期章節，本版不登場）。

### 2.2 地理與季節感（第一版）

- 作業海域：亞熱帶近岸——港內濁水、潮差、午後雷陣雨窗口。
- 序章：訓練季，水池與港外避風區。
- 第一章：港務交班季末，趕工壓力真實存在。
- 第二章：養殖場例行巡檢＋一場破網逃魚。

船上生活的「一點新東西」範例（簡報／結算後短句，非獨立關卡）：
方晴補油漆、周楷換纜標籤、馬力煮太鹹的泡麵、林岑在白板上多畫一條檢查路線。

## 3. 角色（六位）

玩家本人不具名；無線電呼號見 §5。每位名字需在繁中／英文／簡中／日文都自然。

### 3.1 林岑｜督導（Supervisor）

| 語系 | 寫法 |
|---|---|
| 繁中 | 林岑 |
| EN | Lin Cen |
| 簡中 | 林岑 |
| 日文 | リン・ツェン |

- **背景**：四十出頭，前一級駕駛，現任向潮號作業督導兼考照考官。嘴硬、護短，程序絕不讓。
- **說話方式**：短句、先講結論再講原因；少用語助詞。稱呼玩家多用呼號，偶爾「新人」。
- **口頭禪**：「先停。」「報告只寫看得到的。」「退路想好了嗎？」
- **與玩家**：嚴格的師傅；金牌時只點頭，中止時先問「人機都回來了沒」。
- **弧線（序～二）**：從「盯住不出事」→「敢把趕工窗口交給你」→ 養殖場大事件後第一次當眾說「這趟你做得對」。
- **配音**：年齡感 42–48；語速中偏慢；基調沉穩、低壓命令；緊張時變更快但不喊叫。

### 3.2 周楷｜纜線手（Tether / Tender）

| 語系 | 寫法 |
|---|---|
| 繁中 | 周楷 |
| EN | Zhou Kai |
| 簡中 | 周楷 |
| 日文 | シュウ・カイ |

- **背景**：二十大後半，甲板纜線手。手指有舊繭，記纜長比記人名準。
- **說話方式**：口語、會插一句職場冷幽默，但緊急時只報數字與方向。
- **口頭禪**：「線還夠。」「我收一點。」「別讓我跟樁談戀愛。」
- **與玩家**：第一個會用玩笑緩和緊張的人；纜線出事時比督導先罵、罵完立刻協助。
- **弧線**：序章愛碎念 → 第一章學會在趕工時少說話多報張力 → 第二章逃魚時主動建議「先補洞座標再收魚」。
- **配音**：年齡感 26–32；語速偏快；基調輕鬆帶砂感；告警時變乾、變短。

### 3.3 方晴｜甲板手（Deck）

| 語系 | 寫法 |
|---|---|
| 繁中 | 方晴 |
| EN | Fang Qing |
| 簡中 | 方晴 |
| 日文 | ファン・チン |

- **背景**：三十初，甲板與吊放。負責下水／回收口令、甲板安全、偶爾幫控制室送咖啡。
- **說話方式**：清楚、像檢查表；偶爾吐槽天候與客戶時程。
- **口頭禪**：「甲板淨空。」「吊鉤好了。」「窗口還有幾分，我看表。」
- **與玩家**：實務派姊／兄長感；玩家回收慢也不催，只報剩餘潮時。
- **弧線**：從「看好新人別掉海里」→ 第一章趕工時成為時間壓力的人聲節拍器 → 第二章在網箱邊幫忙準備夾爪籃，話變少、動作變快。
- **配音**：年齡感 30–36；語速中等、咬字清楚；基調務實、微涼；趕工時提高音高但不尖。

### 3.4 馬力｜資深駕駛員（Senior Pilot）

| 語系 | 寫法 |
|---|---|
| 繁中 | 馬力 |
| EN | Ma Li |
| 簡中 | 马力 |
| 日文 | マー・リー |

- **背景**：三十五左右，一級駕駛。名字常被笑「馬力不夠／馬力太大」——他本人懶得解釋。
- **說話方式**：懶、準；愛用比喻但不講幹話。常在結算後才出現一句評語。
- **口頭禪**：「慢就是快。」「你撞的是錢。」「回來我煮麵——今天偏鹹。」
- **與玩家**：不是對手，是「你未來可能變成的樣子」。會在玩家銀牌時說「還能更乾淨」。
- **弧線**：序章在岸上旁觀 → 第一章交班大事件遠端聽頻、必要時提醒 → 第二章大事件與玩家並肩（他開第二視角或備機），承認新人判斷。
- **配音**：年齡感 34–40；語速慢、尾音掉；基調慵懶自信；緊急時忽然變清楚。

### 3.5 葉理｜港務客戶代表

| 語系 | 寫法 |
|---|---|
| 繁中 | 葉理 |
| EN | Yeh Li |
| 簡中 | 叶理 |
| 日文 | イェ・リー |

- **背景**：港務局／碼頭營運窗口，三十多。要交班報告、怕延誤、不完全懂 ROV，但懂合約罰則。
- **說話方式**：公文腔夾口語；催的時候用「窗口」「簽收」「複查」。
- **口頭禪**：「照片要能對上工單。」「交班前我要檔案。」「這段寫『待複查』可以，空白不行。」
- **與玩家**：壓力來源，不是反派。尊重專業，但時間不等人。
- **弧線**：第一章從「催件」→ 大事件後改口「你們中止得對，我去延交班」。
- **配音**：年齡感 33–40；語速偏快；基調客氣帶焦躁；滿意時忽然變短、變軟。

### 3.6 翁慈｜養殖場客戶代表

| 語系 | 寫法 |
|---|---|
| 繁中 | 翁慈 |
| EN | Weng Ci |
| 簡中 | 翁慈 |
| 日文 | オン・ツー |

- **背景**：箱網場場務，四十上下。在意魚群壓力與破洞座標；逃魚等於錢與合規雙重打擊。
- **說話方式**：直接、數字多（網號、深度、時鐘方位）；緊張時會重複同一句。
- **口頭禪**：「燈別太亮，魚會瘋。」「破洞報方位。」「先堵住再說情緒。」
- **與玩家**：第二章主要客戶。平常冷淡，大事件時把指揮權暫時交給船上專業。
- **弧線**：從「例行巡檢外包」→ 逃魚當下信任玩家回報 → 結算後請喝罐裝咖啡（船上生活小獎賞）。
- **配音**：年齡感 40–48；語速中快；基調乾、急、專業；安穩後明顯降速。

## 5. 無線電通話規範

### 5.1 呼號

| 單位 | 呼號（繁中） | EN |
|---|---|---|
| 工作船 | 向潮 | Facing Tide |
| 控制室／督導 | 向潮－指揮 | Tide Control |
| 駕駛員（玩家） | **R-1** | R-One |
| 纜線手 | 向潮－纜手 | Tide Cable |
| 甲板 | 向潮－甲板 | Tide Deck |
| 備機／資深駕 | R-2 | R-Two |
| 港務客戶 | 岸台－葉 | Shore Yeh |
| 養殖客戶 | 網台－翁 | Pen Weng |

開場示例：「向潮－指揮呼叫 R-1。」／「R-1，收到。」

### 5.2 確認與習慣用語

- 收到／明白／等待／再說一次
- 到位／拍照完成／目標完成
- 張力偏高／請求放纜／請求收纜
- 揚沙，減速／保持距離
- 中止作業，回收／人機安全
- 不要說「over and out」混用；結束用「向潮－指揮，R-1 結束。」

### 5.3 真實的簡短習慣

1. **先身份、後內容**。
2. **一次一事**：不要在一句裡塞三個指令。
3. **數字要單位**：米、節、點鐘方位。
4. **壞消息先報狀態再報建議**：「張力高。停推。我收一米。」
5. **客戶頻道與內頻分開**：對葉理／翁慈少講內部吐槽。

| 層 | 做法 |
|---|---|
| 日常 | 工單簡報（書面）＋下潛無線電＋結算評語（金牌／銀／銅／中止） |

## 7. 禁忌清單

1. **不出現**真實 ROV／船舶／養殖／能源公司名稱與商標。
2. **不出現**真實事故受害者姓名、真實海難細節、可辨識的真實沉船。
3. **遺體**：若未來有搜救關，只用**證物**或**訓練假人**；畫面與台詞不描述遺體。
4. **不搞笑到出戲**：可以吐槽趕工與泡麵，不講超自然、不講第四面牆玩梗。
5. **不改物理說服力**：台詞不暗示玩家可以「加馬力硬拖」過關。
6. **不宣稱** IMCA 或其他真實機構認證；執照皆 YX 虛構發照。
7. **客戶刁難**限於時程、報告格式、重拍角度——不人身攻擊、不歧視。
8. **動物福利**：養殖關強調燈光勿嚇魚、勿高速撞魚群；逃魚寫財產與合規壓力，不寫血腥。

## 8. 獎牌與結算口吻

| 等第 | 督導口吻 |
|---|---|
| 金牌 | 短、肯定、幾乎不延長音。「乾淨。」 |
| 銀牌 | 肯定＋一項可精進。「能交。纜還能更省。」 |
| 銅牌 | 可用、有保留。「客戶接得了。你自己知道哪段糊。」 |
| 中止 | 先安全、再程序。「回來就對。報告寫中止原因。」 |

馬力／周楷可在結算後各補一句生活感，不覆蓋督導正式評語。
