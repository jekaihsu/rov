# 第一章｜港口與船舶

**主題**：在濁水與船底下方交出可用報告；學會被客戶催的時候仍守程序。  
**情緒曲線**：例行（Level II）→ 船底不安感 → 聲納搜尋的專注 → **交班前趕工大事件**（高壓）→ 回船釋放。  
**大事件建議**：交班前發現異常的趕工檢查（對應研究表 #8／既有 `harbor_signoff` 骨架）。  
理由：真實、不需新物理；壓力來自時程與「異常是否惡化」，符合硬核擬真；比「螺槳流特技」更貼職場。

任務對應見 [`../mission-map.md`](../mission-map.md)。

播放規則見[故事聖經 §10](../bible.md#10-給逐關劇本的播放規則)。每步 20 秒閒置提醒、120 秒硬上限，窗口先到立即交班。

## 關卡 C1-1｜碼頭 Level II 抽樣

### 接手與退場

- 地點字卡「青嶼港 · B 區低潮」。上張照片的樁號溶進濁水，同一樁只剩附著物外緣。
- 首個操作與任務走向：定住第一測點，讓尺與附著層同框。
- 轉折布置：能見度約一點五米，從看不清尺距到看得到，但貼近時燈下懸粒遮住刻線。逐樁量三層並分軟硬。若玩家避開，保留乾淨航跡。
- HUD 依序顯露：深度 → 雷射比例尺。回艇交件：九格厚度及分類；缺值不補零。
- 厚度照首次同框：葉理「岸台收到。夜班拿這張挑刮刀。」（C11-105）。
- 搜尋閒置：林岑「R-1，尺點和外緣能同框嗎？」（C11-101）。
- 步限／窗口到：林岑「潮時到了。未量的格子註記。」（C11-102）。送部分報告與下列中止評語。
