# 第三章｜八月二十八日，向潮號早班

五月二十八日那張池壁照，背面簽的是林岑。三個月後，防水簿裡夾著三份工作紙，季末排班表的主駕欄還空著。虛構業主岬汀能源委託年度水下外觀檢查，明年要能在同一根腿、同一深度找到同一塊陽極。委託只交外觀影像與未查範圍。陽極的剩餘壽命與保護電位不在這張工單上。

## C3-1｜橫走的浮標

東南側放纜位。鏡頭從載具側面繞過亮著的觀測窗，斜撐在背景往旁邊移。方晴看的是浮標，在防水簿的「現場」欄上停筆。潮表預報平潮，十二米處仍有橫流，鬆桿時 C 腿離開畫面中心。周楷看著粒子橫過陽極，向甲板證實水下也在往東走。接手後朝結構外側修正，讓陽極穩定留在機載畫面再按快門。定深只守水深。收到照片，方晴才在那一欄寫下當班時間。超時就圈出空白交班。無線電 C3-001 至 C3-003、C3-017。

## C3-2｜輪廓以內

B 腿北面，同一深度。八秒側後方鏡頭裡，斜撐遠端消失在懸浮物後面。馬力手在備機上，這次只講他看見的輪廓。B 腿陽極起初在當地能見距外。立管托架先浮現。馬力問備援纜走管子哪一側，周楷報纜在外側，駕駛從外圍慢慢接近，直到能辨認陽極兩端，面向它穩住拍照。馬力留下這張圖給明年的班組，辨認不了的部分留白。無線電 C3-004 至 C3-006、C3-018。

## C3-3｜退路

八月二十八日，同一班的最後二十分鐘。從開場同一個肩後角度看 C 腿、斜撐和魚群。「R-1，這裡是指揮。平潮還剩二十分鐘。」這次不切回五月。玩家從 C 腿外親自靠近，拍下十二米陽極，沿西面北轉。東南側的纜盤放出四十五米，北北西微流把餘纜貼上南面；機體過角後，後方的纜折上陽極座。周楷只在主機回報勾點時報出實際張力並喊停。張力表淡入，保留最近三秒峰值，達到 40 N 轉成橙色。

- 放開推桿，沿來路向南退。夾角解開，纜重新走動。周楷想起五月那張照片上畫的退路。林岑把簿子遞過來，馬力指著主駕欄，自己簽備援。YX 一級駕駛員執照，季末「完」。
- 持續朝北頂桿，卡點承載後張力上升，超過本趟機尾纜端的剩餘承載力時斷纜。方晴記最後位置，B 腿這一趟未查。交部分報告，以中止收季；不發晉級執照，也不要求重飛才能看結尾。
- 未拍、未勾或未解開就到時，指揮接班，交已取得的影像。日誌保留實際纜況。無線電 C3-007 至 C3-016。

## 場務與研究依據

依研究報告「檢測怎麼飛、事故怎麼發生」及「臍帶纜」段落，現場流況可偏離潮表，視距限制目視檢查，牽拉會收緊卡點，鋼構接觸可使纜損壞。參見[研究摘要與原始來源](../../reference/real-rov-research.md)與[開場的場景實驗](../../design/cold-open/README.md)。三關的流速、能見度和季末纜端的剩餘承載力是遊戲情境假設。試單由遊戲公司內部簽核。每個拍攝步驟限時 120 秒；北轉 85 秒，解纜 100 秒。以上時限只控制交班。

故事模式的晉級記在劇情存檔的 YX 一級執照獎勵。職涯模式的實際時數與考照簿沿用各自的紀錄。
