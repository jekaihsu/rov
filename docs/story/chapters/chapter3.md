# 第三章｜班簿翻回八月

延續公共服務章（研究表 #12–14）。三張單照常交件，只在乾區換班時露出海上的消息。

| 工單 | 既有工作重心 | 交班鏡頭 |
|---|---|---|
| 水庫進水口攔污柵 | 場方確認隔離後逐片拍攝，記堵塞、斷柵 | 值班員借走複寫紙，最底聯的時刻很淡。 |
| 湖底證物搜尋 | 聲納搜尋，影像確認，移動背包前留原位紀錄 | 馬力分袋收好原檔與工作副本。這套交件法稍後會跟到海上。 |
| 壓力鋼管入口找異物 | 依原工單辨認壓板，線路不安全就撤回 | 方晴把八月排班卡從簿底翻到正面。 |

8/28 風場試單接回片頭。業主在回傳間歇中斷後要一份 C 腿現況給下一班，原訂平潮只剩二十分鐘。從結算後開始敘事，不重演玩家操作；查到哪就將哪一段帶回，未拍處留白。次晨余禾來電，外海電信纜也失去訊號，她要的是原始時間（K1-W01）。林岑交出當日班簿；不同線路的工單各自編號。
