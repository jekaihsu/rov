# 序章｜水池與第一張工單

**主題**：入隊、程序、第一次把「看得到的東西」變成證據。  
**情緒曲線**：緊張好奇 → 手忙腳亂學操控 → 小成就（第一張照）→ 港外第一單的謹慎興奮 → 回船鬆一口氣。  
**大事件**：本節無獨立大事件演出；高潮是「第一張合格水下照」與「第一張對外工單交件」。船上生活感用潛次間短句承擔。

任務對應見 [`../mission-map.md`](../mission-map.md)。台詞 id 見 [`../lines.csv`](../lines.csv)。

播放規則見[故事聖經 §10](../bible.md#10-給逐關劇本的播放規則)。每步 20 秒閒置提醒、120 秒硬上限，窗口先到立即交班。

## 關卡 P1｜水池檢查潛

### 接手與退場

- 地點字卡「三個月前 · 青嶼訓練池」。池壁編號倒映在水面，馬力的手電移到第一塊牌。
- 首個操作與任務走向：查接頭；甲板回覆淨空後入水、解鎖，朝編號前進。
- 轉折布置：第三塊牌靠淺色池壁，近距離全燈時反光吃掉筆畫。留距離或減光都能讀回末碼。若玩家避開，保留乾淨航跡。
- HUD 依序顯露：上鎖狀態 → 深度 → 拍照準心。回艇交件：三張標記與程序紀錄。
- 末碼被燈光洗白：馬力「R-1，最後一碼白了。燈收一格。」（P1-105）。
- 搜尋閒置：馬力「R-1，看得清牌上的筆畫嗎？」（P1-101）。
- 步限／窗口到：林岑「池時到了。缺哪張就記哪張。」（P1-102）。送部分報告與下列中止評語。

馬力帶飛的順序為池底標記（前進）、牆上編號（轉向）、第三塊淺色牌（升降及調燈）。各標記可見才拍；三張入檔後由林岑簽見習卡。P2、P3 接續外場隨班，P3 的評語是准予進港務班。

```
工單編號：YX-TR-001

工作內容：
  1. 完成預潛檢查表（密封、接頭、配平）
  2. 入水後人員離開甲板再解鎖

海況：無流、能見度佳（池水）
注意：水面外禁止解鎖；程序錯誤本趟不算時數
```

## 關卡 P2｜開放水域熟悉

### 接手與退場

- 地點字卡「青嶼港外 · 避風水域」。四個浮標前後排開，浮繩偏向同一側。
- 首個操作與任務走向：轉向第一個浮標；依序過四點，最後鬆桿觀察。
- 轉折布置：末點設在微橫流裡；鬆桿後用浮標邊緣比對漂移，再修回。若玩家避開，保留乾淨航跡。
- HUD 依序顯露：深度 → 航向。回艇交件：四點航跡與漂移修正。
- 末標在鬆桿後移出畫面中央：方晴「R-1，浮標還在走。看它偏哪邊。」（P2-105）。
- 搜尋閒置：林岑「R-1，找上一個浮標作參照。」（P2-101）。
- 步限／窗口到：林岑「這趟到這裡。留航跡給下班。」（P2-102）。送部分報告與下列中止評語。

## 關卡 P3｜碼頭外的第一張工單

### 接手與退場

- 地點字卡「青嶼港 · A 區外樁」。從艇尾看紅色纜標出艇，第一根樁把後五根遮住。
- 首個操作與任務走向：對準第一樁，沿同一側做六趟垂直目視。
- 轉折布置：第二根樁在轉角後；抄近路會把餘纜帶向樁側，繞外側可避開。張力升高才呼叫停推。若玩家避開，保留乾淨航跡。
- HUD 依序顯露：深度 → 拍照準心；張緊才顯張力。回艇交件：逐樁編號照與未查面。
- 外側樁縫首次露出回程纜：周楷「R-1，看右下角。你過樁了，線還沒。」（P3-105）。
- 搜尋閒置：林岑「R-1，從照片邊找纜在哪側。」（P3-101）。
- 步限／窗口到：林岑「岸台，未拍的樁留待複查。」（P3-102）。送部分報告與下列中止評語。
