# 序章｜水池與第一張工單

**主題**：入隊、程序、第一次把「看得到的東西」變成證據。  
**情緒曲線**：緊張好奇 → 手忙腳亂學操控 → 小成就（第一張照）→ 港外第一單的謹慎興奮 → 回船鬆一口氣。  
**大事件**：本節無獨立大事件演出；高潮是「第一張合格水下照」與「第一張對外工單交件」。船上生活感用潛次間短句承擔。

任務對應見 [`../mission-map.md`](../mission-map.md)。台詞 id 見 [`../lines.csv`](../lines.csv)。

| 欄位 | 內容 |
|---|---|
| 研究表 | #1 水池檢查潛 |
| 情境 | `tutorial_pool` |
| 時長目標 | 15–20 分 |
| 客戶 | YX 內部（考照） |

### 簡報（工作單口吻）

```
工單編號：YX-TR-001
客戶：YX 海事服務（內部考照）
地點：青嶼港訓練水池
載具：YX Model R
工作內容：
  1. 完成預潛檢查表（密封、接頭、配平）
  2. 入水後人員離開甲板再解鎖
  3. 六向移動確認；定深開啟後懸停
  4. 開燈；拍攝至少 3 張帶疊字照片
  5. 回收前上鎖、停錄
海況：無流、能見度佳（池水）
注意：水面外禁止解鎖；程序錯誤本趟不算時數
```
