# 第二章｜養殖場

**主題**：在柔性網衣與魚群之間作業；合規與魚群壓力優先於「看起來很忙」。  
**情緒曲線**：例行網衣巡檢 → 死魚回收的髒活實感 → **破網逃魚緊急處理** → 回船安靜、喝罐裝咖啡。  
**大事件建議**：網箱破洞導致逃魚的緊急處理（強化研究表 #9 的破洞壓力，作章末高潮）。  
理由：`aquaculture_pen` 已有破洞與魚群；逃魚是真實養殖痛點（合規／保險）；玩家目標仍是定位、拍照、回報方位——模擬器做得到。  
備選（未採用為主高潮）：颱風後錨繩巡檢（#11）——更長距離與近水面浪，**需繫泊／湧浪功能標註**；適合作章後支線或第二章加長版。

任務對應見 [`../mission-map.md`](../mission-map.md)。

播放規則見[故事聖經 §10](../bible.md#10-給逐關劇本的播放規則)。每步 20 秒閒置提醒、120 秒硬上限，窗口先到立即交班。

## 關卡 C2-1｜網衣巡檢

### 接手與退場

- 地點字卡「折帆灣 · 三號圈入口」。白浮框在艇頭，工人站在框上等第一個洞位。
- 首個操作與任務走向：以入口作十二點繞行，分層找洞、記深度。
- 轉折布置：背流側的網面向航路鼓出，沿原半徑會縮短間距；繞向外凸前先讓出距離。張力或距離有變才告警。若玩家避開，保留乾淨航跡。
- HUD 依序顯露：深度 → 拍照準心與鐘點。回艇交件：破洞照片、圈號、鐘點及深度。
- 下流側網面進入近景：翁慈「R-1，這段網往外鼓。留點距離。」（C21-105）。
- 搜尋閒置：林岑「R-1，白浮框算十二點。」（C21-101）。
- 步限／窗口到：林岑「未查網段留白，我註明範圍。」（C21-102）。送部分報告與下列中止評語。

## 關卡 C2-3｜大事件：破網逃魚

### 接手與退場

- 地點字卡「折帆灣 · 三號圈外緣」。白框旁空著一捲補網，翁慈捏住送話鍵等位置。
- 首個操作與任務走向：由入口搜尋主洞，帶深度拍照定位，再監看到場方接班。
- 轉折布置：主破口靠下流側；順流接近的機體鬆桿仍會靠網，須留退路。可在外側回報或安全中止；魚群動向只作線索。若玩家避開，保留乾淨航跡。
- HUD 依序顯露：深度 → 鐘點；近網才報間距。回艇交件：主洞照、位置與補網班接手狀態。
- 場方接過有註記的報告後：林岑「網台收到你的紀錄了。這趟你做得對。」（C23-105）。
- 搜尋閒置：林岑「R-1，先看網線在哪裡斷。」（C23-101）。
- 步限／窗口到：林岑「窗口關了。已查範圍交網台。」（C23-102）。送部分報告與下列中止評語。
