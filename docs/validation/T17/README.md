# T17 draft validation artifacts

These artifacts document an incomplete instructor implementation, not acceptance
of T17. `instructor.png` is the 1600×900 internal instructor page after ephemeral
local authentication and a physical thruster override. `print-preview.png` shows
the print media layout. `example-report.json` is evidence from the same local
preview; it is not an operator qualification record. No instructor credential is
stored in these files. Before T17 there was no instructor page, so no matching
before screenshot exists.

Reports use provisional limits and explicitly retain nulls for unsampled phases.
Further required work is listed in the PR and the optional protocol section.
