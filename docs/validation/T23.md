# T23 潛前與回收驗證

通用程序依 `docs/reference/real-rov-research.md`「下水回收是一串可檢核的閘門」。
完整流程為每台載具的選用狀態機，快速模式維持原行為；`?nointro` 跳過流程與動畫。
訓練模式預設完整，遊戲預設快速，主選單可明確選擇。

完整流程以確認動作檢查密封、接頭、配平、供電、通訊、相機、燈光、儀表與解鎖條件；
推進器逐顆進行兩秒、5% 推力的模擬診斷脈衝。未入水及未確認人員離開，不准飛行解鎖。
回收需先到水面並上鎖，停止錄影後收纜；淡水沖洗、檢查後可補註記並匯出 JSON 日誌。
日誌帶 UTC 建立時間、作業時間、最大深度、最大纜長、事件與扣分。

## 暫定與範圍界線

- 機型專屬上電順序、提示音、燈號均暫定；沒有套用其他機型音序或燈號。
- 完整流程採緩放，沒有新增拋擲操作；快速模式的既有動畫仍保留。
- 每個未檢項目 35% 故障機率、短測推力與回收速度都是訓練假設，非實測參數。
- 收纜使用規定速度約束支撐載具，非絞車張力動力學。浪況使用時間正弦調制近似，尚未建立浪高／週期物理模型。
- 通訊／接頭等程序故障中止作業並進入失控收纜回收；未檢推進器故障降低一顆推進器效能，
  未檢燈光故障關燈。未模擬獨立網路封包中斷，故障透過事件與回收狀態顯示。
- T12 序章前加入程序教學對話，完整流程仍由共用主選單選項開啟。
- 鍵盤 Tab/Enter 與手把方向鍵/A 可完成檢查；飛行階段保留飛行輸入。

## 與 main 整合後的變更

- 是否走完整流程改由擬真設定項目 `deployProcedure` 決定（`viewer/procedure/fidelity_item.js`）：
  `real` 預設完整流程、`assisted` 預設快速下水；快速下水標為超出真機。原本的主選單下拉與
  `rov.procedure` localStorage 鍵已移除，改由兩處擬真設定面板自動列出。URL `?procedure=full|quick`
  仍可覆寫；`?nointro` 一律略過流程。設定在下次載入場景時生效，飛行中更改不會把載具搬回甲板。
- 檢查表面板改用 `--z-controls` 圖層（原為字面值 95），樣式集中在模組內。
- 手把導覽改由 `input/bindings.js` 的選單情境（`menuUp`、`menuDown`、`accept`）處理，
  面板開啟且不在 `diving` 階段時選單情境啟用；移除原本自行輪詢 `navigator.getGamepads()` 的計時器。
- `browser_smoke.py` 不再修改（使用 main 版本）；`browser_procedure_smoke.py`、`browser_procedure_compat.py`
  改經 `_browser.py` 啟動並取得位址，可用 `run_browser_checks.py` 執行。
- `t23/browser-smoke.txt` 與 `t23/local-tests.txt` 是整合前的原始紀錄，保留供參考。
