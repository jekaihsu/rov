# X1 原廠遙控器整合紀錄

紀錄日期：2026-10-01。使用者確認目前成果可以，結束本次調整並保留紀錄。

## 使用情境

以 QYSEA X1 原廠 Q-iRC 遙控器控制電腦上的 ROV 模擬器，不連接水下機器。USB-C 直接接電腦即可，不需要網路線。

本次裝置為 Q-iRC / QY665，韌體 RC_V001R003S001。瀏覽器 Gamepad API 未列出此裝置，改由本機 USB ADB 轉接程式讀取遙控器通道。未修改韌體或搖桿校準。

按住功能鍵不會重複觸發；連線時已按住的鍵須先放開再按。網頁可操作功能鍵，USB 模式下搖桿軸由實體遙控器控制，SDK 遠端控制仍保有優先權。USB 斷線或資料逾時會回中並上鎖，重新接通後須再解鎖。

本次 14 項遙控器測試通過；另補強 SDK 優先權測試，與 11 項 SDK 模擬測試一同通過。JavaScript 語法檢查通過，測試瀏覽器未回報錯誤。最後檢查時 USB 已斷線，因此其餘按鍵的實機確認保留至下次。

## 下次啟動

1. 遙控器以 USB-C 接電腦，在原廠 App 選 Sys → Connection mode → Local Data Transfer，若詢問 USB 偵錯則允許。
2. 關閉舊模擬器，再雙擊 `simulator/START_QIRC_SIM.bat`。
3. 開啟或重新整理 <http://127.0.0.1:8080/?nointro>，確認顯示 Q-iRC USB 已連接。
4. 可先按空白鍵解鎖。若續測實體功能鍵，依序確認鎖定、定深、拍照及錄影狀態。

使用期間保持原廠 FIFISH / RCTool 關閉，避免同時讀取通道；以 Ctrl+C 結束轉接程式時會嘗試恢復原廠 App。其他電腦須自行安裝 Python 依賴及 Android Platform Tools；工具與原廠 SDK／APK 不隨此更新上傳。

完整操作說明見 [模擬器 README](../simulator/README.md)。
