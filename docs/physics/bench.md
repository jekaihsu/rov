# 100 Hz 物理操縱基準

這套測試回答兩件事：同一個操縱相較已審查版本改了多少，以及目前有哪些水池或文獻數據可供對照。第一版基準取自 main `ad62e04`。自有資料目前只有合成示例，以下模擬數字都是暫定值。各案例使用 0.01 s 固定步長，含隨機過程的案例固定種子 1947。[資料清冊](../reference/own/README.md)

## 執行與判讀

從儲存庫根目錄執行。Numba 用於編譯正式纜線求解器，Matplotlib 僅用於離線繪圖。

```bash
python -m pip install -r simulator/requirements.txt -r simulator/tools/sysid/requirements.txt numba
python simulator/tools/physics_bench/run.py
(cd simulator && python -m unittest discover -s tests)
node --test simulator/tests/*.mjs
```

預設產物在 `simulator/tools/physics_bench/output/`，可用 `--out <目錄>` 指定位置。每個工況輸出完整逐步 CSV、PNG，另有 `summary.csv`。時間為該步積分結束時刻，coast 另含放桿瞬間。圖上點是版本庫裡的基準，實線是本次執行，四軸虛線是同級載具係數推算。任一超帶時指令以非零狀態結束。單元測試逐案重新建立場景，比對兩次完整數值曲線與摘要，計時另驗預算。

## 工況與比較尺度

除拖纜、全場景與計時外，試驗從 20 m 深靜水開始，隔離纜力與環境干擾。位置使用 NED 公尺，機體速度使用 FRD，角度以 rad 表示。四軸階躍由分配器下達滿幅正向力或力矩，保留馬達延遲與六自由度耦合。

| surge / sway / heave / yaw | 持續 8 s，末秒均值與首次達此值 63.2% 的時間，分辨阻尼及馬達起步改變 | 2.315 / 1.286 / 0.769 m/s、1.571 rad/s；0.34 / 0.26 / 0.15 / 0.09 s。同級水池 Table 4 為 0.72 / 0.63 / 0.71 m/s、3.6 rad/s |
| coast | 從前進滿推穩態鬆桿，保留剩餘馬達推力；記 1 s 速度、20 s 位移及位移達 63.2% 的插值時間 | 0.525 m/s、2.284 m、1.790 s。同級係數從 0.72 m/s 且零剩餘推力推算約 0.30 m，起始條件不同 |
| turn | A 檔定深，先 60% 偏航 8 s，再加 50% 前推 8 s。分別量原地角速率與穩定迴轉的水平速度／航向變化率 | 0.577 rad/s、2.395 m；未找到相同桿量與幾何的水池曲線 |

## 更新參考

1. 新實測依自有資料規格保存原始資料、校正方式與條件，確認 manifest 的 synthetic 標記、軸向、量綱、纜長、供電、初速與控制模式。相同工況優先引用 X1 實測，逐筆保留來源與不確定度。[量測清單](../reference/x1-measurement-checklist.md)
2. 在改動前後各跑一次並保留不同的輸出目錄。先用舊參考判讀超帶項，再比較實測殘差。單純縮小跨機型差距，無法證明 X1 擬真度提升。
3. 需要換版時，針對已核准的案例，用 `checkpoints(result)` 抽出前 20 步與 64 個等距原始步，再用 `write_csv` 寫入該案例的 `curves/<case>.csv`。這些小型數值檔是測試輸入。保留逐步輸出供審查，於 PR 說明前後值、工況、來源與更新理由。
4. 在 `bands.json` 更新基底版本、該指標上下界與理由。初版摘要採基準值 ±5%，時間至少一個 tick，接近零的超越量、末端偏差及能量另有絕對門檻。曲線以各欄基準峰值的 5% 作絕對容差，避免過零點的相對誤差失真。重新執行上述三組指令。CPU 與牆鐘耗時請附 CPU 型號、Python 與 Numba 版本；筆電需在目標硬體另測。

離線工具重用 #111 的一維 `scalar_response` 與 #112 的 `glide_time`。前者產生類比曲線，後者讓放桿標記和水池擬合使用同一個位移定義。[#111 程式版本](https://github.com/jekaihsu/rov/blob/5ace3fc28f0da0836307f25f59f7367914d575f6/simulator/qysim/model_o.py) · [#112 程式版本](https://github.com/jekaihsu/rov/blob/eed103a5ca27d8fa660d377f8f43ee2698ae1781/simulator/tools/sysid/field.py)
