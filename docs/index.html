QYSEA X1 · 操作員訓練

X1 ROV 訓練模擬器

接上和 Q-iRC 同配置的 USB 手把，在電腦上練習下水、在洋流中飛行、避開樁柱與斜撐、處理纜線纏繞，以及在深水沉船旁開燈檢查。模擬器也提供和 QYSEA SDK 相同介面的 mock，團隊原本的 SDK 程式不用改就能對著模擬器跑。

7 + 隨機訓練情境，含碰撞與纜線張力扣分

回放裡有什麼

  1. 導管架碰撞：自動導航直線穿越斜撐高度，撞擊後停航倒退脫離。
  2. 纜線纏繞脫困：開局纜線已繞樁 1.8 圈，反方向繞樁解開。
  3. 強流中樁前懸停：2.5 kn 橫流下導航到樁前 1.5 m 並保持。
  4. Korean Castle 沉船調查：32 m 海床上斷成三截的 150 m 貨輪，下潛時開燈，依格網編號檢查斷裂面、貨艙與艉樓。

自己飛

安裝 Python 3.10 以上，Windows 直接雙擊 simulator/START_SIM.bat；其他系統在 simulator 資料夾執行 pip install -r requirements.txt 和 python -m qysim.server。用瀏覽器開 http://127.0.0.1:8080/，插上手把就能飛。詳細步驟見 README。

工作船、甲板人員模型來自 OpenGameArt 與 Quaternius（CC0），海面與天空使用 three.js（MIT）。Korean Castle 為依海報推估的示意模型，非實測。清單見 CREDITS。
