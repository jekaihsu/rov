QYSEA X1 · 操作員訓練

X1 ROV 訓練模擬器

接上和 Q-iRC 同配置的 USB 手把，在電腦上練習下水、在洋流中飛行、避開樁柱與斜撐、處理纜線纏繞。模擬器也提供和 QYSEA SDK 相同介面的 mock，團隊原本的 SDK 程式不用改就能對著模擬器跑。

觀看訓練回放 原始碼與安裝說明
6-DOF推進器配置與 X1 相同，拉力依規格擬合
0–2.5 kn表層、中層、底層分別設定的洋流與陣風
350 m集中質量纜線：張力、卡纜、繞樁圈數、斷纜
6 + 隨機訓練情境，含碰撞與纜線張力扣分

回放裡有什麼

  1. 導管架碰撞：自動導航直線穿越斜撐高度，撞擊後停航倒退脫離。
  2. 纜線纏繞脫困：開局纜線已繞樁 1.8 圈，反方向繞樁解開。
  3. 強流中樁前懸停：2.5 kn 橫流下導航到樁前 1.5 m 並保持。

自己飛

安裝 Python 3.10 以上，Windows 直接雙擊 simulator/START_SIM.bat；其他系統在 simulator 資料夾執行 pip install -r requirements.txt 和 python -m qysim.server。用瀏覽器開 http://127.0.0.1:8080/，插上手把就能飛。詳細步驟見 README。

工作船、甲板人員模型來自 OpenGameArt 與 Quaternius（CC0），海面與天空使用 three.js（MIT）。清單見 CREDITS。
