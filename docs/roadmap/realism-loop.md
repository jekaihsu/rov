# 擬真改進循環（發散 → 研究 → 收斂 → 實作 → 驗證）

目標：體驗與真實 ROV 一致（見 AGENTS.md）。每一個面向都走同一個循環，由審查者（Claude）自行推進，不需逐項請示。

## 循環

1. **發散**：從研究報告、實測清單、真實影片、使用者回饋、整合審計中找出「與真機不一致」的面向。
2. **研究**：每個面向派 2–4 個研究方向（物理與文獻、業界實務、真實影片觀察、對照本專案現況），筆記放 `research_notes/<主題>/`，彙整報告放 `reports/` 與 `docs/reference/`。
3. **收斂**：依「對訓練真實感的影響 × 可驗證性 ÷ 成本」排序，寫成任務（含驗收標準與文獻依據）。
4. **實作**：派 agent 在獨立分支實作，附測試；X1 專屬參數一律標為暫定。
5. **驗證**：審查者在本機重跑測試與瀏覽器檢查，對照文獻數據或影片量測，合格才合併。
6. **回饋**：需要實機數據的項目補進 `docs/reference/x1-measurement-checklist.md`。
