# 教官手冊

## 開課與每課節奏

使用[課程表](curriculum.md)與[學員手冊](student-manual.md)。所有合格門檻均為
**暫定，待資深操作員基準航次校準**。教材供模擬器課堂使用；T17 教官面板仍為預覽，不宣稱實機訓練驗收或 IMCA 等效。
課前備妥學員名冊、列印考核表、操控器映射、程式版本、場景與種子、錄影及匯出目錄。
教官、駕駛、纜線手、記錄員分工；兼任須記錄，不能由駕駛代答全部閉環通訊。

每課另排 10 分鐘簡報及 15 分鐘講評，不算操桿時數。學員實際操桿 60 分鐘分三組：
第一組分步練習，第二組完整航次與適用的單一故障，第三組獨立考核或重飛。
教官先示範，示範時間另計；觀察員與纜線手輪替時間也不得計成駕駛時數。
每組可包含多個短航次，既有場景期限不變；失敗後收證、講評再重開，不能待機湊時數。
獨立考核不提示解法，安全介入須記錄；學員可隨時要求停止。補強可直接選課，不設通關鎖。

## 進入課程與收證

認證與操作以 [PROTOCOL 教官章節](../../simulator/PROTOCOL.md#optional-instructor-preview-t17-draft)為準。
管理者在內部伺服器設定 `QYSIM_INSTRUCTOR_CODE`；不可將密碼寫入 URL、教材、日誌或成績。

1. 房主先建房，在工程面板「章節 / 訓練課程」選 B01–A04，勾「公司課程（略過故事）」啟動。
   先不要登入教官監督，因監督中 `campaign_start` 會被拒絕。
2. 教官打開 `/instructor/instructor.html`，輸入既有房間 ID 與密碼，確認能看到載具。
   學員設真實模式、第一人稱並關閉額外輔助；記錄實際配置，檢查殘留設定覆寫。
3. 開始錄影與人工計時，每階段設定 phase 與 reference。JSON 不會自動切教官 phase。
4. 完成、失敗或中止後，先匯出教官 JSON／CSV、課程成績、照片與錄影，附考核表。
   以日期、匿名學員 ID、課號、航次、設定版本命名，存公司內部空間，不上公開倉庫。
5. 換課前收證，由教官 reset 結束本次採樣與覆寫，退出監督，再由房主選課並重新監督。
   確認沒有仍在作用的故障；存檔恢復航次另標練習，不與獨立考核混算。

只有監督連線或覆寫作用中才採樣，約每秒一次；每台最多保留最近 3600 筆、最多 16 份封存報告。
每短航次立即匯出，不能等整天結束。B01 水池無場景目標，Scorer 可能提前完成並封存，
因此 B01 以互動歷程、錄影與人工表評核，不用空白／短矩陣判合格。

## 評分方式與限制

phase 用 descent、transit、hover、orbit、dock 對應下潛、轉場、懸停、繞行、回收接近。
每階段設定 NED `target`、`path_start`、`heading`（度）、`depth`、`distance`、`speed_min/speed_max`（SI）。
預設航向取當下航向會掩蓋誤差，預設目標在投放點也不適合巡檢，必須明確設定。

| 證據 | 實作與判讀 |
|---|---|
| 場景 Scorer | 完成比例 × 100 再扣碰撞及過張力；斷纜、三次嚴重碰撞、逾時失敗。查 finished 和 failed，有失敗優先；此為既有場景規則，非公司資格門檻 |
| 課程 completed | 腳本結束；失敗分支也可走完，匯出 completion 可能仍為 1，不等於合格 |
| 矩陣 | 五階段分 still/current；`current_kn > 0.1` 是分組條件，不是安全流速或 X1 能力 |
| 誤差 | path 為水平到有限線段距離；heading 為角度差；depth 為深度差；hover 為水平到目標距離；distance 為三維距離減設定值；speed 為超出速度區間的量 |
| 顏色 | 綠：outside_fraction ≤ 0.1 且 RMS ≤ 容差；黃：比例 ≤ 0.3 且 RMS ≤ 2 倍容差；其餘紅。null 是無樣本，不是綠 |
| 平順度 | 記錄六軸變異數、過零、反桿；最大軸變異數 ≤ 0.25 綠，≤ 0.5 黃，其餘紅。過零與反桿不直接決定顏色 |
| 反應時間 | reaction_s 只是注入後第一個控制封包內容改變，非正確恢復；另人工記辨識、通報、正確動作時間 |
| 張力 | 教官 max_tension 是採樣載具端張力，Scorer 用纜線最大張力；不可互換，採樣也可能漏掉瞬時峰值 |

`instructor.py` 預設容差：path 2 m、heading 15°、depth 1 m、hover 1 m、distance 1 m、speed 0.3 m/s，
初始 still/current 相同。上述色階及容差全部是**暫定，待資深操作員基準航次校準**的軟體預設，非 X1 性能。
教官可送 `limits` 設兩種流況容差；reference 協定沒有修改 `grade_limits` 的介面。
若需不同色階規則，先在紙本以核准規則人工判讀，不改程式。照片品質、回收上鎖與通訊須人工查核。

## 故障注入建議

先無額外故障基準航次，再另次單一故障；初學預告，考核可只告知故障種類。
先在空課室確認注入、恢復與停止操作；記載具 ID、種類、強度、起止、環境與介入。
以下數值僅為教學試跑建議，待資深操作員確認，非 X1 故障程度或合格門檻。

| 課程 | 建議 | 觀察與限制 |
|---|---|---|
| B01–B04 | 無實體注入；B03 口頭報纜線偏緊 | 觀察是否先確認線路，不假稱真實張力改變 |
| I01 | 另次 visibility strength 0.3、duration 20 秒 | 全房間能見度為原值 × (1−強度)，最低 0.1 m；看減速、調燈與退出 |
| I02 | thruster，確認 index 後 strength 0.25、duration 15 秒 | 健康度依原值衰減；DVL 失鎖只用口頭通報 |
| I03–I04 | 沿用事故情境，不疊加 | 揚沙固定低能見度；羅盤讀數不會真的偏移 |
| A01–A02 | 預設強流／預纏；口頭人手不足、信標風險 | 無磨纜累積、細線收結、信標耗電模型 |
| A03 | 固定強流情境 | 無隨時間轉強或結構背流模型 |
| A04 | 標準航次後另次 thruster strength 0.25、duration 15 秒 | 失聯、供電、漏水僅桌上口試，不用 battery 冒充 X1 岸電 |

引擎另支援 current（strength × 4 節、各層方向保留、全房間）、battery、freeze。
freeze 是暫停載具，不是凍結影像；battery 是模擬電量，非岸電故障。這些不當作本課實機故障證據。
同類同範圍重疊覆寫會拒絕；到期恢復原值，不能把自動恢復記成學員修復。
遇失控、斷纜、危險程序或要求停止，暫停、收證、講評、reset，不等耗完課時。

## 如何以資深操作員基準航次訂門檻

1. 凍結版本、場景、種子、操控器映射、模式、輔助、影像延遲、流況、能見度、纜長與每階段 reference。
   依[實測清單](../reference/x1-measurement-checklist.md)補 X1 實機數據；缺項仍暫定。
2. 資深操作員飛全部技能與事故課，分無流／有流；建議至少兩位各三次作為內部起始設計，非外部標準。
   保存成功、失敗與合理中止，不挑最好一趟。某階段無樣本或不可重複，標證據不足並補飛。
3. 按課號、階段、流況、設備設定分組，比較 RMS、超限比例、最大偏差、張力、碰撞、平順度與照片。
   程序由教官依時間戳評核；合理中止不應因任務未完成一律判能力不合格，但任務技能要另補考。
4. 以安全且可重複的基準分布（中位數、範圍、較差尾端）及任務允許誤差提出候選容差，記理由。
   不照抄預設、不把專家失誤當標準；無流／有流分開訂。
5. 保留部分基準航次與中階操作員航次作交叉驗證，由另一教官盲評；檢查錯放危險程序與錯拒合理中止。
   調整後重驗，記版本與簽核。樣本不夠則保持暫定，不能湊出看似精確的數字。
6. 訓練負責人核准後才發布內部門檻表，保留原始檔、日期、適用配置與採用理由。
   本次所有門檻仍標「暫定，待資深操作員基準航次校準」；物理或配置改變後重新驗證。

## 每課講評與補訓

B01 問解鎖閘門；B02 解釋漂移；B03 重畫纜路；B04 獨立交班。
I01 看照片定位；I02 問中止時機；I03 找失去可信視野時間；I04 核對退出定向與通報。
A01 討論人手與信標；A02 辨識會加緊纏繞的動作；A03 找最早可中止時點；A04 交接最後位置、失效範圍與已採措施。
學員先講理由再回看證據，選一個具體動作重練。考核結論用「暫定通過／需補訓／證據不足」，
不以總分抵銷危險程序；補訓寫課號、動作、所需證據、複核日期，不覆寫原紀錄。
