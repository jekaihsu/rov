# 學員手冊

## 課前約定

先讀[課程表](curriculum.md)。每航次報姓名、課號、角色、機型設定與輔助狀態。
所有合格門檻均為「暫定，待資深操作員基準航次校準」。X1 專屬參數一律暫定。
本冊提供可演練的程序骨架；實機使用前必須把原廠手冊、公司核准 SOP 和現場風險評估補齊。
不以模擬器顯示的速度、深度、張力或供電讀數決定實機安全範圍。

## 1. 基本原理與操控模式

ROV 由推進器提供推力，水阻力、慣性、浮力、重心與浮心、洋流和臍帶纜共同決定運動。
前後、左右、上下是平移；橫滾、俯仰、偏航是旋轉。機體前方會隨艏向改變，不能把畫面右方永遠當作東方。
模擬世界使用北、東、下座標；深度增加是下潛。每次換控制配置先在安全水域逐軸確認方向、回中與上鎖。

手動水平推桿表示推力，不是指定速度；鬆桿後仍可能滑行、隨流漂移或被纜線拉回。
短小輸入後觀察反應，避免因影像延遲連續加桿再大幅反桿。相機只有有限視野，畫面外仍有障礙。
光線衰減、背向散射與揚沙會降低辨識能力；燈開最亮不一定看得最清楚。

| 功能 | 能做什麼 | 操作時要確認 |
|---|---|---|
| 手動推力 | 控制各軸推力 | 鬆桿不代表停住；先預留退路 |
| 定深 | 閉迴路維持深度 | 不是維持離底高度，也不保持水平位置 |
| 定向／姿態保持 | 依感測器維持方向或姿態 | 鋼構旁羅盤可不可信；交叉看目視與纜向 |
| DVL 定點 | 有有效量測與足夠推力時保持位置 | 失鎖或推力飽和時不可繼續假定站位可靠 |
| 模擬器速度／定點輔助 | 改變操桿語意、主動煞停或保持位置 | 屬訓練輔助；正式考核關閉，使用時記錄 |

X1 的 A/S/C 名稱是否適用、定深與俯仰的關係、鬆桿是否自動定點、DVL 失鎖降級方式、
控制器鍵位與曲線均為暫定，不能把其他機型的設定背成 X1 的事實。
教官示範用第三人稱時要標記；個人考核使用機載第一人稱、真實模式，確認沒有殘留設定覆寫。

## 2. 纜線管理

纜線手與駕駛分工：駕駛報方向、深度、目標和退路；纜線手報放纜量、出纜方向、鬆緊、卡點與水面危險。
只放到達工作區且能操控所需的纜線；過短會拖曳載具，過長會增加橫流阻力與勾纏機會。
報數間隔在簡報時約定，轉向、繞構件、張力突增或水面危險立即報，不等固定間隔。

出發前畫出投放點、目標、流向、禁入區及回航路線。接近樁或船殼先說明纜線會落在哪一側，
繞行後確認是否增加纏圈，避免一圈接一圈。不要把張力警報當作可承受拉力的證明。
張力上升先減少會加緊纜線的動作、通報並確認卡點；可移動且退路清楚才沿已知路線返回。
禁止盲目加推、硬拉或自行切纜。配重、纜線起吊能力及收納方式依公司核准設備程序，不能照搬其他機型。

## 3. 下水與回收口令演練

以下每一步由指定責任人確認，記錄於考核表。桌上演練不代表已驗證 X1 實機上電或吊放程序。

1. **任務閘門**：督導確認人員、作業區、天候與流況、船舶／潛水員協調、退出條件及緊急聯絡。
   任一條件不明就暫停；不使用廠商宣稱抗流能力當現場許可值。
2. **設備閘門**：按核准清單檢視結構、密封、接頭、纜線固定與外皮、推進器異物、供電保護、影像與記錄。
   電氣檢查與接拆線由合格人員依 SOP 執行；本冊不提供推測的 X1 岸電接線次序。
3. **控制閘門**：保持上鎖，核對操控配置、深度零點與姿態、通訊、影像、緊停與紀錄狀態。
   不以其他機型「可空轉若干秒」規則測試 X1；功能測試依已核准方法。
4. **下水閘門**：纜線手確認通道清楚；按核准吊點、吊具與施放程序入水，不拋擲、不擅用臍帶纜起吊。
   施放者離開推進器危險區且回報後，督導允許解鎖。駕駛覆誦並小幅試操，確認配平與可控性。
5. **作業閘門**：報位置、深度、艏向、流況、纜線與剩餘作業裕度；保持退路。異常先中止任務目標，再評估回收。
6. **回收閘門**：確認返航路線與收纜協調，回投放區；在甲板人員接觸載具前上鎖並確認推進器停止。
   按核准程序吊回、隔離能源、停止／保存記錄。不得要求人員接近仍可能啟動的推進器。
7. **潛後閘門**：按設備手冊清洗、檢查纜線與密封、整理收納、記錄異常並隔離疑似故障設備。
   清洗時間、乾燥方法與維護週期都是 X1 待確認項，不套用其他機型數字。

## 4. 常見事故與正確處置

共同次序：辨識並通報 → 停止加劇危險的操作 → 確認人員、位置、能源、纜線與感測器 →
提出可控撤離方案、覆誦 → 執行或停等督導接管 → 保存證據。中止是可接受的專業決策。

| 情況／課號 | 立即行動 | 不應做的事與能力邊界 |
|---|---|---|
| 揚沙／I03 | 減少擾底，調整燈光；交叉核對深度、可信航向、已知纜路，必要時聲納輔助；無可信路線則停止盲航並通報 | 不因畫面白霧繼續向前；情境最低能見度 1 m，並非真正零視野 |
| 羅盤失準／I04 | 通報航向不可信，退出不可靠定向；依目視與纜向後退離開鋼構，重新確認感測器 | 不追逐跳動指示；本題僅通報，儀表不會真的偏移 |
| 導管架受困／A01 | 及早中止，確認開放出口、纜線避開構件；人手不足時不繼續作業 | 不硬守、不磨纜；信標管理與人員不足用口頭演練 |
| 沉船勾纏／A02 | 先評估；能動且路線清楚時沿纜返回卡點，確認方向後反向解纏；不能解就交由督導安排救援 | 不從水面盲拉使結更緊；模型只模擬繞樁，非細線收結 |
| 強流站位失守／A03–A04 | 報持續漂移與推力不足，及早放棄目標，按已確認路線撤離與回收 | 不持續滿推硬守；無結構尾流保護模型，情境流速非真機極限 |
| 推進器異常／I02 延伸 | 報異常軸向與可控性，減少任務負荷，在可控條件下撤離 | 不水中拆修；卡異物後按核准隔離程序檢查 |
| 影像／通訊／供電異常／A04 口試 | 報最後可信位置、時間、纜向及失效範圍；停止盲操，通知督導與電氣人員，按核准失聯回收計畫處置 | 不假定斷線會自返、不盲拉、不帶電拔插；不背誦未驗證的恢復時間 |
| 漏水／過載警報／A04 口試 | 中止任務、通報、評估受控回收；按 SOP 隔離能源與設備 | 不消警後繼續、不自行拆開帶電設備；警報條件為 X1 暫定 |

導管架與沉船課取材自研究報告中的匿名事故；其他題是典型險情，不虛構事故細節。
真實切纜、潛水員介入或另機救援必須另作風險評估及授權，不是本課程的學員操作項目。

## 5. 通訊用語與課後自查

使用「呼叫對象＋本台＋狀況＋請求／動作」，接收者覆誦關鍵指令，發話者確認。方位說清楚是機體或地理方向。
數字附單位；不懂就要求重述，沒有覆誦不推定已執行。任何人均可喊「停止作業」。

| 發話 | 覆誦／閉環 |
|---|---|
| 「纜線手，駕駛：準備向機體右側移動，請確認線路。」 | 「駕駛，纜線手：線路清楚，可右移。」駕駛：「收到，開始右移。」 |
| 「督導，駕駛：站位持續漂移，申請中止並沿已確認路線回收。」 | 「駕駛，督導：中止，確認纜線後回收。」駕駛覆誦並報開始時間。 |
| 「全體：停止作業，纜線疑似卡住。」 | 駕駛：「停止增加推力，待評估。」纜線手：「停止拉纜，確認卡點。」 |
| 「督導，纜線手：載具入水，人員已離開危險區。」 | 督導：「允許解鎖。」駕駛：「收到，解鎖並確認狀態。」 |
| 「纜線手，駕駛：已上鎖，推進器停止，請確認後回收。」 | 纜線手確認狀態並覆誦，依核准程序接觸載具。 |

課後用自己的錄影指出：一次正確中止、一次不必要反桿、一次纜線風險、下一航次要改的一件事。
自測：為什麼鬆桿仍漂移？定深和定點差在哪？為什麼濁水不能只加亮燈？卡纜為何不能硬拉？
答題要指出可觀察證據與下一步，不能只背「注意安全」。
