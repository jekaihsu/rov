# T09 多語系（繁中／簡中／英文）

**排程**：第二波。等 T04、T06 合併後再開始，否則會與它們大量衝突。

**目標**：Steam 發行至少需要英文與簡體中文。所有使用者可見字串集中管理、可即時切換語言。

**範圍**：新增 `simulator/viewer/i18n/`（`index.js`、`zh-Hant.json`、`zh-Hans.json`、`en.json`）；所有前端檔案中的硬編碼字串；後端回傳給玩家看的訊息（情境名稱與簡報、任務訊息、錯誤訊息）改為回傳訊息鍵與參數，並保留原文字欄位以維持相容。

**要做**

1. `t(key, params)`，支援參數插值與複數；缺鍵時退回繁中並在開發模式於 console 警告。語言來源優先順序：使用者設定 → Steam 語言（桌面版由主行程傳入）→ 瀏覽器語言。
2. 抽出所有字串。HTML 靜態文字用 `data-i18n` 屬性。各模組先前放在 `STRINGS` 物件的內容搬入語系檔。
3. 後端：`scenarios.py`、`mission_modes.py`、`expedition.py`、`operations.py` 等產生的名稱與訊息新增 `*_key` 與 `params`，前端優先用鍵翻譯。協定既有文字欄位不移除。更新 `PROTOCOL.md`。
4. 英文由母語水準撰寫，術語統一並附術語表 `docs/design/glossary.md`（例：臍帶纜 tether、定深 depth hold、解鎖 arm、上鎖 disarm）。簡中不是機械轉換，用語依大陸習慣（手柄、摄像头、分辨率）。
5. 數字、單位、時間格式依語系；提供公制／英制與節／公尺每秒的單位設定。
6. 字型：三種語言都能正確顯示，中文退回系統字體；版面在英文較長字串下不破版。
7. CI 檢查：三個語系檔的鍵集合一致；`simulator/viewer` 內（vendor 除外）新增的 CJK 字面值會使檢查失敗（語系檔與註解除外）。

**驗證**：三種語言各附主選單、HUD、設定頁截圖。所有 `browser_*smoke.py` 通過（腳本若依賴中文文字比對，改為依賴 id 或 `data-i18n` 鍵）。
