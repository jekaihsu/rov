# T04 飛行 HUD：全幅畫面與極簡儀表

**目標**：把「兩欄表單夾著一個視窗」改成全幅 3D 加疊層 HUD。必讀 `docs/design/ui-direction.md`。

**範圍**：`simulator/viewer/index.html`、`style.css`、新增 `simulator/viewer/hud/`（模組與 `hud.css`、`tokens.css`、`icons.svg`）；`app.js` 只改 HUD 更新呼叫處。可調整 `cockpit.js`、`attitude_indicator.js`、`mission_panel.js`、`pilot_guide.js`。不改 `main_menu.js`／`menu.css`（T06），不改輸入（T02）與鏡頭（T03）。

**要做**

1. 3D 畫布全視窗、無邊框。建立 `tokens.css`（設計文件中的變數）供全站共用。
2. 依設計文件「版面」實作飛行 HUD：航向帶、深度尺與離底高度、小型姿態／俯仰梯、底部資訊帶（速度、纜線長度與張力狀態、電量）、模式膠囊列（輔助等級、檔位、定深、燈光、鎖定；讀 `state.assist`，欄位不存在時隱藏該膠囊）、任務單行提示、三級警告。
3. **小地圖**：俯視，顯示自己（含朝向）、隊友、纜線走向、任務目標、已知結構輪廓；可切換北朝上／機頭朝上。用 2D canvas，不另開 WebGL。
4. **障礙距離**：前方測距與離底高度低於門檻時，顯示距離條並分級變色。
5. **速覽卡（peek）**：依設計文件實作四張由十字鍵／數字鍵 1–4 呼出的速覽卡：按一下顯示 3 秒自動淡出、按住持續、事件觸發自動跳出。T02 未合併時先直接讀標準配置的十字鍵（索引 12–15），寫成之後可替換的單一函式。
5a. 現有左右兩欄的**所有功能**移入「工程面板」抽屜，預設收起，Tab 鍵開關，記住狀態。內容可重新分組為分頁（任務／環境／載具／纜線／紀錄），但不得刪功能；現有元素 id 盡量保留，因為 `simulator/tools/browser_*.py` 依賴它們。若必須改 id，同步修正那些腳本。
6. 虛擬搖桿僅在觸控輸入時顯示。
7. 讀數以每幀插值顯示，數字用等寬數字。面板進出動效依設計文件。
8. 提供 HUD 密度設定：極簡／標準／完整（完整接近現在的資訊量，給訓練用）。另有「隱藏 HUD」動作供截圖。
9. 1280×720、1920×1080、2560×1080、3440×1440 版面皆正確。手機直立回放版面（現有功能）不可壞。
10. 回放模式、觀看者模式、SDK REMOTE 提示、Q-iRC 連線提示、下水動畫的「跳過」都要在新版面中有位置。

**驗證**：跑 `simulator/tools/` 下所有 `browser_*smoke.py` 並在 PR 列出結果。附四種解析度截圖與一張抽屜展開的截圖。
