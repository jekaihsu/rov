# T12 劇情戰役與新手教學

**目標**：玩家第一次進遊戲就有故事帶著走：先教學、再一章一章解鎖任務。內部訓練版可用同一套系統編排課程。

**範圍**：新增 `simulator/qysim/campaign/`（腳本執行、觸發條件、進度）、`simulator/viewer/story/`（對話、字幕、教學提示、章節選單）、`simulator/campaign/*.json`（章節資料）。任務判定沿用 `scenarios.py`／`mission_modes.py`／`expedition.py` 既有機制，不重寫。

**故事設定（原創，可調整細節，不可換成既有作品的設定）**

玩家是剛加入一家小型海事工程公司「潮間帶工作隊」的 ROV 操作員。隊上只有一艘舊工作船、一位嚴格但護短的資深督導（無線電裡的主要聲音）、一位負責纜線的甲板手。公司靠接零星的檢查案維生。

- **序章｜水池**：室內測試水池。學解鎖、六個方向、定深、燈光、拍照。
- **第一章｜港灣**：碼頭樁與船殼檢查。學貼近結構、纜線管理、能見度差時的操作。
- **第二章｜離岸**：風場導管架與單樁。學強流、定點、陽極塊巡檢。第一次纜線纏住，要自己解開。
- **第三章｜礁區**：替研究單位做生態調查與儀器部署。學機械臂、回收與部署、圖鑑攝影。
- **第四章｜沉船**：例行調查中在 32 m 的貨輪殘骸發現不在紀錄上的東西；後續幾次下潛逐步拼出這艘船沉沒的原因。深、暗、窄，綜合所有技巧。
- **終章**：一次有時限的夜間回收作業，三人協作可選。結局依前面的調查完整度有兩種。

每章 3–5 個任務，每個任務 5–15 分鐘。敘事靠無線電對話、任務簡報、拍到的照片與打撈物，不做過場動畫。

**要做**

1. **腳本格式**：JSON，資料驅動。節點類型：對話、等待條件、設定目標、提示操作、生成／移除物件、切換環境參數、分支、給予獎勵、存檔點。條件可引用既有狀態（位置、深度、速度、模式、拍照結果、纜線張力、碰撞、任務目標完成）。附 JSON Schema 與驗證測試。
2. **執行器（後端）**：每個房間一個戰役執行個體，狀態進 `state.campaign`（目前章節、節點、目標、對話佇列）。協定新增以 operation 封包啟動／推進／跳過。多人時由房主推進，隊友同步看到對話與目標。更新 `PROTOCOL.md`。
3. **對話呈現（前端）**：無線電風格字幕條（說話者、頭像圖示、文字逐字出現），可用確認鍵快轉、可回看紀錄。不擋住飛行視野，不搶輸入。預留語音檔欄位（目前無配音）。所有文字走語系鍵（T09 之前放 `STRINGS`）。
4. **新手教學**：序章為互動式教學：一次只教一件事，畫面上以目前裝置的按鍵圖示提示（T02 的 glyphs；未合併時用文字），偵測到玩家確實做到才往下。做錯不扣分，督導會用不同台詞再說一次。可從設定重玩，可跳過。教學預設開啟定點輔助（assist 2），第二章再介紹手動模式。
5. **進度與解鎖**：章節選單、每任務評價（時間、碰撞、纜線、完成度）、解鎖新載具與貼紙。存檔放在既有偏好／收藏的儲存位置。
6. **首批內容**：完整做出序章與第一章（可玩、有全部台詞），其餘章節先放大綱與空殼節點。台詞自然、簡短、有人味，不要說明書語氣。
7. **課程模式**：同一格式可編排公司內部訓練課表（不帶故事），並輸出學員成績 JSON。

**測試**：腳本執行器的單元測試（條件觸發、分支、存讀檔、多人推進、斷線重連後狀態一致）。序章以自動化輸入可跑完的整合測試。附序章與第一章的遊玩錄影。
