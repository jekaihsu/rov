# T01 飛行輔助控制器（後端）

**目標**：讓 ROV 飛起來像消費級空拍機一樣穩：推桿給速度、鬆桿煞停、定點抗流。只動控制層，不動物理。

**範圍**：`simulator/qysim/controller.py`、`rc.py`、`engine.py`、`room.py`／`server.py`（僅傳遞欄位）、`simulator/tests/`、`simulator/PROTOCOL.md`。不得修改 `physics.py`、`tether.py`、`world.py`、前端。

**背景**：目前 `FlightController.update` 姿態有閉環，但平移是開環推力（`force = [surge, sway, 0]`）。鬆桿後靠水阻滑行並被洋流帶走。

**要做**

1. 依 `AGENTS.md`「共用契約：飛行輔助」實作 `assist` 0／1／2 與 `profile` cine／normal／sport，欄位與 `state.assist` 結構完全照契約。
2. `assist >= 1`：搖桿（經曲線後）為機體座標速度設定值。設定值先經**加加速度受限**的整形（S 曲線起步與煞停），再由速度 PI 控制器產生推力。速度回授用引擎已有的對地速度（DVL 語意）。A／C 模式下速度指令以「航向對齊、水平面內」的座標解讀，機身俯仰不應讓前進變成下潛。
3. `assist == 2`：三軸平移指令都低於門檻且速度降到 0.05 m/s 以下時，鎖定當下對地位置；位置 PD 外迴圈加積分項抵抗穩定洋流。任何平移輸入立即解除鎖定。與既有定深、導航（H_NAVI／V_NAVI）的優先順序：導航 > 輔助；定深開啟時垂直軸交給既有定深。
4. 三個檔位只改參數（速度上限、加速度、加加速度、偏航角速度上限、曲線）。參數依機型推進能力比例縮放（用 `vehicle.authority` 與既有極速規格），不可寫死單一機型。偏航在 `assist >= 1` 時同樣做角加速度限制。
5. 推力飽和時不要積分暴衝（anti-windup），並把 `state.assist.limited` 設為 true。
6. 失效保護、上鎖、SDK 遠端控制、斷線重連時，輔助狀態與積分器清零，行為與現行一致。
7. `assist` 未提供或為 0 時，輸出必須與現在逐位元相同（加一個回歸測試鎖住這點）。

**測試（必附）**

- 階躍推桿：速度無超過 10% 的過衝，達 90% 設定值的時間在檔位規格內；加速度曲線連續（相鄰步差有上限）。
- 鬆桿：normal 檔從全速到 0.05 m/s 以內的時間與距離有上限，且不反向倒退超過 5 cm。
- 定點：0.5 kn 穩定側流下 30 s，位置誤差收斂到 0.15 m 內；2.5 kn 超出能力時 `limited` 為 true 且不發散。
- 三種機型各跑一次以上測試。
- 既有 108 項測試全過。

**交付**：PR 內附一張圖或一段數據，對比 assist 0 與 2 在「推桿 2 秒後鬆開」下的速度曲線。
