# T21 纜線作業：纜線手、扭轉計數、勾纏脫困評分

**目標**：研究報告指出纜線是真實操作的一半。把「管纜」做成有回饋、可評分的作業。依據 `docs/reference/real-rov-research.md` 的臍帶纜與事故章節。

**範圍**：新增 `simulator/qysim/tether_ops.py`（只讀取 `tether.py` 的狀態，不改其求解器；T19、T20 正在動 `tether.py`）、`simulator/viewer/tether/`、`simulator/tests/`、`PROTOCOL.md`。

**要做**

1. **纜線手（甲板上的隊友）**：依放纜長度約每 5 m 報數、張力升高與纜線接近結構時以無線電字幕提醒（沿用 T12 的對話呈現）。可由 AI 擔任，多人時可由另一位玩家擔任並手動收放纜。
2. **扭轉計數**：累計載具相對纜線的淨旋轉圈數，顯示在系統速覽卡；超過門檻時纜線產生扭矩並提醒反向解開。
3. **勾纏偵測與脫困評分**：辨識纜線繞過結構的狀態；評分依真實程序：不硬拉（拉力峰值）、掉頭沿纜線回到卡點、正確方向解開、耗時。硬拉導致結拉緊時難度上升。
4. **放纜紀律**：放纜過多（水中鬆弛量）與過少（張力）都計入成績；下水時在上游側、保持視線的提示。
5. **重物（clump weight）**選項：纜線在載具後方數公尺處加配重，影響纜線走向（用既有節點質量參數設定，不改求解器）。
6. `state.tether_ops` 為選填欄位，更新 `PROTOCOL.md`。

**測試**：扭轉計數、勾纏判定與評分的單元測試；既有 `tether_untangle` 情境以自動輸入跑出「正確程序高分、硬拉低分」。附截圖。
