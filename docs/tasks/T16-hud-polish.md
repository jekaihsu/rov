# T16 HUD 修正與打磨

**目標**：修掉 T04、T12 合併後發現的問題。小任務，一個 PR。

**範圍**：`simulator/viewer/hud/`、`simulator/viewer/story/campaign.js` 的版面、相關 smoke 腳本。不新增功能。

**要做**

1. **回放列被 HUD 擋住**：回放模式下 HUD 元素覆蓋回放控制列，按鈕點不到。修正層級與 pointer-events，並加一個瀏覽器測試：回放模式下以真實點擊操作播放／暫停。
2. **劇情對話框擋住載具**：對話框目前在畫面中央偏下，正好蓋住追蹤視角的載具。移到不遮住載具與航向帶的位置，寬度不超過畫面 45%。
3. **工具按鈕列**（工程／標準／切換 HUD／視角）改為圖示加提示，預設半透明，滑鼠移入或手把呼出才完全顯示。
4. **模式膠囊**：「馬達鎖定」在鎖定時要夠醒目並附解鎖按鍵提示（新手最常卡在這裡），解鎖後縮小。
5. 檢查所有 HUD 文字是否都在 `STRINGS` 內。
6. 逐一檢視 `docs/design/ui-direction.md`「驗收方式」的三個問題，在 PR 描述回答。

**驗證**：`browser_hud_smoke.py`、`browser_menu_smoke.py`、`browser_campaign_smoke.py` 通過；附 1280×720 與 1920×1080 的飛行、回放、劇情對話截圖。
