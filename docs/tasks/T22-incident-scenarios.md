# T22 真實事故情境

**目標**：把研究報告中細節足夠的真實事故與典型險情做成訓練情境。依據 `docs/reference/real-rov-research.md` 的事故章節。不得使用真實公司、人員或船名。

**範圍**：`simulator/qysim/scenarios.py`（只新增情境）、`simulator/campaign/`（腳本）、`simulator/tests/`。不改物理。

**要做**

1. **導管架內受困**：潮流轉強，載具在導管架內，纜線貼著構件磨損。玩家要判斷中止時機、選對出口、不讓纜線繼續磨。人手不足與定位信標電量作為情境壓力（以事件與字幕呈現）。
2. **沉船勾纏**：深處纜線勾到殘骸上的繩索，硬拉會越拉越緊。正確解法是沿纜線回到卡點反向解開。
3. **零能見度迷航**：觸底揚沙後完全看不見，只剩羅盤、深度與（若有）聲納；任務是沿纜線回到出發點。
4. **鋼結構旁羅盤失準**：靠近大型鋼構時航向讀數偏移，定向功能不可信；玩家要改用目視與纜線走向（若 T20 的羅盤偏差尚未合併，以情境腳本注入偏差）。
5. **流速超過能力**：定點守不住，要判斷收回或改到背流側。
6. 每個情境：簡報、目標、評分項、失敗條件、結束後的講評文字（說明真實案例中發生了什麼、正確程序是什麼）。全部以 T12 的戰役腳本格式撰寫，可單獨從訓練選單進入。

**測試**：每個情境可載入、可完成、可失敗的自動化測試；腳本通過 schema 驗證。附每個情境的截圖。
