# T05 音效系統

**目標**：目前完全無聲。加入有層次的水下聲音，讓操作有回饋、深度有氛圍。

**範圍**：新增 `simulator/viewer/audio/`；`app.js` 僅加入初始化與每幀 `audio.update(state)` 呼叫；設定頁加入音量滑桿。不改後端。

**要做**

1. `audio/engine.js`：Web Audio，主音量與分軌（載具、環境、介面、警告）音量，設定持久化。瀏覽器需使用者手勢後才啟動音訊，處理好；分頁隱藏或暫停時淡出。
2. **推進器**：依各推進器實際輸出（`state` 內的推進器數值）即時合成，音高與音量隨轉速，正反轉音色略不同，數顆疊加不爆音。優先用合成（振盪器加濾波噪音），不依賴取樣檔。
3. **環境**：水下底噪隨深度變悶變暗（低通截止頻率隨深度下降）；水面附近有波浪聲並在出入水時交叉過渡；洋流強時有流水聲；生物點綴聲稀疏隨機。
4. **事件**：碰撞（依 touch／hard／severe 分級）、纜線張力警告、斷纜、解鎖／上鎖、定深開關、拍照快門、燈光切換、任務完成、警告嗶聲（分級，不刺耳）。事件來源用狀態變化偵測，不要求後端新增欄位。
5. **介面音**：選單移動、確認、返回。短、輕、一致。
6. **空間感**：其他玩家載具的推進器聲用 `PannerNode` 依相對位置定位；聽者跟隨目前鏡頭。機載視角與第三人稱的混音不同（機載時機身聲較貼近）。
7. 若使用取樣檔：僅限 CC0，單檔小於 300 KB，OGG 格式，總量小於 3 MB，逐檔寫入 `CREDITS.md`。
8. 回放與電影模式同樣發聲；`render_movie.js` 離線渲染不需要聲音，但不得報錯。
9. 提供「靜音」動作與 `?mute` 參數（自動化測試用）。

**測試**：狀態到音訊參數的映射寫成純函式，用 `node --test` 測（轉速到頻率、深度到截止頻率、事件偵測不重複觸發）。跑 `browser_smoke.py` 確認無 console 錯誤。PR 附一段 30 秒含聲音的錄影。
