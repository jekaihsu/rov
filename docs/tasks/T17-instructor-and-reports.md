# T17 教官台與訓練成績

**目標**：公司內部訓練用。教官可以即時出狀況考學員，下潛結束有可存檔的成績報告。

**範圍**：新增 `simulator/qysim/instructor.py`、`simulator/viewer/instructor/`（獨立頁面 `instructor.html`）、`simulator/tests/`、`PROTOCOL.md`。Steam 版不包含此頁。

**要做**

1. **教官連線**：以教官身分加入房間（需教官碼，由啟動伺服器的人設定；不佔玩家席位與載具）。可看所有學員的視角、姿態、推進器、纜線狀態。
2. **即時注入**（每項可指定對象、強度、持續時間，並寫入事件紀錄）：推進器失效或推力下降、洋流突變、能見度驟降、纜線卡住、電量驟降、感測器失效（深度、羅盤、測距）、影像延遲或中斷、燈光故障。全部走既有的物理與狀態，不另寫假邏輯。
3. **情境控制**：暫停、重置、換情境、把學員載具移回起點、凍結單一學員。
4. **成績報告**：每次下潛自動產生：任務完成度、時間、碰撞次數與嚴重度、纜線最大張力與纏繞、深度與航向保持的誤差統計、對注入狀況的反應時間、操作平順度。輸出 JSON 與可列印的 HTML；可匯出軌跡 CSV。
5. **課表**：沿用 T12 戰役腳本格式的課程模式，一份課表由多個情境與預排的注入事件組成，產生總成績。
6. 教官的操作不得被學員端取消或偽造；教官碼不寫入日誌。

**測試**：每種注入的後端測試（狀態確實改變、到期恢復、寫入紀錄）；權限測試（無教官碼不可注入）；報告欄位的單元測試。附教官頁截圖與一份範例報告。
