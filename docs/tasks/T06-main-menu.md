# T06 主選單與前台流程重做

**目標**：主選單像一款遊戲的開場，而不是一張表單。必讀 `docs/design/ui-direction.md`。

**範圍**：`simulator/viewer/main_menu.js`（重寫，拆成 `simulator/viewer/menu/` 下多個模組）、`menu.css`、`index.html` 中選單區塊、`scene_previews.json` 與 `tools/build_menu_previews.py`（需要時）。不改飛行 HUD（T04）與遊戲內邏輯。

**背景**：現在右側是一長串下拉選單與說明小字，要捲動；「機型」是三顆小按鈕；設定與連線混在同一欄。`main_menu.js` 是 100 行高度壓縮的程式，請依 `AGENTS.md` 風格重寫。

**要做**

1. **流程**：標題畫面 → 主選單（開始潛航／多人／圖鑑與收藏／設定／離開）→ 選模式 → 選載具 → 選海域 → 簡報 → 下水。每步一個全幅畫面，背景是持續的即時 3D 場景，步驟間鏡頭平滑運鏡。可隨時返回上一步。「快速開始」一鍵沿用上次設定。
2. **載具機庫**：載具在轉台上，可用搖桿／滑鼠旋轉；規格用少量大數字（重量、推進器數、極速、是否有機械臂）與 3–4 條能力條；貼紙選擇即時套用在模型上。
3. **海域選擇**：大卡片加預覽圖，顯示深度範圍、能見度、洋流強度、可用任務類型；選中時背景場景切換到該海域。
4. **模式選擇**：四種玩法用卡片呈現，各有一句話說明與人數。訓練情境清單（`scenarios`）放在「訓練」卡片內，以難度與練習重點標示。
5. **多人**：獨立畫面：建立／加入房間、伺服器位址、房間碼、玩家名稱、目前房內玩家。把現在混在主欄的連線欄位移到這裡。
6. **設定**：分頁（畫質／控制／音訊／介面／語言）。畫質沿用 `render_quality.js`；控制與音訊分頁預留掛載點給 T02、T05（它們未合併時顯示現有的簡易選項）。
7. **手把完整可操作**：焦點導航、確認／返回、分頁切換；焦點框明顯；底部顯示目前裝置的按鍵提示。T02 未合併時，先在本模組內用標準配置讀手把，並把讀取寫成之後容易替換的單一函式。
8. **暫停選單**：遊戲中按 Esc／Start 開啟（繼續、設定、返回主選單）。多人房間不暫停模擬，只開選單並把自己的操控回中。
9. 載入過程有進度與提示文字，不出現空白畫面。
10. 既有 URL 參數（`model=`、`room=`、`replay=`、`nointro`、`cam=` 等）與桌面版偏好儲存照常運作；帶 `replay=` 時直接進回放。

**驗證**：`simulator/tools/browser_menu_smoke.py`、`browser_connection_smoke.py`、`browser_gameplay_smoke.py` 必須通過（需要時同步更新腳本，並說明改了什麼）。附每個畫面的 1600×900 截圖，以及一段只用手把從標題進到水裡的錄影。
