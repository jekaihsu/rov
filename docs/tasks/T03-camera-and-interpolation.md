# T03 鏡頭與畫面插值：消除抖動與拖影

**目標**：畫面運動絲滑。同樣的物理，看起來要像 60 fps 原生運動。

**範圍**：新增 `simulator/viewer/state_buffer.js`、`simulator/viewer/camera_rig.js`；`app.js` 中狀態平滑（約 `lerpA`、`rovG.position.lerp(...)` 一帶）與鏡頭更新（`CAMS`、`setCam`、chase／orbit／top／onboard 更新）搬入新模組。不改後端、不改 HUD 與選單。

**背景**：目前渲染是每幀把模型朝「最新收到的狀態」做指數 lerp，網路抖動直接變成畫面抖動，並有固定延遲感。追蹤鏡頭是固定偏移加 lerp，`lookAt` 會生硬轉向。

**要做**

1. **狀態緩衝插值**：以伺服器時間（`state.t`／`tick`）建立快照緩衝，渲染時間落後約 2 個封包間隔，在兩個快照間插值（位置線性、姿態 slerp）。估計並追蹤時鐘偏移與抖動，緩衝延遲自適應。封包遺失時以速度做上限 100 ms 的外插，之後平滑收斂，不可瞬移。本機載具、其他玩家、纜線節點、魚群、工作物件使用同一個渲染時間。回放模式沿用同一套。
2. **本機回應感**：鏡頭與機載視角不得因緩衝而增加可感延遲。量測並在 PR 內回報「按下搖桿到畫面開始動」的延遲，改動前後各一組數字。若延遲變差，對本機載具採較短緩衝或預測。
3. **鏡頭架**：
   - 追蹤鏡頭改為臨界阻尼彈簧（位置與朝向分開調），偏航跟隨有延遲與上限，載具倒退或原地旋轉時不甩頭；速度越快鏡頭略拉遠、視角略增（上限 +8°）；碰到結構或海床時鏡頭前推避免穿模。
   - 機載鏡頭加入**虛擬雲台**：預設水平鎖定（畫面不隨橫滾傾斜、小幅俯仰抖動被濾除），俯仰可由動作平滑調整並有限位。提供開關切回硬連結（訓練用，等同現行行為）。
   - 環繞與俯視鏡頭加入慣性與平滑縮放。右搖桿在環繞模式可轉鏡頭（透過 T02 的動作；T02 未合併時先用滑鼠）。
   - 切換鏡頭有 250 ms 的交叉過渡，不是硬切。
4. 所有平滑都必須與幀率無關（用 `dt` 的指數／解析解），30、60、144 fps 下行為一致。
5. `?cam=`、電影模式（`cine`）、`render_movie.js`、觀測照驗證（`observation_camera.js` 依賴鏡頭姿態）不得壞掉。觀測照必須使用未加雲台美化前的真實機載姿態，或同步更新驗證邏輯與測試。

**測試**：`state_buffer.js` 用 `node --test`：亂序／遺失／抖動封包下輸出連續（相鄰幀位移有上限）、時鐘偏移收斂。彈簧函式測幀率無關性。跑 `simulator/tools/browser_smoke.py`、`observation_smoke.py`。PR 附一段 10 秒前後對比錄影或逐幀位移圖。
