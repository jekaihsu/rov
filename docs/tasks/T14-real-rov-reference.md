# T14 真實 ROV 參考研究與機載畫面（OSD）

**目標**：讓「機載鏡頭看到的東西」像真的 ROV 影像，而不是遊戲鏡頭。先研究，再實作。

**範圍**：`docs/reference/public.md`（研究產出）、新增 `simulator/viewer/onboard/`（機載畫面模式）、`simulator/viewer/hud/` 的最小掛載。不改物理、不改選單。

**第一部分：研究（先交，獨立一個 PR：T14a）**

用公開資料（廠商公開的作業影片與說明書、開源地面站軟體文件、離岸檢查與科研潛航的公開影像、操作員訓練教材）整理成 `docs/reference/public.md`。每一條寫「觀察到什麼 → 模擬器現在差在哪 → 建議怎麼做」，附來源連結。不得把他人圖片或影片存進儲存庫。至少涵蓋：

1. **影像特性**：水色隨深度與水質的變化、能見度的實際範圍、燈光下的後向散射（懸浮微粒像下雪）、近亮遠暗、光暈、自動曝光與白平衡的遲滯、鏡頭畸變與視角、低照度雜訊、影像壓縮痕跡與延遲。
2. **畫面疊字（OSD）**：真實作業影像上常見的資訊（時間、深度、航向、俯仰橫滾、纜長、溫度、專案與下潛編號、相機雲台角度、燈光檔位）與排版慣例。
3. **操作員實際在看什麼**：主畫面、聲納、導航圖、系統狀態的配置；多螢幕與單螢幕的差異；巡檢時的口頭紀錄與標記習慣。
4. **操作手感**：自動定向、定深、定高、定點的實際表現；纜線管理；常見失誤與事故型態。
5. **觀測級與作業級的差異**：尺寸、推力、機械臂、感測器。

若執行環境無法上網，如實說明並停止，不要憑記憶編寫來源。

**第二部分：實作（T14b，研究合併後再做）**

1. 機載視角新增「真實影像」模式：依研究結果加入後向散射、自動曝光遲滯、鏡頭畸變、雜訊與輕度壓縮感；可調強度，可關。與 T07 的後製管線共用（T07 未合併時自建最小版本，並寫成之後可併入的單一模組）。
2. OSD 疊字：依研究的慣例排版，內容取自權威狀態；可開關；錄影與拍照可選擇是否燒入 OSD。
3. 影像延遲選項（0／80／150 ms），訓練用，預設 0。
4. 觀測照的幾何判定不得受影響。

**驗證**：同一機位「一般機載」與「真實影像」並排截圖；`observation_smoke.py`、`browser_hud_smoke.py` 通過。
