# T20 物理對標：用已知載具驗證引擎，X1 參數標為暫定

**目標**：證明物理引擎能重現一台有公開實測數據的真實載具，再把 X1 的實測值填進同一套模型。依據 `docs/reference/real-rov-research.md`。

**範圍**：`simulator/qysim/vehicles.py`、`physics.py`（僅參數與必要的模型項）、`tether.py`（僅參數）、`simulator/tests/`、`docs/reference/`、`docs/rov-dynamics-research.md`。

**要做**

1. **BlueROV2 Heavy 對標**：以研究報告引用的實測係數（質量、各軸線性與二次阻尼、附加質量、慣量、浮心高度、推進器推力與正反推不對稱、推進器時間常數）建立對標用的機型設定。附測試，容差 15%：
   - 各軸穩態極速接近水池實測值（前進約 0.72、橫移約 0.63、垂直約 0.71 m/s，對應文獻的推力）。
   - 鬆桿滑行距離、最大偏航率與由係數推算的量級一致。
   - 洋流 0.5 m/s 的巡檢情境中，纜線拉力占水平推力的比例落在文獻量級（平均約四分之一）。
   若引擎的模型形式無法重現（例如缺少線性阻尼項或正反推不對稱），補上該項，並保證既有機型的行為不變（回歸測試）。
2. **X1 參數標記**：在機型定義中，每個 X1 參數標明來源等級：`official`（官網）、`reseller`（單一經銷商）、`estimated`（估算）、`measured`（自有實測）。目前沒有任何 `measured`。把這份清單輸出成 `docs/reference/x1-parameters.md`，之後實測數據進來時只改這一處。
3. **實測資料匯入**：寫一支工具，讀 `docs/reference/own/` 下依 `x1-measurement-checklist.md` 格式整理的 CSV（各軸極速、起步與滑行時間距離、偏航率），自動擬合阻尼與推力參數，輸出建議值與擬合誤差。用 BlueROV2 Heavy 的文獻數據當作測試案例驗證這支工具。
4. **真實現象補齊**（各自可開關，預設開）：推進器正反推不對稱；羅盤在大型鋼結構附近的偏差（5–10° 量級）；DVL 定點的有效高度範圍與失鎖。每項附測試，並更新 `PROTOCOL.md`（若狀態欄位有新增，一律選填）。
5. 不要為了對上數字而調整與該現象無關的參數；每個改動在 PR 描述中對應到報告裡的來源。

**驗證**：對標測試表（文獻值、模擬值、誤差）；既有測試全過。
