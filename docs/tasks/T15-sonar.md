# T15 聲納模擬

**目標**：真實 ROV 在能見度差時靠聲納。加入前視成像聲納，既是玩法，也是 AI／SI 整合的資料來源。

**範圍**：新增 `simulator/qysim/sonar.py`、`simulator/viewer/sonar/`、`simulator/sdk_mock` 選填擴充、`simulator/tests/`、`PROTOCOL.md`。不改物理。

**要做**

1. **後端掃描**：以既有的障礙物、地形與沉船距離場做扇形射線掃描（預設水平 120°、256 波束、量程 2–50 m 可調），輸出每波束的距離與回波強度。強度考慮入射角、距離衰減；加入可調的雜訊、多路徑假影與聲影。其他載具、纜線、工作物件、魚群要有回波。更新率 5–10 Hz，不拖慢物理步長（降頻與向量化；附效能數據）。
2. **協定**：`state.sonar` 為選填，只有客戶端訂閱時才送（新增 operation `sonar_subscribe`），強度量化為 8 位元。更新 `PROTOCOL.md`。
3. **顯示**：扇形聲納畫面（2D canvas），量程環、方位刻度、增益與量程調整、色表切換。作為 HUD 的一張速覽卡與可固定的小視窗；樣式依 `docs/design/ui-direction.md`。
4. **避障提示**：前方障礙距離由聲納提供時，HUD 的距離條改用它，並標示來源。
5. **SDK**：`sdk_mock` 新增選填方法讀取最新聲納掃描，文件標明「模擬器擴充，非原廠 SDK 介面」。附一個 Python 範例把掃描存成影像。
6. **玩法**：新增一個低能見度訓練情境（能見度 1 m 以內），必須靠聲納找到目標。

**測試**：已知幾何下的距離誤差上限；聲影正確（牆後物體無回波）；訂閱開關；三人房間下的效能。附聲納畫面截圖。
