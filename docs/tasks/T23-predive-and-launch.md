# T23 潛前檢查與下水回收流程

**目標**：真實作業從開機檢查開始，不是從水裡開始。把潛前檢查、下水、回收、潛後處理做成可操作的流程。依據 `docs/reference/real-rov-research.md` 的下水回收章節。

**範圍**：新增 `simulator/viewer/procedure/`、`simulator/qysim/procedure.py`、`simulator/campaign/`（教學腳本）、`simulator/viewer/deploy_intro.js`（銜接）、`simulator/tests/`。

**要做**

1. **潛前檢查表**：互動式清單（外觀與密封、纜線接頭、配重與配平、上電順序、通訊、相機、燈光、推進器逐顆短測、深度與羅盤讀數、解鎖條件）。每項要實際操作或確認才打勾。X1 專屬的順序與提示音在實測資料補齊前標為暫定。
2. **真實限制**：推進器離水運轉超過 30 秒告警並計入成績；只有入水後才能解鎖；跳過檢查會埋下對應的隨機故障（例如沒查接頭 → 下潛後通訊中斷）。
3. **下水**：從船或碼頭吊放／拋放的可操作版本（現有的是動畫）。玩家選下水點（上游側）、與纜線手確認、入水後做功能確認再下潛。
4. **回收**：回到水面、上鎖、由纜線收回；流速與浪況影響難度。
5. **潛後處理**：淡水沖洗、檢查、紀錄潛水日誌（自動帶入時間、深度、纜長、事件，可補註記並匯出）。
6. **模式**：訓練版預設完整流程；遊戲版預設快速下水，可在設定開啟完整流程。現有 `?nointro` 與動畫照常可用。
7. 作為 T12 序章之前的一段教學腳本。

**測試**：流程狀態機的單元測試（順序、跳步後果、解鎖閘門、離水運轉計時）；瀏覽器測試跑完整檢查表。附截圖。
