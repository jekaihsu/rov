# A3：訓練機型材質

在既有內部訓練重建上，透過 Blender MCP 更新 PBR 材質與輕微表面磨耗。
維持原始幾何、尺寸、節點名稱、父子階層、變換與 userData；不新增標誌或文字。

交付：兩份內嵌貼圖的 `.blend`、兩份小於 8 MB 的 meshopt GLB、1K–2K 貼圖，
以及兩台各三機位的 1600×900 PNG 前後比較（每張小於 1.5 MB）。

驗證包含最終 GLB 解碼後的幾何與節點契約比對、源檔重開檢查、預覽頁載入、
轉子綁定／旋轉及全部機械臂滑桿，並執行倉庫要求的後端與瀏覽器 smoke 測試。

[成果、前後比較、重現步驟及預覽頁既有限制](../design/training-vehicles/README.md)。
此任務不提升原模型的尺寸或物理估算可信度，不修改模擬器控制與物理。
