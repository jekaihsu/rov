# T18 SDK／AI 整合範例與自動化介面

**目標**：讓公司的 AI 與系統整合團隊拿模擬器就能開發：乾淨的 Python 介面、可重現的無頭執行、可直接跑的範例。

**範圍**：新增 `simulator/examples/`、`simulator/qysim/headless.py`（如需要）、`simulator/sdk_mock` 文件、`simulator/tests/`。不改物理與既有 SDK 行為。

**要做**

1. **無頭執行**：不開瀏覽器即可跑模擬，支援快於即時、固定種子、可逐步推進；同一種子與輸入必須得到相同結果（附測試）。
2. **Python 環境介面**：`simulator/examples/env.py` 提供 `reset() / step(action) / observe()`，觀測含姿態、速度、深度、測距、纜線狀態；動作為六個通道或速度指令。不引入重量級依賴。
3. **範例**（每個可獨立執行、附說明與預期輸出）：
   - 用模擬 SDK 做定深定向巡航，走一個矩形航線。
   - 沿牆面等距離掃描（用測距回授）。
   - 取機載影像並存檔。
   - 纜線張力監看與自動退避。
   - 最小的自動巡檢任務：依序到三個站點懸停拍照，並用任務判定驗證完成。
   - 批次評測：同一控制器在 20 個隨機種子下的成功率與統計。
4. **資料紀錄**：把一次執行的狀態與動作存成 CSV，附讀取範例。
5. **文件**：`simulator/examples/README.md` 從零開始的教學：安裝、啟動、第一個範例、如何換成真機 SDK。明確標示哪些是原廠 SDK 相容介面、哪些是模擬器擴充。
6. 所有範例納入測試（縮短版本，確保不壞）。

**驗證**：每個範例的實際執行輸出貼在 PR 描述；決定性測試通過。
