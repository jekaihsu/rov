# T07 水下畫面品質

**目標**：截圖放上 Steam 商店頁不丟臉。重點是光、水體、粒子與材質，不是多邊形數。

**範圍**：`simulator/viewer/environment.js`、`underwater_lighting.js`、`render_quality.js`、新增 `simulator/viewer/fx/`；`app.js` 只改渲染迴圈的呼叫點。不改 HUD、選單、後端。

**要做**

1. **後製管線**：`fx/pipeline.js` 以 three.js 內建 `EffectComposer` 建立，可依畫質等級開關各效果。必須與 `render_quality.js` 的動態解析度、錄影、`render_movie.js`、觀測照擷取相容。
2. **水體**：依深度與距離的波長相依吸收（紅先消失、遠處偏藍綠），取代單一顏色的霧；能見度沿用情境參數與揚沙。燈光照到的近物恢復原色，這是水下畫面最重要的質感來源。
3. **光**：淺水的水面光束（god rays）與海床／結構上的焦散，隨深度衰減至消失；載具燈光為體積光錐，被懸浮微粒散射；深處關燈時幾乎全黑但仍可辨識輪廓。
4. **粒子**：海洋雪（懸浮微粒）隨洋流方向漂移，靠近鏡頭時有景深感；推進器擾動、觸底揚沙、氣泡（出入水、推進器靠近水面）。使用 GPU instancing，數量依畫質調整。
5. **水面**：由下往上看的全反射窗（Snell's window）與波動；出入水時鏡頭有水線與水滴轉場。
6. **調色與鏡頭**：ACES 色調映射後加輕度調色、暗角、極輕微色差與膠片顆粒（皆可關）。機載視角加入輕微鏡頭畸變與感光雜訊選項，讓「機載畫面」與「第三人稱」有明顯區隔。
7. **材質**：載具與結構使用環境貼圖反射（水下版本）；海床加細節法線與近景碎石；海生物附著在結構上的顏色變化。
8. **效能**：定義低／中／高／極致四級。整合顯示晶片在「低」必須維持現有幀率（用 `simulator/tools/browser_fleet_perf.py`、`browser_expedition_perf.py` 前後對比並回報）；自動畫質要能在掉幀時先關後製再降解析度。
9. 所有效果不得影響觀測照的幾何判定（判定用投影與射線，不看像素；確認仍然如此）。

**交付**：五個固定機位（淺水礁、海草床、港灣、沉船 32 m 開燈、沉船關燈）的前後對比截圖，四級畫質各一張，以及效能數據表。新增貼圖僅限 CC0，並更新 CREDITS。
