# T20 物理對標

依據 [研究報告](real-rov-research.md)「BlueROV2 Heavy 是唯一有完整實測係數的參考載具」及
[動力學審查](../rov-dynamics-research.md)。對標 profile 是離線用 `BENCHMARK_HEAVY`，
不新增操作介面品牌，不覆寫既有三個機型。

## 來源與模型

- von Benzon 2022 Table A1：質量 13.5 kg；線性阻尼 (13.7,0,33,0,.8,0)；
  二次阻尼 (141,217,190,1.19,.47,1.5)；附加質量 (6.36,7.12,18.68)；
  合併慣量為 CAD (.26,.23,.37) 加估算 (.189,.135,.222)；浮心高 .01 m。
  浮力 -0.982 N 由文獻排水量 .0134 m³、淡水密度 1000、重力 9.82 推算。
  引擎其他部分仍採海水密度與 9.81，不能宣稱完整重現原文。
- 報告引用 T200 16 V 官方 5.25/4.1 kgf，轉 N 使用 9.81；一階時間常數 .076 s
  是文獻轉移函數主導極點近似。正反推可用 `thrust_asymmetry=False` 關閉。
- 新增可選六軸 `quadratic_drag`，未提供時仍用既有 vmax/wmax 反算。
- 對標配置的推進器幾何仍是既有重建（正負方向交錯），不是原文 CAD；
  未驗證完整分配器、交叉耦合、滿桿最大偏航率與步階推進器響應。
- 纜線提供獨立 `BENCHMARK_TETHER_PARAMETERS`：Table A1 的 .0075 m、.043 kg/m、
  法向 1.2、切向 .01。沒有更改 X1 預設，也沒有為湊比例調剛度或長度。

## 對標結果（15% 容差）

下列測試透過 Vehicle.step 積分，明確隔離單軸、扣除浮力，直接施加文獻指定力，
**不是整機滿桿實測驗證**。滑行測試從 .72 m/s、零剩餘推進器推力起算。

| 項目 | 文獻／推算 | 模擬 | 誤差 |
|---|---:|---:|---:|
| 前進 85 N | .72 m/s | .72936 | 1.30% |
| 側移 85 N | .63 m/s | .62586 | .66% |
| 垂直 120 N | .71 m/s | .71261 | .37% |
| 前進鬆桿滑行 | 約 .30 m（係數推算） | .29010 | 3.30% |
| 偏航 20 Nm（指定力矩，非整機最大值） | 約 3.7 rad/s | 3.65148 | 1.31% |

20 Nm 是測試條件，不是查得的實測最大力矩。偏航這一列僅驗證指定力矩下的阻尼量級。
既有機型正反推比例仍為 1（曲線未知），測試比較開關切換前後軌跡完全相同。

## CSV 擬合

`python docs/reference/fit_measurements.py docs/reference/own/trace.csv`；欄位與限制見
[x1-measurement-checklist.md](x1-measurement-checklist.md#t20-csv-匯入格式)。
回歸案例以文獻 surge 的 85 N、13.7、141、19.86 kg 生成 .001 s 合成階躍／滑行資料，
得到 85.250 N、13.742 Ns/m、141.413 Ns²/m²，力殘差 RMSE .02642 N。
這是演算法驗證，並非新增實測資料。無法只靠極速、時間距離摘要唯一擬合三個係數；
缺乏有效質量、纜線力或推力曲線時不得升格為 measured。

## 未驗證與後續

- 未驗證：原文 .5 m/s 巡檢的平均 21.1 N/85 N（25%）及峰值 38%。
  尚未移植其巡檢軌跡、SMC 控制器及纜線初態；不得以任選長度湊比例。
- 未驗證：滿桿最大偏航、文獻 CAD 幾何與完整推進器響應、X1 任一實機參數。
- 尚未實作：羅盤鋼構偏差、DVL 高度窗及失鎖。任務書範圍未包含 engine/controller；
  必須另行確認控制器與遙測接線範圍，不能只增加不影響控制的狀態欄位假裝完成。
  （後續：已由共用感測器層 `simulator/qysim/sensors.py` 實作，控制器、導航與遙測都讀估計值；
  數值仍為暫定，見 PROTOCOL.md「Optional sensor layer」。）
- 未修改協定，也未對任何 SDK 欄位增補或改義；新增感測器行為時須同步 PROTOCOL.md。

原文複核另發現：Table 8 的巡檢流速向量是 [.21,.21,0] m/s、纜長 35 m，
與研究報告敘述的 .5 m/s 不同。25% 是 Table 9 的 x 軸平均纜力／85 N 軸推力，
並非總水平推力比例。這個差異須先釐清，不能把 .5 m/s 任意場景當成同一實驗。
